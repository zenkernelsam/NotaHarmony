## 改了什么

创建 `note/src/main/ets/core/adaptation/Canvas2DStrokeRenderer.ets`（StrokeRenderer 的 Canvas 2D 实现）：

- `class Canvas2DRenderContext implements RenderContext`：包装主画布 CanvasRenderingContext2D，扩展 beginPath/moveTo/bezierCurveTo/stroke/fill/setLineDash/drawImage 等 Canvas 2D 能力
- `class Canvas2DOffscreenRenderContext implements RenderContext`：包装 OffscreenCanvasRenderingContext2D（方法集与 A 一致）——ArkTS 禁止结构化类型赋值，主画布与离屏上下文必须分属两个包装类
- `class Canvas2DStrokeRenderer implements StrokeRenderer`：
  - renderCenterPath()：中心线 Path（cubicSegments 优先，pathPoints fallback）；lineWidth=brushWidth、cap/join=round；DASH `[2w,1w]`、DOTS `[0.001w,2w]`；荧光笔 alpha 107/255；colorToRgba
  - renderVariableWidthOutline()：WidthOutlineBuilder 构建封闭轮廓 → fill
  - renderPencilSplats()：splat 包围盒动态离屏（修复：splat 为绝对坐标，离屏用相对坐标绘制，避免 512 固定离屏导致 splat 溢出不可见）→ source-in 笔色着色 → transferToImageBitmap → 主画布合成；纹理未加载用 4px 圆形 fallback；颜色缓存 Map<number, OffscreenCanvas>
  - renderEraserMask()：maskPath 非空时 destination-out 挖洞（lineWidth=eraserMaskWidth 默认 20）
  - setSplatTexture() / setEraserMaskWidth()
