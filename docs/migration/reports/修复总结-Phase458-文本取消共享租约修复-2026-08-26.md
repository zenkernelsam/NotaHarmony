# 修复总结 — Phase 458 文本取消共享租约修复

## 问题

照片导入前新建的空文本块，可在异步导入释放 `historyBusy` 后、共享租约收口前被取消。取消
会从文本数组和 elementOrder 删除元素并持久化，与照片插入结果形成并发窗口。

## 修复

文本取消统一入口在内部历史门禁前拒绝共享导入租约并保留会话，用户可在导入完成后重试取消
或确认。空文本创建的撤销语义、原始墨迹预约刷新和页上下文防御不变。
