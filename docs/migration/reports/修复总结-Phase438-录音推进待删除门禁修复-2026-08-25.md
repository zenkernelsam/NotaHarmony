# 修复总结 — Phase 438 录音推进待删除门禁修复

日期：2026-08-25

## 问题

录音 A 的 COMPLETED 快照会启动一个异步自动推进任务。若用户在该任务 await 控制器加载前请求删除 A，
时间线重建已把 A 从可见列表排除，控制器也卸载了 A；但过期续体仍会查询当前时间线并加载 B，导致面板中
不可见、不可播放的 A “跳到”隐藏后继并自动播放。

## 修复

自动推进入口在销毁检查后、选择下一曲前增加待删除门禁：完成录音 ID 已进入
`pendingRecordingDeleteIds` 时直接返回。每次 COMPLETED 事件仍由自身计数递增和 finally 递减负责所有权；
正常连播与用户 seek 失效语义不变。

## 验证

新增专项 Replay `d02-recording-advance-pending-delete-bound.mjs`，锁定销毁门禁、待删过滤和时间线选择
顺序，结果 2/2。既有推进计数与待删投影所有权 Replay 继续通过。其余全量验证见总进展补录。
