# Phase 403：标题提交与离开上下文绑定

日期：2026-08-25（Asia/Shanghai）

## 问题

离开编辑器在等待画布 flush 后没有复查销毁态，迟到的续体会继续释放工具和录音资源并执行路由返回。标题持久化返
回后也只检查销毁；如果用户已切页，旧续体还会发布标题并把 NOTE_TITLE 撤销命令推给 Canvas，可能导致新页上下文被
跨页历史加载打断。

## 修复

- 画布 flush 返回后增加销毁门禁，销毁则停止后续工具、录音清理和路由返回。
- 标题持久化成功后再确认当前页仍是发起页。
- 页身份漂移时只把本地标题同步为 durable 物化值，不修改撤销 action、不调用 bridge 推入。
