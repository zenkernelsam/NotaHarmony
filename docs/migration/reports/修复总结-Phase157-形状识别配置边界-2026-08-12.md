# Phase 157 修复总结：ShapeDetector 配置边界

## 发现

`ShapeDetector` 的可选配置会直接覆盖默认阈值。非法的 `NaN`、负长度、零重拟合阈值和
超出 `[0,1]` 的置信度会污染识别流程。

## 修复

- 对五个配置字段增加有限性和范围门禁。
- 非法值分别回退既有默认值；合法有限值保持不变。
- 未改动直线、椭圆、多边形启发式判据，也未把移植算法宣称为原版 MyScript 等价实现。

## 验证

`d02-shape-detector-config-boundaries.mjs`：`TOTAL=5 FAILED=0`。

本阶段未启动设备、模拟器、虚拟机或 Hypium；原版识别阈值和真实手写观感仍待独立取证。
