# Phase 398：删除页刷新身份绑定

日期：2026-08-25（Asia/Shanghai）

## 问题

删除页流程在捕获快照前等待画布 `flushCurrentPage()`。这个 await 可能让挂起的切页加载完成并改变当前页；旧续体
随后仍会把“新的当前页”快照为被删页的撤销内容，同时持久化删除原来的 page ID，最后再把剩余页列表发布到已经切换
的上下文。这样会污染撤销历史并造成 UI 与 durable 状态错位。

## 修复

- flush 返回后检查父级当前页是否仍是原删除目标；不一致则静默取消本次删除。
- 成功路径继续使用 flush 前算出的 `selectedAfter`，发布剩余列表后精确选择该后继页。
- 销毁门禁、删除失败回滚、撤销元数据和 durable 删除行为不变。
