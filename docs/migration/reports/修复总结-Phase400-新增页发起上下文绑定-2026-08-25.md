# Phase 400：新增页发起上下文绑定

日期：2026-08-25（Asia/Shanghai）

## 问题

新增页在持久化等待期间允许用户切页。旧续体只检查销毁态，随后仍会把当前页改回新页并推入撤销记录；这会抢夺导航，
且撤销 action 记录的发起页与真实切换结果不一致。

## 修复

- durable 建页返回后先确认当前页仍为发起页；不是则静默返回。
- 陈旧续体保留已持久化的新页，但不再发布 UI 页列表或撤销 action。
- 正常路径改为发布更新列表后一次性按列表长度选择新页。
