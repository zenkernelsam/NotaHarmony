# Phase 165 修复总结：Note 导入文件句柄生命周期

## 发现

`NoteImporter.importFromFile` 在文件打开后若 `statSync`、完整读取或后续流程抛错，原实现可能跳过 `closeSync`，泄漏文件句柄。

## 修改

- `note/src/main/ets/data/NoteImporter.ets`
- 新增 `ADR-0142-note-import-file-handle-lifecycle.md`
- 新增 `d02-note-import-file-handle-lifecycle.mjs`

导入文件句柄现在由 nullable 所有权管理，成功关闭后清空，异常路径由 `finally` 兜底关闭；取消和空文件语义保持不变。
