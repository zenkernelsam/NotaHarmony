## 改了什么

1. `note/src/main/ets/rendering/CanvasViewport.ets`（新建）：视口状态管理
   - `screenToCanvas` / `canvasToScreen`（屏幕↔画布坐标映射）
   - `zoomAt`（以屏幕点为中心缩放，保持该点内容不动）/ `panBy` / `setZoom` / `setScroll` / `reset` / `clamp`
   - zoom 范围 [0.25, 4.0]；滚动边界 MVP 不限制（自由平移）
2. `note/src/main/ets/ui/editor/NoteCanvasView.ets`：
   - **渲染变换**：renderFrame 中 `translate(scrollX, scrollY) + scale(zoom)` 后绘制背景/已完成层/文本框；背景铺满视口可见区（w/zoom, h/zoom）
   - **输入映射**：所有输入点（书写/擦除/选区/双击/拖拽）经 `screenToCanvas` 逆映射（toRawPointerEvent 内统一转换）；选区 overlay 边框用 `canvasToScreen` 转屏幕坐标
   - **手势**：`GestureGroup(Exclusive, [Parallel(PinchGesture(2), PanGesture(2))])`——双指捏合缩放（以两指中心为锚，增量换算）+ 双指平移；onTouch 中 `touches.length > 1` 忽略（单指书写不受干扰）
   - **缩放控制条**：右下角 `[-][百分比][+][适应宽度]`（步进 0.25；适应宽度按页面宽 800 画布坐标铺满 85%）
   - **持久化**：缩放/滚动变化 → `scheduleViewportSave`（防抖 500ms）→ `saveViewState`；loadNoteData 恢复 zoom/scroll
3. `note/src/main/ets/rendering/PaperRenderer.ets`：`renderBackground` 加 zoom 参数，线宽/点半径除以 zoom（保持视觉 1px）
