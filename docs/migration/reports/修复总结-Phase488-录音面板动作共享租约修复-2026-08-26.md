# 修复总结 — Phase 488 录音面板动作共享租约修复

## 问题

录音面板已有响应式禁用，父页回调也有共享导入/结构租约防线；但组件内十个直接转发缺少第二层
拒绝，导入收口窗口内的晚到点击或拖动仍可能触发录音、播放或删除流程。

## 修复

关闭、进度拖动、暂停、恢复、停止、开始、倍速、播放切换、删除和撤销删除回调先拒绝
`photoImportLeaseActive`，再调用原有父页回调。控件可用性、待删行、会话控制、播放快照和
持久化语义不变。

## 影响与验证

- 新增 ADR-0460、Harmony evidence 和本中文 Report。
- 扩展录音面板共享租约专项 Replay 锁定十项新防线，当前 `TOTAL=23 FAILED=0`。
- ArkTS 目标无错误，仅既有警告与信息级提示。
- 相邻录音关闭共享租约 Replay 通过。
- 全量 Desktop Replay `REPLAY_FILES=421 PASSED=421 FAILED_FILES=0`
  （31.046 秒）；clean 3.189 秒、ohosTest HAP 10.610 秒、default HAP 29.614 秒均静态构建成功。
- 未启动模拟器、虚拟机、真机或 Hypium；T-042 继续保留为 Goal 最后任务。
