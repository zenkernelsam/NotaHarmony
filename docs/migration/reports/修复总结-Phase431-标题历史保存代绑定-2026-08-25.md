# 修复总结：Phase431 标题历史与保存代绑定（2026-08-25）

## 问题

Phase 430 后边修边补审发现，NOTE_TITLE Undo/Redo 仍走通用页面历史入口。普通标题提交由
独立的 `titleSaveQueue` 驱动，但该队列没有可被历史入口检查的权威状态；队列飞行中执行标题历史，
可能基于旧 `noteTitle` 通过校验并与 durable 标题事务竞争。

## 修复

- 新增 `titleSaveInFlight`：每次标题保存入队置位，durable commit settle 后 finally 清零。
- 新增 `onApplyNoteTitleHistory()`：页面操作或标题保存飞行中直接拒绝标题历史。
- Canvas 仅对 `NOTE_TITLE` 分流到新入口，其他页面级历史语义不变。

## 证据与回放

- 新增 ADR-0403 记录“权威 in-flight + 独立历史入口”边界。
- 新增 Harmony evidence 固定源码顺序、缺口和断言。
- 新增专项 Replay 3/3；相邻标题、页面历史、删除和结构租约回放通过。
