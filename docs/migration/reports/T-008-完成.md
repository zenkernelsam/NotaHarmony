## 改了什么

创建 3 个适配层实现文件：

1. `note/src/main/ets/core/adaptation/InkInputProviderImpl.ets`
   - `class InkInputProviderImpl implements InkInputProvider`
   - 构造参数传入设备能力标记（pressure/tilt/orientation）
   - `processEvent()`：kind 判定（PREDICTED/HISTORICAL/REAL）；pressure clamp [0,1]、tilt clamp [0,π/2]、orientation 归一化 [0,2π)、无能力时 -1；toolType 映射（0→STYLUS 其他→TOUCH）
   - 扩展方法 `beginStroke(startTime)`：调用方在 touchDown 时设置，用于计算 elapsedTimeMillis
   - 不 import 平台 API

2. `note/src/main/ets/core/adaptation/PenKitPredictor.ets`
   - `class PenKitPredictor implements Predictor`：线性外推（最后两点速度方向外推 2 点）；history < 2 返回 []；注释预留 PointPredictor 接入点（当前版本不实际调用，模拟器可能不支持）

3. `note/src/main/ets/core/adaptation/NullPredictor.ets`
   - `class NullPredictor implements Predictor`：predict 返回 []，reset 空实现
