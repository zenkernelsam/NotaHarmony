# 修复总结 — Phase 577 原版形状识别覆盖仲裁（e5d.b 双阈值）

日期：2026-09-22
提交范围：`ShapeDetector.ets`、`d02-original-shape-override.mjs`、
ADR-0548、证据文档、跟踪文档。

## 背景

A-32 遗留：`ShapeDetector` 判据常量为移植方自拟。本 Phase 对照原版
`e5d.b()` 的候选仲裁逻辑，发现 Harmony 只做 argmax + `>0.2` 接受门，
缺少原版的两条**覆盖规则**。

## 原版语义（硬证据）

`e5d.b`：4 候选器（`cg7` + `y90`×3）→ argmax → 覆盖检查 → `>0.2` 接受。

- 最佳 = POLYGON 且 `b16.h()`（`min|edge|/max|edge| < 0.25`，边长严重
  不均——手绘团块被误简化为多边形的特征）→ 首个 `>0.3` 候选替代；
  再若有 `>0.3` 的正圆 ELLIPSE（`m06.h==i` 长短轴相等）则再替代。
- 最佳 = LINE → 首个 `>0.3` 的 ELLIPSE 替代。

覆盖门 0.3 高于接受门 0.2：只让位于"像样的替代者"。

## 修复

`ShapeDetector.ets`：

1. `DetectionResult` 增加 `kind/closed/circle/unevenEdges` 仲裁元数据；
   `circle` = 归一化后 `rx === ry`（`m06.h==i` 等价）。
2. `hasUnevenEdges` 实现 `b16.h()`：闭合环计入 last→first 回环边，
   开放链只算相邻边；判据 `|min|/|max| < 0.25`。
3. `applyOriginalOverride` 按原版顺序执行两条覆盖；候选顺序即评估序
   （line→ellipse→polygon）。
4. 新增常量 `ORIGINAL_SHAPE_OVERRIDE_CONFIDENCE=0.3`、
   `ORIGINAL_POLYGON_UNEVEN_EDGE_RATIO=0.25`。

三候选映射"评估序"语义；`b16.h()` 对闭合环的零长边细节采用去重顶点

Harmony 折叠为 LINE/ELLIPSE/POLYGON（既有差距）。
