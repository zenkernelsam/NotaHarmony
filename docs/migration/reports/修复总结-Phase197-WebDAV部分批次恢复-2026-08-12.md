# Phase 197 修复总结：WebDAV 部分批次恢复

## 发现

`BackupBatchRestorer` 能逐项返回 hash 校验失败，但 `BackupPage.restoreFromCloud()` 在
`failedNoteIds.length > 0` 时立即返回，已验证的其他笔记完全不会导入，且用户看到恢复
数量为 0。

## 修改

- 仅在没有任何已验证对象时提前结束
- 将远端校验失败数初始化进统一 `failed` 计数
- 保留已验证对象的逐篇导入与 PARTIAL 汇总
- 恢复器改用结构化校验后的 manifest、batchId 和 entries 快照
- 更新旧 replay，新增恢复器快照 replay
