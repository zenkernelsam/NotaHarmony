# Phase 397：新增页选择上下文绑定

日期：2026-08-25（Asia/Shanghai）

## 问题

新增页的持久化续体通过销毁检查后，先把 assigned page 追加到末尾并把 `currentPageIndex` 设为最后一项，之后才
修改 action 并向 Canvas 发布新页。Canvas 的当前页是受监听属性，发布后可能启动异步切页加载；若用户在这两帧之
间切换页面，旧续体仍会把索引改回新页，形成选择回抢。

## 修复

- 销毁检查后先基于 assigned page ID 在更新列表中定位并设置当前索引。
- 随后再规范化撤销 action、发布更新后的页列表并推入撤销栈。
- durable 建页、撤销语义和既有销毁门禁保持不变。
