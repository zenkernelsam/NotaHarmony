# Phase 412 修复总结：显式墨迹轮廓中心线绑定

## 问题

补审 1.0.3 中心线墨迹渲染时确认，`customPath` 在原版中是裁剪轮廓，不是主墨迹形状；真正绘制的是 `path` 中心线。Harmony 旧实现只有 DASH/DOTS 使用轮廓裁剪，其他样式直接填充 customPath。这样带显式轮廓的普通笔迹会变成实心多边形，荧光笔也会绕过统一的 alpha 覆盖。

## 修复

现在 `renderCustomPath()` 不再区分 ink style：先构建 customPath，再 clip，最后调用 `renderCenterPath()`。中心线路径继续统一处理宽度、BUTT/ROUND 线帽、ROUND/MITER join、DASH/DOTS 参数、backingDashPhase 和荧光笔 107 alpha。铅笔的 customPath + splat 组合保持独立。

- 辅助路径、渲染、样式映射、墨迹特效、局部擦除、创建墨迹和铅笔修改相邻 Replay 全部通过。
