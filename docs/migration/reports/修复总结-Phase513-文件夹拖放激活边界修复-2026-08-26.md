# 修复总结 — Phase 513 文件夹拖放激活边界修复

## 问题

文件夹拖放收尾缺少页面激活入口防线；晚到 drop 可在页面失活后读取过期快照并启动移动事务。

## 修复

`finishFolderDrag()` 先拒绝非 `pageActive` 并清理拖拽快照，再执行原状态换算与移动流程。忙态拒绝、
ArkUI 边界扣除、可见子树层级、失败提示和生命周期发布全部保留。

## 影响与验证

- 新增 ADR-0485，并在既有原版文件夹索引拖拽 evidence 文件追加本阶段增量段。
- 扩展原版文件夹索引拖拽 Replay 的静态断言，当前通过。
- ArkTS 目标无错误，仅既有警告与信息级提示。
- 全量 Desktop Replay `REPLAY_FILES=421 PASSED=421 FAILED_FILES=0`
  （33.373 秒）；clean 3.174 秒、ohosTest HAP 10.145 秒、default HAP 30.907 秒均静态构建成功。
