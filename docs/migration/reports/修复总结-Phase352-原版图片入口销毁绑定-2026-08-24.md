# Phase 352 修复总结：原版图片入口销毁绑定

日期：2026-08-24（Asia/Shanghai）

## 缺陷与修复

- 相册图片选择/导入和剪贴板图片粘贴的迟到续体只校验页面代数与 pageId；`aboutToDisappear()` 后仍可弹出失败或
  部分失败提示、覆盖剪贴板图片可用状态，并让旧实例的 busy 清理与新实例生命周期错位。
- 新增 `isPhotoContextCurrent()`，统一要求 `lifecycleActive`、页面代数和 loadedPageId 一致。
- 相册 toast、剪贴板探测写入、权限中断路径、导入完成状态和失败 toast 全部绑定该完整身份；过期续体不触达 UI。
- durable 插入成功继续遵循 ADR-0321 的陈旧页语义；`photoImportBusy` 仍在 finally 中复位。
