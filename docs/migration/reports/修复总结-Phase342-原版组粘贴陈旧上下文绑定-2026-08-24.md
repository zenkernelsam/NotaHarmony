# Phase 342 修复总结：原版组粘贴陈旧上下文绑定

日期：2026-08-24（Asia/Shanghai）

## 缺陷与修复

- `applyOriginalGroupClipboardPaste()` 的成功回调只保护了页面元素安装；编辑器销毁或切换后，迟到事务成功仍会提交剪贴板粘贴序号、push 本地 undo 历史、更新历史版本并发布通知。
- 现在所有成功侧效果前统一检查 `isHistoryPageContextCurrent(generation, pageId)`。陈旧成功只记录“durable 历史仍可用”并返回，不触达剪贴板、undo 栈、UI 或通知。
- 失败路径继续只在当前上下文发布保存失败；`.finally()` 无条件复位 `historyBusy`，避免污染下一个页面。
