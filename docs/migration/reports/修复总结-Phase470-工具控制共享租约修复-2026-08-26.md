# 修复总结 — Phase 470 工具控制共享租约修复

## 问题

选区样式信号入口已有共享导入守卫，但导入前打开的 `ColorPickerView` 与 `WidthSlider`
不感知该租约。色块可继续改写笔刷颜色并排队工具状态保存；宽度滑杆也可连续触发内存
状态更新与持久化任务，与照片导入收口竞争。

## 修复

两个面板接收父页共享导入租约并分别禁用全部色块和滑杆。`EditorToolbar` 统一传递该属性；
既有 `onSelectionColor` 与 `onSelectionWidth` 回调继续先拒绝共享导入，再保留页面结构、
历史等待和加载健康防御。工具状态模型、保存链、回滚和选区墨迹语义不变。
