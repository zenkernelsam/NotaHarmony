## 集成修复记录（T-025 联调发现）

1. SelectionOverlay 全屏 Stack 拦截 Canvas 触摸 → HitTestMode.Transparent 解决
2. Transparent 下 Canvas onTouch 与菜单按钮 onClick 双路分发，Canvas 的 selection begin 触发 rebuild 使按钮 click 识别失效（CLK RACC T:null）→ NoteCanvasView 在菜单区域（isInSelectionMenu）不处理触摸
3. 渲染器未应用 stroke.transform（选区变换视觉无效果）→ StrokeLayerManager.renderStrokeOnto 渲染前 setTransform
4. 移动中每次 Move push Undo（栈爆炸）→ 改为移动结束时统一 push
