# 修复总结 Phase 557 — 原版库无障碍标签

日期：2026-09-22

## 原版证据

`decompiled_1.0.3` 资源为库界面定义了四条专用 contentDescription：

- `feature_library__cd_add_note` = "Add note" → 新建笔记 FAB
- `feature_library__cd_open_note_action` = "Open note" → 打开笔记（无标题变体）
- `feature_library__cd_open_note_titled` = "Open note %1$s" → 打开笔记（含标题）
- `feature_library__cd_sort` = "Sort notes" → 排序控件

原版的卡片整体就是一个可点击面，因此整张卡片用一条描述
"Open note %1$s"，而不是给内部图标分别加描述。

## Harmony 落地（`LibraryPage.ets`）

- 创建 FAB（speed-dial 根 `+`/`×`）：补 `.accessibilityText(cd_add_note)`。
- `NoteCard`（宫格）：在持有 `.onClick` 的 `Column` 上加
  `cd_open_note_titled`（传 `note.title`），标题为空时退 `cd_open_note`。
- `NoteListRow`（Phase 547 的 `ie7` 列表行）：同样的标签挂在行的点击
  容器上，保持宫格/列表无障碍对等。
- 排序字段按钮：`sort` 泛标签换为 `cd_sort`（"Sort notes"）；方向箭头
  按钮保留自有标签。

## 字符串

`base`（英文取原文）与 `zh_CN` 各新增四条：`cd_add_note`、
`cd_open_note`、`cd_open_note_titled`、`cd_sort`。

## 登记差异

- `.accessibilityText` 对应 `contentDescription`；标签挂在点击容器上，
  避免内部子节点（标题、文件夹 chip、录音指示）产生重复播报。
- 搜索框 `cancelButton`（Phase 555）无独立无障碍挂点，为平台差异，
  已在该 Phase 文档登记。
- 无标题回退 `cd_open_note` 属防御性对等：仓库始终持久化非空标题
  （默认笔记名）。
