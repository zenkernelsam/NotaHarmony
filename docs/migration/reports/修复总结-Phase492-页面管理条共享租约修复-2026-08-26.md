# 修复总结 — Phase 492 页面管理条共享租约修复

## 问题

页面管理条的紧凑新增、前后翻页、普通新增和删除按钮已有响应式禁用；但点击直接转发父页，
缺少组件内第二层租约拒绝，导入收口窗口内的竞态点击仍可能排队页面操作。

## 修复

四个直接回调先拒绝 `photoImportLeaseActive`，再调用原有 `onAdd()` / `onPrev()` /
`onNext()` / `onDelete()`。控件可用性、菜单防线、设置弹窗抑制和父页页面操作守卫全部保留。
