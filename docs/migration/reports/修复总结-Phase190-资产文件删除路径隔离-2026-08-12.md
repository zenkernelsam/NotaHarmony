# Phase 190 修复总结：资产文件删除路径隔离

## 发现

资产记录的 `local_path` 直接用于 unlink，没有验证其位于应用私有 files 目录；损坏数据
或恶意导入可能触发应用外文件删除。

## 修改

- `AssetRepositoryImpl.ets` 与 `NoteRepositoryImpl.ets` 删除调用点传入 `filesDir`
- `unlinkAssetFile()` 增加根目录和 `..` 穿越检查
- 新增 ADR、replay 和本报告

## 验证

- Replay：`TOTAL=5 FAILED=0`
- HAP/设备测试：本轮未执行

## 未闭环

符号链接解析与真实权限故障仍需设备 fault injection。
