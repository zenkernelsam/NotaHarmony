# Phase 390：Math 提交发布页面绑定

日期：2026-08-25（Asia/Shanghai）

## 问题

原版 Math 插入和 LaTeX 修改在 durable commit 成功后已有陈旧页返回门禁，但门禁位置只挡住内存元素发布；迟到
续体仍会向已离开的 Canvas 实例 undo 栈 push 动作，并调用全局 `notifyUndoRedo()`，导致新页面可能收到旧实例
的撤销状态广播。

## 修复

- 将提交后 Math undo action 的构造移到 `isHistoryPageContextCurrent()` 通过之后。
- `undoRedo.push(mathAction)`、修订记录、编辑器清理与 `notifyUndoRedo()` 统一保持在当前页分支内。
- 陈旧成功续体继续保留 durable 历史，但不再污染旧实例撤销栈或触发全局通知。
- 相邻照片插入路径复核为已有完整门禁，不做无意义改动。
