# Phase 417 修复总结：跨页历史命令租约

日期：2026-08-25（Asia/Shanghai）

## 问题

跨页撤销/重做会保存 pending 方向并请求目标页。目标页异步加载期间，底部上一页/下一页只检查
`pageLoading` 和 `pageOperationBusy`，仍可再次改页并启动新一轮加载。旧方向之后可能落到非目标页，
或被恢复健康门禁静默清除，造成错误上下文执行或用户命令丢失。

## 修复

- 将 `pendingHistoryDirection` 明确为跨页历史命令租约，并在 NotePage 增加 `historyPending` 投影。
- Canvas 在设置方向、请求目标页之前先通知页面持有租约；`resumePendingHistory()` 消费方向后立即释放。
- 上一页/下一页在 loading 和 operation busy 之外增加 history-pending 门禁，挂起期间不允许旁路翻页。

## 原版依据

1.0.3 文本 undo 队列 `dd8.a()` 要求无 pending register 且队列空闲后才触发 rollback；一条命令独占编辑器状态。
Harmony 现在让导航尊重同样的独占语义：目标页加载完成前，pending 历史 move 不被新翻页替换。
