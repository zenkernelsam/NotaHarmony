## 修复的集成问题（7 个缺陷）

| # | 缺陷 | 根因 | 修复 |
|---|------|------|------|
| 1 | **启动即崩溃**（`LibraryPage.ets:417` TypeError: background of undefined） | ArkTS 编译器**丢弃 @Component struct 中的自定义 getter**（编译产物无 `get tokens()` 定义，运行时 `this.tokens` 为 undefined）；T-038 引入、从未 UI 实测 | 6 个文件（LibraryPage/NotePage/EditorToolbar/PageManagerBar/BackupPage/WebDAVSettingsPage）将 `private get tokens()` 改为普通方法 `resolveTokens()` |
| 2 | 标题编辑后返回丢失 | 路由返回时 TextInput onBlur 不保证触发，且无兜底 | NotePage 加 `aboutToDisappear` 兜底保存 + Back 按钮先 `await saveTitle()` 再返回（消除与 onPageShow 的读写竞态） |
| 3 | 返回 LibraryPage 列表不刷新 | 无 onPageShow；且 @State 持有 @Observed 对象时内部属性变化不触发 UI 刷新 | 加 `onPageShow`：`loadNotes().then(() => this.viewModel = vm)`（重新赋值强制刷新）+ refreshThumbnails |
| 4 | 模板面板（bindPopup）渲染为空 | `bindPopup` 同时传 `message` 与 `builder` 时 message 优先、builder 被忽略 | 移除 message，builder 改经 @Builder 方法承载 |
| 5 | 切换模板/尺寸后画布不重绘 | `currentPage` 是 @Prop 无 @Watch | 加 `@Prop @Watch('onPageChange')` → renderFrame |
| 6 | 纸张尺寸/方向不参与画布渲染（总是铺满） | PaperRenderer 无纸张尺寸参数 | PaperRenderer.renderBackground 加 paperWidthMm/paperHeightMm（1mm≈3.78px），纸张居中绘制、纸外铺页面背景色；drawLines/Grid/Dots 支持偏移 |
| 7 | "适应宽度"固定 800px 基准 | zoomFitWidth 不看纸张尺寸（横向 A4 下 zoom 2.72 纸张超宽） | 基准改为 `currentPage.widthMm * 3.78` |
