# 修复总结 — Phase 496 图片裁剪按钮共享租约修复

## 问题

图片裁剪的关闭、重置和确认按钮已有响应式禁用，父页回调也有防线；但组件内点击直接转发，
缺少与其他覆盖层一致的组件内第二层拒绝。

## 修复

三个按钮回调先通过 `controlsEnabled` 拒绝租约激活状态，再执行原有转发。按钮布局、可访问性
文本、选区几何、确认事务和历史语义全部保留。

## 影响与验证

- 新增 ADR-0468，并在既有 Harmony evidence 文件追加本阶段增量段。
- 扩展已打开裁剪共享租约专项 Replay 锁定三项新防线，当前 `TOTAL=14 FAILED=0`。
- ArkTS 目标无错误，仅既有警告与信息级提示。
- 相邻图片裁剪共享租约与本地图片裁剪出界 Replay 通过。
- 全量 Desktop Replay `REPLAY_FILES=421 PASSED=421 FAILED_FILES=0`
  （35.720 秒）；clean 3.611 秒、ohosTest HAP 11.619 秒、default HAP 35.182 秒均静态构建成功。
- 未启动模拟器、虚拟机、真机或 Hypium；T-042 继续保留为 Goal 最后任务。
