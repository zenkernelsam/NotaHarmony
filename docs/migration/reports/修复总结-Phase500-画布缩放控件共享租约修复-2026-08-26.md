# 修复总结 — Phase 500 画布缩放控件共享租约修复

## 问题

画布缩放条的缩小、放大和适配宽度按钮只有响应式禁用；晚到点击可在共享导入收口窗口中绕过
组件边界并改写视口。

## 修复

三个按钮回调先通过 `photoImportBusy` 拒绝共享导入租约，再执行原有缩放流程。布局、可用性、
缩放范围、适配宽度计算和历史持久化语义全部保留。

## 影响与验证

- 新增 ADR-0472，并在既有 Harmony evidence 文件追加本阶段增量段。
- 扩展既有视口续体共享租约 Replay 至 13 项，当前通过。
- ArkTS 目标无错误，仅既有警告与信息级提示。
- 全量 Desktop Replay `REPLAY_FILES=421 PASSED=421 FAILED_FILES=0`
  （34.271 秒）；clean 3.243 秒、ohosTest HAP 10.027 秒、default HAP 30.616 秒均静态构建成功。
- 未启动模拟器、虚拟机、真机或 Hypium；T-042 继续保留为 Goal 最后任务。
