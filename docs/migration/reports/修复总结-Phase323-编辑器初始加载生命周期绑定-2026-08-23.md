# Phase 323 修复总结：编辑器初始加载生命周期绑定

日期：2026-08-23（Asia/Shanghai）

## 缺陷与修复

- `NotePage.loadPages()` 在多个 await 后没有生命周期检查；快速进入并退出编辑器时，过期加载可继续写入已销毁状态、为已关闭笔记创建 fallback 页面或弹出失败 toast。
- 现在新增 `pageLoadGeneration`：销毁入口和每次加载开始都递增；note 元数据后、页面物化后、catch 路径和 finally 状态重置前均检查代数。
- 过期续体立即返回，不触碰页面/标题/背景/录音状态，不创建恢复页，也不弹 toast；持久化数据保持权威，后续编辑器实例正常加载。
