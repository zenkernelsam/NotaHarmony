# 修复总结 — Phase 553 原版文件夹专属错误提示（2026-09-22）

## 原版行为

`sad.java`/`xdb.java`：文件夹创建与移动深度超 6 层抛
`MaxFolderDepthExceededException` → toast "Notability is limited to 6 levels
of folders."；非法名/同级重名抛 `InvalidFolderNameException` → toast
"A folder already exists with this name, or this name contains invalid
characters."。其余失败走通用提示。

## 本次改动

- `FolderRepositoryImpl.ets`：新增 `MaxFolderDepthExceededError` 与
  `InvalidFolderNameError` 类型化错误；`createFolder`/`validateFolderMove`
  两处深度抛出与 `validateFolderName` 两处名称抛出全部改为类型化。
- `LibraryPage.ets`：新增 `folderErrorToastRes` 映射，建/改文件夹提交、
  `moveFolder`、拖拽落点解析三个 catch 面统一按错误类型弹原版文案；
  生命周期与 busy 守卫不变。
- 双语字符串：`error_max_folder_depth`（EN 用原文）、`folder_name_error`
  （EN 用原文）。
