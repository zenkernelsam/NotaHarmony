# 修复总结 — Phase 461 历史重置共享租约修复

## 问题

历史损坏恢复对话框可在照片导入释放内部历史租约但尚未收口共享租约时确认重置。
重置会清空内存撤销栈并执行持久历史重置事务，与照片结果合并竞争。

## 修复

历史重置请求与执行入口都在内部历史门禁前拒绝照片导入租约；对话框仍通过唯一
request 入口调用。恢复提示、失败保留、生命周期绑定和 finally 释放不变。
