# 修复总结 — Phase 450 跨页历史失败选页恢复修复

## 问题

跨页 Undo/Redo 在目标页加载失败后会用快照还原源页，但恢复父级选页的
`onRequestPage(fromPageId)` 在 `onPageHistorySettled(false)` 之前发出。父页仍处于
原命令的 `historyPending` 租约中，因此拒绝恢复请求，导致父级选中失败目标页、
Canvas 已显示源页的状态分叉。

## 修复

仅在确实需要恢复源页时，先把残留的 `pendingHistoryDirection` 清零并发布
`onPageHistorySettled(false)`，让父页历史租约先行收口，随后调用
`onRequestPage(fromPageId)`。catch 末尾的残留方向守卫保留，用于非历史失败路径；
正常 resume、成功提交和终态失败释放语义不变。
