# Phase 353 修复总结：资料库搜索生命周期绑定

日期：2026-08-24（Asia/Shanghai）

## 缺陷与修复

- 资料库搜索 debounce 回调缺少 lifecycle generation；页面销毁后迟到回调仍可启动 ViewModel 查询，
  迟到失败还会向已离开页面弹出搜索失败 toast。
- 定时器触发时捕获 lifecycle generation，并在发起查询前校验 pageActive、lifecycle、请求代数和文本。
- `isCurrentNotesRequest()` 增加触发时生命周期身份；成功发布和失败 toast 都必须匹配该身份。
- 既有 ViewModel/query/folder/request 去重契约不变，durable 数据保持权威。
