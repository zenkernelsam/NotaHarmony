# Phase 415 修复总结：选区样式工具栏上下文绑定

## 问题

选区激活后，Canvas 能把已有笔迹的颜色、宽度、宽度范围和“是否允许 Taper”回传给工具栏，但没有回传当前 Ink 样式。
`selectionInkStyle` 初始化为 FIXED_WIDTH 且只被用户点击改变，因此选中 Dash、Dot 或 Taper 后，四个样式按钮都不高亮，
也无法反映真实上下文。

## 修复

对照 1.0.3 `dhb.java` 的 `t16 → y31` 反向映射：

- 新增 `inkStyleToBrushStyle()`，保持 FIXED/MONO、VARIABLE/Taper、DASH、DOTS 双向一致。
- Canvas 在同一个 selection-controls 回调中提取第一个非 partial 笔迹的 `renderSpec.inkStyle`。
- NotePage 将该样式写回状态，并以 `selectionStyle` 传入 EditorToolbar。
- 选区样式按钮按上下文高亮；Taper 可用性门禁不变。

## 边界

- 只绑定 UI 上下文，不改持久化字段、历史操作或批量样式修改算法。
- 混合选择沿用既有“第一个合格笔迹”策略；该策略同时已用于颜色和宽度。
- Shape-only 选择不会触发本回调，也不伪造 Ink 样式。

## 验证

- ArkTS 检查四个触点均无错误；项目既有 warning/info 保持不变。
- 新增专项 Replay 覆盖原版反向映射、回调签名、partial 过滤、首笔迹策略、铅笔禁用和页面状态同步。
- 全量 Desktop Replay `REPLAY_FILES=370 PASSED=370 FAILED_FILES=0`。
- clean 4.855 秒、ohosTest HAP 8.725 秒、default HAP 51.827 秒均静态构建成功；未启动模拟器、虚拟机、真机或 Hypium。
