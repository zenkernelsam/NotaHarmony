# Phase 388 修复总结：普通粘贴失败销毁绑定

日期：2026-08-25（Asia/Shanghai）

## 缺陷与修复

- 补审发现 NoteCanvasView 普通粘贴 deferred flush 的成功续体缺少 lifecycleActive，迟到成功可在销毁后清除
  旧页 saveFailed；失败续体也遗漏该门禁，迟到失败可调用 reportSaveFailure() 并弹旧 UI toast。
- 现在成功与失败续体统一复用 isHistoryPageContextCurrent(generation, pageId)，陈旧态静默返回；失败仍先写
  durable hilog。
- 同步入队失败、剪贴板提交、状态发布、撤销历史、渲染和图片刷新语义不变。
