## 修复前真实缺陷

### Shape 富寄存器会丢失

`ShapeElement`、CREATE_SHAPE encoder、ModifyShape reducer、持久 metadata、自有包、Clipboard 和 Partial Eraser
对 Tape、smart-highlight、force、effect、tint 的覆盖不一致。保存重启、复制或 Shape→Ink 残片可能静默改变外观。

### CREATE_SHAPE table 和校验不完整

旧 encoder 没有完整发出 18 字段/8-byte alignment，uint64 effect、force/tint、布尔 canonical、Polygon/LINE 定义和
effect coupling 缺少一致门禁。ModifyShape 还可能在最终组合验证前写部分 journal。

### Pencil/曲线 Shape 渲染不等价

Shape renderer 只覆盖普通 Canvas border；Pencil Shape 没有原版散布和确定性 seed。Ellipse/Polygon/LINE 没有一套
共享的原生 verb 几何。带箭头的 quadratic/cubic LINE 又通过 64 个采样点重组可见主干，产生与原版 PathMeasure
不同的固定折线。

## 实际修改

### 完整模型、CREATE/MODIFY 与持久化

- Shape 新增并全链保留 `originalTapePattern/originalSmartHighlight/originalForce/originalInkEffects/
  originalInkEffectsTinted`。
- CREATE_SHAPE encoder 改为完整 18-field、84-byte object、8-byte alignment；effect 使用 canonical uint64
  十进制字符串。
- encoder、reducer、persistence 与 `NotePackageSpec` 统一拒绝非法 color/fill/style/Tape/force/effect/tint、短
  Polygon 和坏 LineDefinition。
- ModifyShape 先解析/apply 所有 LWW winner，再统一验证 resolved state，成功后才写 modification journal。

### 识别、Clipboard 与 Partial Eraser

- VARIABLE_WIDTH Ink 被识别为 Shape 时降级到原版合法 FIXED_WIDTH=1，并保留单 Shape reserved create identity；
  不再制造原版 wire 与自有包都拒绝的 style=0 Shape。
- Clipboard 保留 Tape/force/effect/tint，只重置 smart-highlight 和 reserved identity；legacy create force 先提升为
  稳定 register。
- Shape Partial Eraser 转换到 Ink 时保留 force、Tape、effect 和 tint，继续使用既有 Group replacement、层序与
  Undo/Redo 事务。

### 语义 Path、Pencil 与 renderer

- 新增纯逻辑 `ShapeStrokeGeometry.ets`：LINE 保留 line/quadratic/cubic，Ellipse 使用四段 rotated cubic，Polygon
  按原版 ShapeDefinition 闭合。
- 箭头弧长仍由有界采样定位参数，但随后用 de Casteljau 截取原始 quadratic/cubic；主干不再以采样折线进入 Canvas
  或 Pencil walker。
- Pencil Shape 对每个主干/箭头子路径重置 `1544949492`，消费保存 force；缓存为 32 项/262144 splat LRU，几何或
  width 变化失效。
- 主画布、held Shape 与缩略图共享同一 Shape renderer；两种 renderer dispose 都清 Pencil cache。
- Highlighter Shape 使用原版 alpha 107。
- 最终人工复核纠正早期实现：Shape 的 Tape register 继续保存，但 Shape 本体恢复普通中心线，不再额外调用
  `renderTapePattern()`；Partial Eraser 产出的 Ink 仍可消费 Tape register。

## 边修边审发现并修复

- 第一版带箭头 cubic 复用了 `lineRenderGeometry()` 的 64 段 polyline，普通 Canvas 会真的画出折线；现增加原始
  Bezier 参数裁剪 fixture。
- 第一版把 VARIABLE_WIDTH 映射为 style=0，和 `ao2` 及本地 package validator 冲突；现改为 style=1 并保留
  reservation。
- default HAP 的严格 ArkTS 编译发现 Shape Pencil catch 路径会抛任意类型；现只直接重抛 `Error`，其余值包装为
  `Error`，不再触发 `arkts-limited-throw`。
- 一组既有源码型 replay 对 CRLF 敏感，或用 URL pathname 手工处理带空格 Windows 路径；统一在读取后规范换行，
  资源路径改用 `fileURLToPath()`，避免工作树位于 `Cisco He` 路径时产生伪失败。
