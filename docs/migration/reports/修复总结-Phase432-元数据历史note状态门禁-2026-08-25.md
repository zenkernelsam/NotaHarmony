# 修复总结：Phase432 元数据历史 note 状态门禁（2026-08-25）

## 问题

Phase 431 补审发现，NOTE_METADATA 虽然当前没有生产 UI caller，但持久化层与撤销栈仍保留其
历史恢复路径；它继续使用通用页面历史入口，无法感知页面操作或标题保存等共享 note 状态变化。

## 修复

- 为 NOTE_METADATA 增加 `onApplyNoteMetadataHistory()` 独立入口。
- 页面操作进行中或标题保存飞行中直接拒绝，避免未来 note-level SET_METADATA 队列恢复后
  出现同类竞争。
- 其他页面动作继续走通用入口；导航租约由 Phase 429 成功/失败续体统一释放。

## 证据与回放

- 新增 ADR-0404 说明“显式 note-state 门禁优先于依赖无 caller”的决策。
- 新增 Harmony evidence 固定源码顺序、缺口和断言。
- 新增专项 Replay 3/3；相邻标题与页面历史回放通过。

## 运行态边界

未启动模拟器、虚拟机、真机或 Hypium；T-042 保持 Goal 最后任务。
