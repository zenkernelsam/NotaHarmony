# 修复总结 — Phase 459 选区菜单按钮共享租约修复

## 问题

选区菜单可在照片导入前保持展开。导入窗口内 DELETE/CUT 等变更会被统一入口拒绝，但 COPY 可
基于尚未包含照片结果的元素数组准备并发布剪贴板快照，造成后续粘贴来源过期。

## 修复

选区菜单按钮新增启用条件，照片导入、历史忙、页面异常或页身份不一致时禁用；统一入口守卫继续
作为第二层防御。剪贴板格式和各 action 逻辑不变。
