# Phase 349 修复总结：备份页长事务销毁绑定

日期：2026-08-24（Asia/Shanghai）

## 缺陷与修复

- `BackupPage` 的本地导出/导入、WebDAV 云备份/云恢复会跨越数据库、文件系统或网络 await；页面没有销毁守卫，
  用户返回后迟到续体仍可改写状态、更新上次备份展示或弹对话框/toast。
- 新增 `pageDisposed` 与 operation lifecycle generation；九个关键续体在发布前检查完整生命周期身份，过期路径直接返回。
- 既有 `finally` 保持不变：共享备份操作租约继续释放，busy/status 正常复位。durable 导入导出、远端批次与
  上次备份时间保持权威。
- 本地加载路径也补上 `pageDisposed`，防止销毁后迟到初始化覆盖配置摘要。
