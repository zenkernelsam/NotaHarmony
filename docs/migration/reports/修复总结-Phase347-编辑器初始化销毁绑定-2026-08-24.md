# Phase 347 修复总结：编辑器初始化销毁绑定

日期：2026-08-24（Asia/Shanghai）

## 缺陷与修复

- `loadPages()` 的失败路径只检查页面加载 generation；初始化在销毁边界后失败时，迟到续体仍可清空 pages/background/recordings、设置 `pageLoadFailed` 并弹出打开失败 toast。
- 失败路径现在同时检查 `editorDisposed`；销毁后的迟到失败直接返回，不再重置状态或发布用户可见错误。
- 成功路径生命周期行为保持不变；durable 初始化效果保持权威。
