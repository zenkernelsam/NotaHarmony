# Phase 550：原版内容管理器“清空页面”

日期：2026-09-22

## 选题

原版内容管理器（`n9j` 工具栏 / `tfh` 每页表单）暴露 Clear Page：
删除该页全部元素、保留页面本身、无确认（撤销栈回退）。Harmony
紧凑页面菜单只有页面级操作，缺内容清空入口。

## 原版现场重放

- `n9j.java` 工具栏与 `tfh.java` 每页表单均携带
  `feature_note__content_manager_clear_page` +
  `ui_designsystem__clear_page`；`tfh` 顺序 Bookmark → Clear Page。
- `strings.xml` 标签 "Clear Page"；`content_manager_*` 命名空间
  无确认文案。

## Harmony 落地

- `PageManagerBar` 菜单在 Bookmark 与 Delete Page 之间新增
  Clear Page，沿用 `busy || photoImportLeaseActive` 守卫。
- `NotePage`：`clearPageSignal` 信号（同 undo/redo 模式）。
- `NoteCanvasView.clearCurrentPageContent()`：按 `elementOrder`
  枚举当前页全部元素分桶（STROKE/SHAPE/TEXT/IMAGE/MATH），
  `selectElementIds` 全选后复用 `onSelectionMenuAction(DELETE)`
  ——撤销、历史、持久化、图层重建全部走既有删除管线；空页无操作。
- 双语言 `clear_page`（EN "Clear Page" / zh "清空页面"）。

## 验证

- `d02-original-content-manager-clear-page.mjs`：25 断言全过
  （含 elementOrder 分桶可执行模型）。
- 全套 replay 通过；`d02-page-bar-shared-lease-bound.mjs`
  fail-closed 计数锚点 10→11 随 `onClearPage` 回调登记更新。
- `note@default` + `note@ohosTest` BUILD SUCCESSFUL。

## 登记差异

- 原版作用于内容管理器勾选的页集合；Harmony 作用于当前页
  （无多选页模型）。
