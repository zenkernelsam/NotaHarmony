# 修复总结 Phase 561 — 原版笔记视图隐藏系统栏设置

日期：2026-09-22

## 原版证据

`decompiled_1.0.3` 的 `r22.java` case 3/4 在 note-editor 设置区渲染
两个沉浸开关：

- `feature_settings__hide_status_bar` = "Hide status bar in note view"
- `feature_settings__hide_navigation_bar` = "Hide navigation bar in
  note view"

运行时应用（WindowInsets/systemUiVisibility）在 native/混淆代码中，
反编译面不可见；可移植契约 = 双开关持久化 + 笔记视图内生效。

## Harmony 落地

- `EditorSettingsStore.ets`：新增 `hideStatusBar`/`hideNavigationBar`
  pref，接口加四个方法；共沉淀 `getBooleanPref`/`saveBooleanPref`
  助手，保留 mutex + flush 失败回滚语义；默认关（无原版真值表，
  登记）。
- `SettingsPage.ets`：Note editor 区再加两行开关，各自走同一
  乐观更新 + 回滚 + 生命周期守护模式。
- `NotePage.ets`：`aboutToAppear` 调 `applyHideSystemBarsSetting`
  读两项 pref，`setSpecificSystemBarEnabled` 应用——`status` 对应
  状态栏；`navigation` + `navigationIndicator` 合并对应原版单一
  导航条开关（三键/手势两种实现各自独立降级）；`aboutToDisappear`
  恢复已隐藏的栏；独立 `systemBarsGeneration` 防竞态。

## 字符串

`hide_status_bar` = "Hide status bar in note view" / "在笔记页面隐藏
状态栏"；`hide_navigation_bar` = "Hide navigation bar in note view" /
"在笔记页面隐藏导航条"（英文取原文）。

## 登记差异

- 原版默认值无证据，取关（沉浸为 opt-in）。
- HarmonyOS 区分 navigation（三键）与 navigationIndicator（手势），
  合并映射到原版单开关，各自独立降级。
- 按窗口生效；离开编辑器即恢复，即使后续应用失败。
