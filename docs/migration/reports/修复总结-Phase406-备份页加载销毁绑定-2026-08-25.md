# Phase 406：备份页加载销毁绑定

日期：2026-08-25（Asia/Shanghai）

## 问题

`BackupPage.reloadPage()` 在数据库初始化和 WebDAV 配置读取后直接发布配置与 READY。原门禁没有捕获页面生
命周期代际；面板销毁后的旧续体仍可覆盖配置。catch 与 finally 也只按加载代判断，已换代续体可错误回写 ERROR，
或把新加载提前标记为 initialized。

## 修复

- 加载开始前捕获 `expectedLifecycleGeneration`，`aboutToDisappear()` 递增该代际。
- 新增 `isStaleReload()` 联合检查销毁、生命周期代和加载代。
- 成功、失败和 finally 均使用统一门禁：无效续体不发布 READY/ERROR，也不污染 `initialized`。
- 备份导出、导入、云端备份与恢复的既有 lease 和 stale 门禁全部不变。
