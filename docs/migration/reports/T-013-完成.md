## 改了什么

创建 2 个渲染层文件：

1. `note/src/main/ets/rendering/DirtyRectTracker.ets`

2. `note/src/main/ets/rendering/StrokeLayerManager.ets`

     - composite()：脏区 clipRect 限制重绘 → clearRect 脏区 → transferToImageBitmap 后 drawImage 主画布（随即回写恢复层内容）→ 渲染当前笔画；无脏区且无当前笔画直接 return
     - clearAll() / rebuildFromStrokes()（擦除/撤销后逐笔重建）/ isInitialized()
     - renderStrokeOnto()：按 renderSpec 分发（Pencil→splat / VARIABLE_WIDTH→轮廓 / 其他→中心线），随后应用擦除遮罩
