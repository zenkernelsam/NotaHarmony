# Phase 393：图片入口启动状态绑定

日期：2026-08-25（Asia/Shanghai）

## 问题

相册插入与系统剪贴板粘贴都是异步 UI 边界，但启动谓词没有检查画布销毁态和页面身份一致性。离开或切换页
面边界上的迟到信号仍可能打开系统照片选择器、请求剪贴板读取权限或占用 `photoImportBusy`。

## 修复

- `canStartOriginalPhotoInsert()` 与 `canUseOriginalClipboardImage()` 增加 `lifecycleActive`。
- 两者同时要求 `loadedPageId === currentPage.pageId`。
- 其余加载健康、忙碌冲突、持久化就绪和剪贴板缓存检查保持不变；迟到续体仍沿用完整页面上下文门禁。
