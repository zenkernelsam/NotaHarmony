# Phase 117 修复总结：原版选区 Ink 颜色与宽度出站

## 原版证据与边修边审

- 直读原版 `wj9/zn3/u5j/o0j`，确认选区颜色按 Highlighter 与普通 Ink 分组：Highlighter 强制
  alpha 107，普通 Ink 强制 alpha 255；Pencil 不在颜色路径排除名单。Shape 另走 type-23。
- 直读 `dhb/fsc/ks0/w4g/aa6`，确认选区宽度按 Ink tool 类型分组；Pen/Highlighter 为
  `0.5..30`、Pencil 为 `1..10`、Tape 为 `2..64`，持久值为 UI 值乘 `pageWidth / 768`。
- `u5j.q -> o0j.a` 证明 type-17 的 color/width 分别是 fields 6/7；只有 style present 时才写
  field 12 空 styleMap，color-only/width-only 不得夹带该字段。
- 边修边审发现 Pencil 不能只改 `brushWidth`：原版每次从完整中心路径、winning width 和
  styleMap seed/reference 重建 splats。又发现用旧 world bounds 增减 padding 虽数学等价，但浮点运算
  次序会令大多数序列化值不同，因此改为恢复原始 quadratic 控制点并按 reducer 顺序完整重算 bounds。
- 全量 replay 还发现 Phase 109 的旧门禁只接受 `.apply()`；多 register 批次现需共享
  `applyPositionPayload + OriginalPageMutationBatch`。已更新旧 replay，继续锁住单次 revision，而非放宽生产逻辑。

## 已完成修复

- Selection 模式复用现有颜色/宽度弹层，但命令与 drawing preset 完全分流。Toolbar 从选区首个有效 Ink
  同步颜色、宽度及原版工具范围；Tape 的 36/42/48/64 不再被固定 30 上限截断。
- 一次颜色或宽度命令批量 clone 选中 Ink、写一个 `TRANSFORM_STROKES` before/after、一次 persist 和一次
  redraw。partial-eraser 继续排除；颜色对 Highlighter/普通 Ink 分别规范 alpha；宽度逐 Tape/Pencil/其他 Ink
  clamp，再按纸宽换算。
- 新增纯 `OriginalPencilWidthGeometry`。Pencil 使用现有 `PencilSplatGenerator`、稳定 seed/reference 和新 width
  重建完整 splat；从 cubic 精确反演原版 float32/half quadratic 控制点，合并 custom/fill 控制凸包，再按
  `2.84` Pencil multiplier 与 transform 重算原版 bounds。Canvas 与 classifier 共用同一 authority。
- `StrokePersistence` 的严格 type-17 classifier 扩展到 style/color/width，完整 persisted bytes 比较拒绝夹带
  变化；Pencil width 也必须 splat/bounds 精确一致。目标按最终 register tuple 分批，因此正向混合 alpha、
  tool clamp 和 Undo 恢复不同旧值均可继续使用原版出站，而不会无故 fallback。
- 每批分配 canonical identity、写完整 `uq9` 和 upload-immediate operation；所有批次共享一个 page mutation
  batch，只 flush 一次 revision。snapshot reconciliation、Harmony history companion 与全部批次处于同一事务，
  任一 reducer defer、journal/history/reconcile 失败整体回滚。
- 修正 ADR-0086 的历史边界，明确 Phase 117 已建立 color/width 生产调用证据与接线。
