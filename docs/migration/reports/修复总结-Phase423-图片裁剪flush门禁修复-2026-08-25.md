# 修复总结：Phase423 图片裁剪 flush 门禁修复（2026-08-25）

## 问题

Phase 422 后边修边补审发现，图片裁剪是绑定当前页的模态临时状态，但 `flushCurrentPage()` 只阻断
Math 编辑。若用户在裁剪浮层存在时触发删除当前页，删除流程 await flush 后可能继续快照并 prepare removal，
造成裁剪中的页被异步删除。

## 修复

将当前页 flush 的临时编辑器门禁改为：

```ets
if (this.mathEditorVisible || this.imageCropVisible) {
  return false;
}
```

该返回发生在任何 flush 副作用之前。图片裁剪确认成功后仍按既有路径恢复 `imageCropVisible=false`，
后续 flush 不受影响；取消与页面切换语义不变。
