# Phase 161 修复总结：系统备份文本精确字节视图

## 发现

系统 Backup Ability 写状态/manifest 文本时直接使用编码结果的底层 buffer，存在写出非有效视图字节的边界风险。

## 修改

- `note/src/main/ets/notebackupability/NoteBackupAbility.ets`
- 新增 `ADR-0138-backup-text-exact-byte-view.md`
- 新增 `d02-backup-text-exact-byte-view.mjs`

编码结果现在只以 `byteOffset..byteOffset+byteLength` 的精确范围写入，文件关闭和备份语义保持不变。

## 验证

- Replay：`TOTAL=5 FAILED=0`
- `note@default assembleHap`：`BUILD SUCCESSFUL`
- `note@ohosTest assembleHap`：`BUILD SUCCESSFUL`
- 未启动设备、模拟器、虚拟机或 Hypium。
