# 修复总结 — Phase 447 照片导入页面结构租约修复

## 问题

照片 Picker 的 URI 复制与字节解析是长时任务，期间 Canvas 只持有私有
`photoImportBusy`。父页的页面结构操作看不到该状态，因此新增、删除、移动或
背景修改可能在导入完成前启动；反过来，页操作加锁后，迟到的照片信号也可能
继续进入 Canvas。原有 generation/pageId 只能事后拦截陈旧提交，不能阻止
用户进入冲突路径。

## 修复

引入父页持有的共享照片导入租约。工具栏在所有页操作和历史门禁通过后先占
租约再发信号；`NoteCanvasView` 的照片 Picker 与剪贴板图片 ingress 在
`finally` 统一释放。`runPageOperation()`、`onRequestPage` 和页导航在入口
检查该租约，使两类长时操作严格互斥。持久化层的 stale-context、
partial-success 和 history metadata 语义不变，只移除可预防的竞态入口。
