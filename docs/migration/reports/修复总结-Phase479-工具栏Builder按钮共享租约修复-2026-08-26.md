# 修复总结 — Phase 479 工具栏 Builder 按钮共享租约修复

## 问题

普通工具按钮和笔刷样式按钮回调已能拒绝共享照片导入租约，但其启用条件缺少该租约，
导入窗口内仍视觉可点。

## 修复

两个 Builder 在工具状态加载门禁外统一叠加共享导入租约禁用；回调继续作为第二层防御。
工具模型、笔刷样式模型、紧凑菜单、选区样式和保存链不变。

  default HAP 29.657 秒均静态构建成功。
