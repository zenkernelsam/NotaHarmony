# Phase 86 修复总结：Math 持久历史补链

日期：2026-08-11

基线：`7f73f8d fix(editor): complete math block interactions`

范围：Math undo/redo 的 durable page snapshot 捕获

## 边修边审发现

- Phase 85 已让 Math 进入 ADD/DELETE/TRANSFORM/ERASE 的内存 action、apply/undo 与状态校验。
- `HistoryPageSnapshot` 和 `StrokePersistence.saveHistoryGroup()` 也已经支持可选 `mathBlocks`，并会把
  initial/step Math 交给统一五类 `prepareSave()`。
- 但 `NoteCanvasView.captureHistoryPageSnapshot()` 只捕获 Stroke/Text/Shape/Image/order，没有填
  `mathBlocks`。因此 grouped undo/redo 的持久事务会把缺失字段按 `[]` 处理：数据库 source-state 校验
  可能失败，或最终 snapshot 丢 Math；此问题不会由普通增量保存或页面删除历史路径代偿。

## 实际修复

- durable history capture 现在逐个 `cloneMathElement()`，把 Math 的 transform、bounds、LaTeX、颜色及
  lock state 放入 initial 与每个 history step。
- 保持 `HistoryPageSnapshot.mathBlocks` 可选，以兼容旧 caller；新画布路径不再依赖空数组回退。
- 扩展 `d02-math-editing-consumer.mjs`，同时锁定画布 capture 和 persistence initial/step consumer，
  防止以后只修 action 而再次漏掉 durable snapshot。
