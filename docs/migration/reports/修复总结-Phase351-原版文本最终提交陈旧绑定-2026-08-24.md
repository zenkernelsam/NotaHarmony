# Phase 351 修复总结：原版文本最终提交陈旧绑定

日期：2026-08-24（Asia/Shanghai）

## 缺陷与修复

- `aboutToDisappear()` 会异步启动文本最终提交；`onTextCommit()` 在原版 Text 样式 preview await 后缺少提交级
  代数检查。销毁后或被新提交接替的续体仍可替换元素、发布历史并保存。
- 新增 `textCommitGeneration`；每次提交捕获独立代数，preview 后与元素身份、页面代数/ID 和生命周期一起校验。
- 陈旧续体现在直接拒绝，不触达内存 Ink、Undo/Redo 或持久化。非 Original 同步路径和重复提交门禁保持不变。
