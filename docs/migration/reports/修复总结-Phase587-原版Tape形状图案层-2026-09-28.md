# 修复总结 — Phase 587：原版 Tape 形状图案层（2026-09-28）

## 原版契约（证据）

- 胶带元素 = `ShapeImpl` + `tapePatternRegister`（`dm2` 校验
  tapePattern 仅属 TAPE）；渲染 = 笔带主体 + `ife` 图案层（`qfe`
  瓦片管线，与 Ink 胶带共用）；`ife=null` = 已揭示视觉。
- Harmony 缺口：导入胶带物化为 `ShapeElement`（`originalTool === 3`
  + `originalTapePattern`），`strokeShape` 只画纯色笔带，图案层缺失。

证据文档：`docs/migration/evidence/original-tape-shape-pattern-2026-09-28.md`
ADR：`docs/migration/adr/ADR-0556-original-tape-shape-pattern.md`

## Harmony 实现

- `ShapeCanvasRenderer.renderTapePatternOverlay`：`originalTool === 3`
  时在笔带之后逐 component 合成等价 `StrokeElementData`
  （`originalTapePattern ?? STRIPES`、shape 笔宽/颜色），走既有
  `renderTapePattern`；`revealedTapeIds` 命中或 PLAIN 不叠加。
- `revealedTapeIds` 会话集合与 `strokePainter` 共享同一 `Set` 实例
  （`aboutToAppear` 接线）。
- `renderShape` 增 `viewportZoom` 参数；两个调用点传
  `this.viewport.zoom`。
