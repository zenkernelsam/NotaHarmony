# 修复总结 Phase 560 — 原版保持设备常亮设置

日期：2026-09-22

## 原版证据

`decompiled_1.0.3` 的 `r22.java` case 2 在 note-editor 设置区渲染
`feature_settings__keep_device_awake`（"Keep device awake"）开关，
与 `note_view_night_mode`、`hide_status_bar`、`hide_navigation_bar`
同区。Android 侧效果（前台时 FLAG_KEEP_SCREEN_ON）在 native/混淆
代码中消费，反编译面不可见——可移植契约是开关 + 持久化 + 编辑器
前台生效。

## Harmony 落地

- `EditorSettingsStore.ets`：`keepDeviceAwake` 进既有
  `noteEditorSettings` preferences；接口新增
  `getKeepDeviceAwake`/`saveKeepDeviceAwake`，沿用 mutex + flush
  失败回滚语义；默认 `DEFAULT_KEEP_DEVICE_AWAKE = false`。
- `SettingsPage.ets`："Note editor" 区第二行开关，随
  `reloadSettings` 加载，`setKeepDeviceAwakeEnabled` 走同一
  乐观更新 + 失败回滚 + 生命周期守护模式。
- `NotePage.ets`：`aboutToAppear` 调 `applyKeepDeviceAwakeSetting`
  读 pref 并 `window.setWindowKeepScreenOn(enabled)`；
  `aboutToDisappear` 已应用则清旗标；独立 generation 防竞态；
  失败仅记日志，不阻塞编辑。

## 字符串

`keep_device_awake`："Keep device awake" / "保持设备常亮"（英文取原文）。

## 登记差异

- 原版默认值无硬证据，取关（安全默认：不主动改变屏幕行为）。

  正常熄屏。
- ArkUI 等价物 `setWindowKeepScreenOn`，与 FLAG_KEEP_SCREEN_ON
  同义、按窗口生效。
