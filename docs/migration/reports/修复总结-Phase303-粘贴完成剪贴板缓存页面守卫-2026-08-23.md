# Phase 303 修复总结：粘贴完成剪贴板缓存页面守卫

## 缺陷

Phase 302 的粘贴完成重同步没有绑定发起时的页面上下文。异步授权、图像规范化或持久化插入期间切换页面后，
旧页面的 MIME probe 与插入结果会直接覆盖新页面的剪贴板可用性缓存；早期失败路径也可能误清新页状态。

## 决策与实现

粘贴入口捕获 `pageLoadGeneration` 和 `loadedPageId`。早退 probe 失败仅在页面上下文不变时清 false；授权前发现
切换立即中止。完成重同步保留最新 MIME probe 和 `insertedCount > 0` 条件，但只在 generation 与 pageId 匹配时
回写。该守卫不改变权限时机、fail-closed probe 或 busy 串行化。

## 验证

- 剪贴板专项 Replay 从 25/25 扩展至 26/26，新增“paste completion respects the captured page generation”；
- 双 HAP、全量 Replay 与静态检查结果见总进展验证补录；
- 未启动模拟器、虚拟机、真机或 Hypium。

## 开放项

真实跨页切换矩阵和厂商 pasteboard 时序仍需设备验收；`T-042` 继续严格留到 Goal 最后一项。
