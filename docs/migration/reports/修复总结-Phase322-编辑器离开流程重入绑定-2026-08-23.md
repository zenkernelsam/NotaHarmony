# Phase 322 修复总结：编辑器离开流程重入绑定

日期：2026-08-23（Asia/Shanghai）

## 缺陷与修复

- 编辑器返回按钮和返回键都可独立启动 `leaveEditor()`；标题保存等待、历史 flush、工具状态 flush、录音删除 flush、会话释放和 `router.back()` 没有共享重入守卫。
- 快速连点返回或两种返回入口并发时，多个离开协程可各自走到 `router.back()`，可能把编辑器之外的 Library 路由也弹出。
- 现在 `leaveEditor()` 用共享 `editorLeavePromise` 包装 `performLeaveEditor()`：首个调用者执行完整收尾，后续调用者等待同一 Promise。收尾顺序保持不变。
