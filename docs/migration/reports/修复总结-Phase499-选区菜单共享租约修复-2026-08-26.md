# 修复总结 — Phase 499 选区菜单共享租约修复

## 问题

选区菜单按钮和画布动作入口已有共享导入及历史防线，但组件构建菜单时没有第二层租约拒绝；
晚到菜单事件可能在租约收口窗口中先触发复制、删除、裁剪等动作。

## 修复

父页把 `photoImportBusy` 作为共享租约传入 `SelectionOverlay`。租约激活时 `buildSelectionMenu()`
立即返回空菜单，不生成任何动作；正常状态下原有动作和能力边界完全保留。

## 影响与验证

- 新增 ADR-0471，并在既有 Harmony evidence 文件追加本阶段增量段。
- 扩展选区菜单按钮共享租约 Replay 至 13 项；既有选区菜单入口 Replay 通过。
- ArkTS 目标无错误，仅既有警告与信息级提示。
- 全量 Desktop Replay `REPLAY_FILES=421 PASSED=421 FAILED_FILES=0`
  （34.016 秒）；clean 3.264 秒、ohosTest HAP 9.845 秒、default HAP 29.988 秒均静态构建成功。
- 未启动模拟器、虚拟机、真机或 Hypium；T-042 继续保留为 Goal 最后任务。
