# Phase 239 修复总结：原版 Shape 局部擦除

## 本阶段目标

在 Phase 237/238 的实体残片替换、Group replacement 与持久 Undo/Redo 基础上，补齐原版 Notability
1.0.3 的 Shape partial erase：按原生 Shape Path 分别裁切 center/custom/fill，把可见 component 物化为
CREATE_INK remnants，并让 Shape source 进入同一事务、Group 与历史管线。

## 原版结论

- `q16.e()` 优先取缓存 Android Path，缺席时由 `xai.d()` 恢复原生 LINE/ELLIPSE/POLYGON Path。
- LINE 保留 line/quad/cubic；ELLIPSE 使用 `addOval(..., CW)`；POLYGON 至少三个顶点时始终 close。
- `o1.shapeErasePaths` 把完整 center path 与独立 arrowhead 交给 `jt1/n8j`，不会把 center 提前截到
  arrow base。
- `n8j.d()` 把 eraser 逆变换到 Shape 局部坐标；center clipping 不额外扩大半个 border width。
- `n8j.e()` 分别裁 center、由 center+width+arrow 形成的 custom outline，以及仅在有 fillColor 时启用的
  fill candidate；失败表示 Unchanged，空结果表示完整删除。
- `o8j/u5j/ys2` 把每个 retained component 写成 CREATE_INK fields 9/10/11 的 center/custom/fill，
  field 12 写 nullable fill color。
- 详细 JADX 证据与恢复文件 hash：
  `docs/migration/evidence/original-shape-partial-erase-jadx-2026-08-15.md`。

## 已完成修复

1. 新增 `OriginalShapePartialEraser.ets`，主几何使用 ArkGraphics2D `drawing.Path`、`Pen.getFillPath()` 与
   `Path.op(DIFFERENCE/INTERSECT/UNION)`，不复用渲染层采样折线或普通 Ink `EraserEngine`。
2. Shape center 与原版 `xai.d()` 对齐：
   - LINE 使用原生 line/quad/cubic verb；
   - ELLIPSE 从右侧起点按 CLOCKWISE `addOval`，并用 `Matrix.setRotation()` 绕局部中心旋转；
   - POLYGON 至少三个顶点时始终 close，legacy `isClosed=false` 不再漏掉 closing edge。
3. SINGLE arrow 按 `d1j/l96.W` 的分段宽度公式生成独立 triangle；center 始终保留到 tip，只擦 arrow
   wing 不会缩短主线。
4. eraser 先逆变换到 Shape 局部坐标。center 以 `Path.getLength/getPositionAndTangent/getSegment`
   提取 retained runs，边界二分 20 次；只按 eraser fill 判断，不增加 Shape border 半宽。
5. 二次、三次 LINE 裁切后继续物化为 cubic CREATE_INK center segments。闭合 center 的首尾 retained
   run 会合并；Dash/Dots remnant phase 从原 center 起始距离继续。
6. ELLIPSE/conic 的 boolean 与 clipping 全程保留原生 Path。Harmony PathIterator 不暴露 rational
   weight，因此最终 center/custom/fill 序列化遇到 CONIC 时统一使用误差 `0.05` 的 `Path.approximate()`；
   多 contour 的同 fraction 断点恢复为独立 MOVE，禁止把 conic 错写为 weight=1 quadratic。
7. outline 从完整 center 与 border width 生成并 union arrowhead；fill 只在非 LINE 且 `fillColor != null`
   时存在。可见 component 分别获得 center fragment、clipped custom outline 与 clipped fill。
8. Shape remnant 继承 transform、z-index、tool/style/color/fill、Pencil seed、Dash/Dots phase、Tape/
   Highlighter 标志；bounds 同时纳入 cubic control points 和 auxiliary path。
9. `OriginalCreateInkPayloadEncoder` 新增完整 20-field CREATE_INK table，编码 fields 10/11 auxiliary path、
   field 12 fillColor，并保留无 auxiliary path 时旧 compact layout 的 byte stability。
10. `OriginalInkPathEncoder` 新增多 MOVE、unattributed BITS_32 auxiliary path 编码，严格限制命令点数、
    finite 坐标与原版 65,535 element 预算。
11. partial-erase plan 泛化为显式 `sourceKind: STROKE | SHAPE`。持久提交会校验 Shape snapshot/z-index，
    按 `CREATE_INK → MODIFY_GROUP → DELETE_ENTITIES` 提交，并验证最终 snapshot、Group 与单 revision。
12. UI 同一擦除手势合并 Stroke 与 Shape replacement，按原页面 mixed element order 排序。事务失败的
    本地 fallback 同样替换 Shape、插入 Ink remnants、更新 Group，并支持混合 Undo/Redo。
13. NPE2/page-mutation validator、持久 Undo/Redo 与本地 history validator 均接受 Shape source，但所有
    remnants 仍严格是 Ink；旧 stroke-only action 与 NPM1 继续兼容。
14. 失败安全：奇异矩阵、Path op/iterator/segment 失败、超过 131,072 center samples、超过原版 path/
    component 预算都保持 Unchanged，不能因无法证明裁切结果而删除 Shape。
15. 边修边审额外捕获并修复：
    - custom/fill CONIC 曾被误当普通 QUADRATIC；现改为最终受控近似；
    - Polygon 曾错误受 `isClosed` 门禁；现与 `xai.d()` 一律闭合；
    - clean default 主模块发现 `drawing.Matrix.rotate()` 并不存在；现使用 SDK 正式 API
      `Matrix.setRotation()`。
