# Phase 330 修复总结：录音时间线跳转销毁绑定

- `seekRecordingTimeline()` 在控制器 load await 后没有生命周期检查；编辑器销毁过程中发起的跳转可对已释放
  控制器驱动 load。
- 现在入口检查 `editorDisposed`：销毁后不定位时间线目标、不做同录音 seek，也不发起跨录音 load。
