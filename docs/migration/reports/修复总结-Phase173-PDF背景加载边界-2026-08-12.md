# Phase 173 修复总结：PDF 背景加载边界

## 发现

`PdfBackgroundLoader` 依赖上游模型校验，只检查目标页不大于 PDFKit 页数。独立调用时，负数或非整数页索引可进入 native `getPage()`；本地 PDF 被截断或替换时，也只会核对数据库记录而不会核对实际文件大小。

## 原版依据

1.0.3 `ddg.java:f(sw9)` 要求 PDF 总页数大于 0，且消费页区间不得超过总页数。移植侧保留该模型约束，并在 loader 边界额外防御 native API。

## 修改

- `note/src/main/ets/core/adaptation/PdfBackgroundLoader.ets`
- 新增 `ADR-0150-pdf-background-load-boundaries.md`
- 新增 `d02-pdf-background-load-boundaries.mjs`

loader 现在先拒绝非法总页数、目标页和文件大小；本地路径必须指向大小精确匹配的普通文件。PDFKit 解析后只读取一次页数，并在取页前验证页数为正安全整数且与 metadata 完全一致。
