# Phase 551：原版库未索引笔记横幅与说明对话框

日期：2026-09-22

## 选题

原版 `flc` SearchIndexingState 驱动 `elc.a` 横幅（all-indexed /
indexing-N / N-unindexed + Learn More）与 `n32` 说明对话框；未索引
笔记不出现在搜索。Harmony 已有 `search_item` 维护与 EXISTS 搜索
过滤，但没有"未索引"用户可见表面。

## 原版现场重放

- `flc` = indexingNotes + queuedNotes + neverIndexedNotes 三集合。
- `elc.a`：`c()==0` → "All notes indexed"；进行中 → "Indexing %d
  notes" + 进度；否则 → "%d Unindexed Note(s)" + Learn More。
- `n32`：Learn-more 对话框 = `unindexed_notes` 标题 + "If the note
  causes the app to crash, it will be unindexed. Unindexed notes
  will not appear in search." + Close。
- 承载面：`yj9`/`hof` 多选工具栏内的 "Index Notes" 底部表单；
  `vmc` 后台索引器重排滞留笔记。

## Harmony 落地

- `NoteRepository.countUnindexedNotes()`：`deleted_at IS NULL` 且
  `NOT EXISTS (search_item)`——正常保存必写 TITLE 行，零行即
  neverIndexed。
- `LibraryViewModel.unindexedNoteCount` 随 `loadNotes` 刷新。
- `LibraryPage` 列表上方横幅（计数>0）：单/复数双变体 +
  Learn More → `UnindexedNotesDialog`（原版标题/正文/Close）。

## 验证

- `d02-original-unindexed-notes-banner.mjs`：22 断言全过（含
  横幅分支可执行模型）。
- 全套 replay 通过；`note@default` + `note@ohosTest` BUILD
  SUCCESSFUL。

## 登记差异

- 原版承载于多选 "Index Notes" 表单（含 unindexed 列表）；
  Harmony 无多选模型，横幅置于列表上方。
- indexing/queued/进度态与 "All notes indexed" 不移植（同步索引）。
