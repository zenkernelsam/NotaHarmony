# Phase 336 修复总结：录音失败 UI 销毁绑定

日期：2026-08-23（Asia/Shanghai）

## 缺陷与修复

- `showRecordingFailure()` 无条件显示权限对话框和 toast；编辑器销毁后送达的失败仍可对已移除页面显示 UI。
- 处理器入口检查 `editorDisposed`；销毁态跳过权限对话框和保存/启动失败 toast。失败序列仍由快照路径权威持有。
