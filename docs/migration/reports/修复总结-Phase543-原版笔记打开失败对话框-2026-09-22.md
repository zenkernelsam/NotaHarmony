# Phase 543：原版笔记打开失败对话框

日期：2026-09-22

## 选题

原版 `u49` 按 `vc9` 失败态渲染终态 AlertDialog（load_failed /
download_failed / access_denied / note_deleted），按钮与外侧取消
共享 dismiss 回调返回上一页。Harmony 此前为内联文本 + 自造 Retry
+ toast——无失败分类，且重试入口非原版语义。

## 原版现场重放

- `u49.java:25-51` `a(function0, titleRes, messageRes, buttonRes)` →
  `f2j.c` AlertDialog；`u8(function0, gl8Var, 20)` 使确认按钮与外部
  取消共用 dismiss（`gl8Var` 防重复）。
- `u49.java:401-416` 四种状态类逐项映射资源前缀：rc9 load_failed
  （"Unable to open note"/OK）、qc9 download_failed、pc9 access_denied、
  uc9 note_deleted（"Note unavailable"/Done）。

## Harmony 落地

- `pageLoadFailureKind`：'' | 'deleted' | 'failed'；`getNote` 为 null
  或 `deletedAt != null` → 'deleted'（uc9），其余异常 → 'failed'。
- `NoteFailureDialog`：标题/消息/按钮随 kind 切换，文案逐字对齐原版
  （"Note unavailable"…Done / "Unable to open note"…OK）。
- `dismissLoadFailure`：`failureDismissHandled` 幂等 + `router.back()`，
  按钮与 `cancel` 回调共用——复刻 `u8` 单次 dismiss 语义。
- 移除内联 Retry 按钮与 `note_open_failed` toast（原版无重试表面）；
  `pageLoadFailed` 保留作守卫，背景列改显对应失败标题。
