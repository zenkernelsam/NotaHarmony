## 背景

审计缺口清单 3.3 挂了四个定位任务，阻塞 A-15、A-17、A-19、A-07、R-32
五个条目。本 Phase 在 `decompiled_1.0.1`（审计所称 `reference/`）与
`decompiled_1.0.3` 中完成全部定位，并对照 Harmony 现行实现。

## 定位结果

| 任务 | 原版定位 | 结论 |
|---|---|---|
| `fc0` 实现类 | `hc0` = SingleAttribute：a()=altitudeAngle、b()/c()=azimuthUnitVectorX/Y、d()=force、e()=strokeWidth；`gc0` 为插值包装 | A-15/A-17 已对齐，关闭 |
| `f92.c(...)` | `(d·m+b)/dv` 仿射；调用参数 (1,0,1) 恒等 | A-19 为 no-op，关闭 |
| `dd4.d()` | `clamp(d,2.6,18.0)`；`ms1:180` 容差式 = `0.5/(((clamp(w·zoom,2.6,18)−2.6)/15.4)·1.5+1)/zoom`，无 Math.log | A-07 公式已精确一致，关闭 |
| 原版 undo 深度 | `nnf`/`ekd` 快照态 List 无界；`n1d.X0`→`tzc`/`nzc` CRDT op 回放无数值上限 | R-32：原版无计数上限；Harmony 128 动作+32MB 双预算为有意发散，关闭 |

## Harmony 侧核对

- `PencilSplatGenerator.ets:246,230-233`：angleDiff 与 sizeFactor 同源
  `altitudeAngleRadians`（`fc0.a()`）——已对齐。
- `PencilSplatGenerator.ets:263-266`：散布方向用 `azimuthUnitX/Y`，
  缺失回退 (1,0)（对应 `a61.f()`）——已对齐。
- `PencilSplatGenerator.ets:283-284`：opacity 无多余钳制——恒等调用
  不需补。
- `CubicFitter.ets:28-32`：`computeOriginalFitTolerance` 与 `ms1:180`
  逐字一致。
- `UndoRedoManager.ets:585-586,861-885`：双预算可配置，`shift()` 逐出
  语义保留（原版无界 → 移植侧内存安全上界，已记录为有意发散）。
