## 改了什么

创建/修改 3 个文件：

1. `note/src/main/ets/ui/editor/NoteCanvasPage.ets`（新增）
   - `@Entry @Component` 页面：顶部工具栏（Pen/Taper/Pencil/Eraser/Partial 五个按钮）+ Canvas 画布
   - onReady：canvasCtx.width/height → layerManager.initialize；predictor.reset
   - onTouch：Down→startStroke / Move→continueStroke / Up/Cancel→endStroke
   - startStroke：橡皮擦模式收集路径；否则 makeRenderSpec（isPencil 按工具判断）→ strokeSession.beginStroke → inputProvider.beginStroke → processEvent → addBatch
   - continueStroke：touches → RawPointerEvent[]（pressure /65535 归一化）→ processEvent → addBatch → renderFrame（Move 中直接操作 canvasCtx，不依赖 build 循环）
   - endStroke：擦除 → eraserEngine.erase → 删除/更新笔画列表 → rebuildFromStrokes；绘制 → finishStroke → commitStroke → renderFrame
   - renderFrame：layerManager.composite(canvasCtx, currentStroke, renderCtx)
   - toRawPointerEvent：TouchObject → RawPointerEvent（tilt/orientation 模拟器 fallback 0）

2. `note/src/main/resources/base/profile/main_pages.json`：注册 `ui/editor/NoteCanvasPage` 路由

3. `note/src/main/ets/pages/Index.ets`：新增 Open Canvas 按钮 → router.pushUrl（带 BusinessError catch）
