# Phase 181 修复总结：文件夹子树删除保留笔记

## 发现

`folder.parent_id` 采用外键级联删除，但 `deleteFolder()` 只迁移目标文件夹直属笔记。删除带子文件夹的父目录时，后代文件夹中的笔记会随级联被删除。

## 修改

- `note/src/main/ets/data/FolderRepositoryImpl.ets`
- 新增 `ADR-0158-folder-subtree-delete-preserves-notes.md`
- 新增 `d02-folder-subtree-delete-preserves-notes.mjs`

删除现在在同一事务中先遍历完整子树，把所有相关笔记移回根目录，再删除文件夹树；不存在的 folder 也会在写入前明确失败。
