# Phase 345 修复总结：资料库回填生命周期绑定

日期：2026-08-24（Asia/Shanghai）

## 缺陷与修复

- 资料库初始加载后的 `backfillSearchIndex()` 成功续体只检查搜索词/文件夹状态，不检查页面是否仍在同一生命周期实例；销毁或重建后的迟到回填可启动额外 `loadNotes()` 并发布 notes/thumbnail 状态。
- 回调入口现在先检查 `isCurrentLifecycle(expectedLifecycleGeneration, vm, renderer)`；陈旧结果直接返回。后续刷新仍由 request generation 保护。
- 设置页审查确认现有 Backup lease、WebDAV 本地 busy 门和配置快照已覆盖主要风险，本阶段不改其行为。
