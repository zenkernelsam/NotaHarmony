# Phase 312 修复总结：原版文本提交页面绑定

日期：2026-08-23（Asia/Shanghai）

## 背景与缺口

带样式的原版 Text 提交会等待 `previewOriginalTextEdit()`。该持久化预览内部执行 `flush()`，存在真实
await 边界；同 ID 页面在预览期间重载时，`pageId` 与 `loadedPageId` 可能保持相等，但加载代际已经推进。

原检查只比较编辑对象引用和两个页 ID，未检查 `pageLoadGeneration`、生命周期、加载中或加载失败状态。
迟到成功因此可能把旧上下文的文本替换进新加载数组，并把可见 `REPLACE_ELEMENT` 推入新页 undo 历史。

## 实现

- 在进入原版样式化 Text 预览前捕获 `pageLoadGeneration`。
- 预览成功后保留原有 `editingTextBlock/editingOriginalTextBlock` 引用检查，并复用 Phase 311 的统一
  健康页上下文谓词。
- 过期结果记录“original Text edit rejected after page changed”，返回失败；不再调用
  `replaceTextBlock()`、不推 undo 历史，也不把本次提交当作当前页成功处理。
- 同步本地 Text 创建与更新分支没有 await 边界，保持不变。
