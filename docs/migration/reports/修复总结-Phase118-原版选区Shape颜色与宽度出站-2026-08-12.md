# Phase 118 修复总结：原版选区 Shape 颜色与宽度出站

## 原版证据与边修边审

- 重新恢复原版 `zn3 case 4`、`ks0 case 4` 并对照 `u5j.r/kgh.c/le8`，确认 Phase 117 暂写的
  Shape type-23 边界错误：Shape 使用 type-19 `MODIFY_SHAPE`，fields 10/11/12 分别是 color、
  borderWidth 与 nullable fillColor。
- Highlighter Shape 改色同时写 alpha 107 的 border color 与同色 fill setter；普通 Shape 只写
  alpha 255 border color并保留 fill。Shape 宽度按自身 InkTool 经 `w4g.a` clamp，但不乘
  `pageWidth / 768`；该换算只属于 Ink 分支。
- 边修边审发现 Harmony Shape snapshot 丢失原版 tool，无法可靠区分 Highlighter、Pencil 与 Tape。
  因此先补 `originalTool`，由原版 reducer 直接物化，并从 `original_shape_state.resolved_payload`
  为旧 snapshot 运行时补全；包校验、clone 和本地识别同步保留该字段。

## 已完成修复

- Selection 颜色/宽度现在同时覆盖 Ink 与 Shape。Shape-only 选择能回显自身颜色、宽度与原版 range；
  混合选择仍以首个有效对象显示值，但每个目标按自身 tool 独立 clamp。Shape width 直接保存，绝不做纸宽换算。
- Highlighter Shape 改色同步更新 border/fill，普通 Shape 只更新 border。涉及 Shape 的命令写一个
  `TRANSFORM_ELEMENTS`，携带混合 Ink/Shape 精确 before/after；Undo/Redo 可恢复不同旧颜色、宽度和 fill。
- 新增 `OriginalModifyShapePayloadEncoder`，严格编码 type-19 fields 0/10/11/12，支持批量目标、
  fill value、nullable clear 与 absent setter，并拒绝重复目标、透明 fill 和非法值。
- `StrokePersistence` 将原 type-17 classifier 扩展为统一 render classifier：完整 bytes 投影只允许已证明
  的 Ink 与 Shape registers，按最终 tuple 分批；生产路径额外确认 Shape state 存在、resolved payload 的
  tool 合法且与每个 snapshot target 完全一致，避免本地非原版 Shape 或损坏快照冒充 type-19 target。
- type-17 与 type-19 使用各自 reducer和 canonical operation identity，但共享同一个
  `OriginalPageMutationBatch`，整条命令只推进一次 revision。journal、snapshot reconciliation、Harmony
  history companion 或任意批次失败都会回滚整个事务。`ORIGINAL_MODIFY_SHAPE` 已加入持久历史透明 companion。
- 更正 ADR-0094、Phase 117 中文总结和总进展中的 type-23 错误边界。
