# Phase 420：临时编辑器选区浮层重绑

## 结论

Phase 420 修复 Math 编辑与图片裁剪这两个临时转换后选区不可见的问题。现在取消、确认或导航分离会在
SelectionTool 仍持有 IDs 且几何非空时重新发布 `selectionVisible = true`；`selectionRect`、能力寄存器、
触摸命中、菜单命中、粘贴锚点和 resize 门禁重新绑定到同一概念选区。

## 问题与边界

- 临时转换入口必须继续隐藏画布选区，避免编辑器期间误触拖拽或菜单。
- 恢复路径此前只刷新几何和能力，没有恢复可见状态；这会让选区看似丢失，也让 viewport/container resize
  无法刷新隐藏选区。
- 本阶段不改 `updateSelectionOverlay()` 的空态规则。权威退出、翻页、绘制开始、DELETE/CUT、Math 插入
  等路径仍按 Phase 418/419 保持隐藏和寄存器默认化。

## 实现

- `detachMathEditorForNavigation()`：刷新后恢复可见。
- `cancelMathEditing()`：刷新后恢复可见。
- Math 确认：持久化提交且当前页上下文有效后，投影新 Math 数据并恢复可见。
- `cancelImageCrop()`：重装原图 ID，刷新后恢复可见。
- `confirmImageCrop()`：相同字节快速返回与普通提交两条成功路径都在刷新后恢复可见。
- 失败、过期页上下文和空几何不伪装成功，也不会强行显示。

## 验证

- 聚焦 Replay 通过，新增临时编辑器隐藏/恢复、resize 可修复前提、空态不复活和权威退出不变断言。
- ArkTS 检查无错误，仅有既有 unused/deprecation 诊断。
- 全量 Desktop Replay 为 `REPLAY_FILES=371 PASSED=371 FAILED_FILES=0`。
- 静态构建：clean 2.253 秒成功；ohosTest HAP 30.212 秒成功；default HAP 3.625 秒成功。构建仅提示既有
  obfuscation/signing 警告，没有错误。
