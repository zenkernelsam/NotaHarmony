## 改了什么

### 1. 标题编辑（NotePage.ets）

- 顶部栏"Note Editor"固定文本 → **行内标题**：显示笔记标题（空标题显示"未命名笔记"占位，Ellipsis 截断）
- 点击标题 → 进入编辑态（TextInput，预填当前标题）
- **回车（onSubmit）或失焦（onBlur）** → `updateNote` 持久化标题（空标题不保存）
- 标题加载：`loadPages` 中 `NoteRepositoryImpl.getNote` 读取

### 2. Undo 全覆盖（UndoRedoManager + NoteCanvasView）

**UndoRedoManager 扩展**（不改已有字段语义）：
- 新类型：`ADD_ELEMENT`（文本框创建）/ `DELETE_ELEMENT`（文本框删除）/ `REPLACE_ELEMENT`（形状替换）
- 新字段（可选）：`addedElement` / `removedElements`

**入栈补齐**：

| 操作 | 类型 | 实现 |
|------|------|------|
| 选区移动 | TRANSFORM_STROKES | ✅ 已有（移动结束时统一 push） |
| Image 翻转 | TRANSFORM_ELEMENTS | ✅ Phase 114 更正为 Image-only MODIFY_BLOCK；不再反射其他元素 |
| 选区删除/剪切 | ERASE_STROKES | ✅ 已有 |
| 文本框创建 | ADD_ELEMENT | ✅ onTextCommit 入栈（undo 删除文本框，redo 恢复） |
| 文本框删除（取消新建） | DELETE_ELEMENT | ✅ onTextCancel 入栈（undo 恢复文本框） |
| 形状替换 | REPLACE_ELEMENT | ✅ 修复：原实现按 ADD_STROKE 入栈（undo 后原笔画丢失）→ 改为 REPLACE_ELEMENT（before=原笔画，undo 恢复手画；after=形状，redo 恢复形状） |

**applyAction 扩展**：处理 ADD/DELETE_ELEMENT（textBlocks 增删）+ REPLACE_ELEMENT（strokes 快照切换）；撤销/重做后统一 rebuild + persist + 刷新。
