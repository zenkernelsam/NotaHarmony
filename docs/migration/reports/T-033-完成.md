## Bug 1：Pencil 渲染大面积污染画布 ✅ 已修复

### 根因（两个叠加问题）

1. **散布半径失控**：`PencilSplatGenerator` 的 `ellipseR = 0.3 × spacing × subdivisions`（xaa.b 原版公式）。模拟器无 orientation 数据（fallback 0）→ `angleDiff = π/5` 最大 → `subdivisions=25` → 笔宽 36 时 **ellipseR ≈ 270px** → splat 在笔画周围 540px 范围散布 → "大面积污染"
2. **scale 语义错误**：xaa 的 `scale` 语义为**半径**（直径 2×scale ≈ 笔宽），渲染器却把它当**缩放系数**（`ctx.scale(s.scale)`），纹理加载时 64px 纹理 ×11 ≈ **704px 大斑**
3. **附带发现**：无 orientation（fallback 0）时 `angleNorm=1 → edgeFactor=0.1 → opacity≈0.03`——splat 几乎透明（修复 1 后笔画一度不可见，已一并修复）

### 修复（3 处）

| 位置 | 修复 |
|------|------|
| `PencilSplatGenerator.generateAtPosition` | `ellipseR` 钳制到 `1.5 × spacing`（散布只在轨迹附近） |
| `Canvas2DStrokeRenderer.renderPencilSplats` | scale 按半径语义渲染：缩放系数 = `scale/texHalf`（直径 2×scale）；fallback 圆半径 = scale；包围盒半径 = scale |
| `PencilSplatGenerator`（3 处） | 无 orientation 时 fallback `Math.PI/5`（中性值：angleDiff=0 → 无散布 + edgeFactor=1 → opacity 正常） |

### 验证（模拟器实测，像素分析）

- 修复前：画布区域深色像素散布全画布（y 380-1378 全范围）
- 修复后：**深色像素集中在笔画轨迹附近**（x 1202-1984, y 554-804 局部 782×250 区域），笔画清晰可见（11930 像素）
- `stroke finished, pts=13` 正常
