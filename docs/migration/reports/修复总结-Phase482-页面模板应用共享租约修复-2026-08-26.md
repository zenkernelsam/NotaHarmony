# 修复总结 — Phase 482 页面模板应用共享租约修复

## 问题

页面设置弹窗已在共享照片导入期整体抑制，但若弹窗先打开，模板预览点击仍可调用
`applyTemplate()` 并进入父页页面操作队列。该函数缺少组件内共享导入租约防线，与尺寸卡片、
自定义色和方向按钮不一致。

## 修复

`applyTemplate()` 先拒绝 `photoImportLeaseActive`，再执行原有模板应用回调。父页页面操作、
背景应用、历史准备和其他面板控件语义不变。

## 影响与验证

- 新增 ADR-0454、Harmony evidence 和本中文 Report。
- 扩展页面设置共享租约专项 Replay，锁定模板应用防线，当前 `TOTAL=8 FAILED=0`。
- ArkTS 目标无错误，仅既有警告与信息级提示。
- 相邻纸张设置、默认模板路由与紧凑页面设置 Replay 通过。
- 全量 Desktop Replay `REPLAY_FILES=421 PASSED=421 FAILED_FILES=0`（29.159 秒）；
  clean 3.151 秒、ohosTest HAP 9.813 秒、default HAP 29.100 秒均静态构建成功。
- 未启动模拟器、虚拟机、真机或 Hypium；T-042 继续保留为 Goal 最后任务。
