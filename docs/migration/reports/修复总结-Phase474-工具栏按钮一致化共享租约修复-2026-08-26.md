# 修复总结 — Phase 474 工具栏按钮一致化共享租约修复

## 问题

Photo/Math 插入和 Undo/Redo 回调已能拒绝共享照片导入租约，但对应四个工具栏按钮没有
消费该租约，导入期仍显示可用，造成视觉状态与实际防线不一致。

## 修复

四个按钮在既有加载或历史能力门禁外统一叠加共享导入租约禁用；父页回调和画布内部双层
防御保持不变。插入信号、历史方向、能力计算、保存链和持久化语义不变。
