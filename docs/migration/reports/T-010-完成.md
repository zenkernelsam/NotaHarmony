## 改了什么

创建 `note/src/main/ets/core/algorithm/WidthOutlineBuilder.ets`（纯数学模块，w4a.b() 等价）：

- `interface OutlineResult`（outlinePoints / isValid）
- `class WidthOutlineBuilder`：
  - build()：输入 < 2 点返回 invalid；法向量 → 上/下轮廓 → 尖角过渡 → 起点帽 + 上轮廓正序 + 终点帽 + 下轮廓逆序组装封闭多边形
  - computeNormals()：切线 = normalize(p[i+1]-p[i-1])，端点用相邻差分；极短段（< 0.01）复用前法向量
  - offsetCurve()：halfWidth = widthFactor × baseWidth / 2，沿法向量 ± 偏移
  - buildRoundCap()：5 段半圆弧（起点从 -normal 扫到 +normal，终点反向）
  - handleSharpCorners()：相邻法向量 dot < cos(60°) 时插入平均法向过渡点（防自交）
