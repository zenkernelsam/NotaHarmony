## 原版行为（硬证据）

`decompiled_1.0.3/sources/defpackage`：

- `dl1.java` case2（ftc 选中态 pointer-down）：`xtc.a(jE, set)` 取最上层
  命中 → 命中元素 ∈ 选中集 → `stc({id})` 单元素抓取；`cqc` 组命中 →
  `stc(cqc.b, cqc.a)` 整组抓取；覆盖层 `cmb` 内 → `utc` 消费；否则
  `qtc → z39(17)` 新选区。
- `ej9.java` case18：被抓取 id 从 `ftc.g` 减去（`ys2.H`）、并入 `ftc.i`

  `aeg` 协程应用。

## 修复前偏差

Harmony：选中态下 `pointInRect(touch, selectionRect)` 命中选框即拖动
**整个**选区。与原版相比：

- 多元素选区中按在某个元素上 → 原版只拖该元素/该组，Harmony 拖全部。
- 按在选框内空白处 → 原版开始新选区，Harmony 仍拖动全部。

## 修复内容

1. `SelectionTool.ets`
   - `SelectionState.movingIds`：`ftc.i` 对应物。
   - `grabElements`/`clearMoving`/`movingSubsetOf`；`applyTransform`
     收窄到 `movingIds ∩ selected`。
   - `beginSelection`/`deselect`/`selectStrokeIds`/`selectElementIds`/
     `deleteSelected` 全部复位 `movingIds`（松手重选全集即自动清空）。
2. `ShapeGeometry.ets`：新增 `pointHitsShape`（与 `tapeHitTestShape` 同核，
   供非 tape 点命中使用）。
3. `NoteCanvasView.ets`
   - `hitTestSelectedElementIds`：统一 z 序逆序逐类命中（笔画精确覆盖 /
     形状精确覆盖 / 块类逆仿射局部矩形）；选中命中 → 元素或组粒度抓取；
     未选中命中 → null。
   - `expandGrabToSelectedGroup`/`selectedGroupLeavesContaining`：命中成员
     属于被选中 Original 组时经 `resolveOriginalSelectedGroupLeaves`
     抓取整组叶子。
   - pointer-down 分支：`hitTestSelectedElementIds` 命中 → `grabElements`
     + 拖拽；未命中 → `beginSelection`（新选区），删除"选框内任意按下
     拖全部"路径。
   - `applySelectionTransform` 与落点撤销记录统一 `movingSubsetOf` 收窄
     到被抓取子集。

## 有界偏差（ADR-0558 §有界偏差）

- 抓取期间选框覆盖层不收缩；`planSelectionSnap` 吸附锚点仍按整选区边界；
- `cqc` 动态组聚合无静态等价物，仅对持久 `selectionGroups` 做组粒度展开。
