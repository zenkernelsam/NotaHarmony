# Phase 568：原版吸附对齐（snap-to-grid / alignment guides）

日期：2026-09-22

## 原版现场

- 开关：`ac4.S` = `SNAP_TO_GRID`，远程键 `androidSnapToGrid` 默认 true
  （`core_remoteconfig__remote_config_defaults.xml`）——正式版默认开启。
- 候选（`q7j.a`，按可视区过滤）：
  - GRID 纸 → `GRID_LINE` 水平/垂直网格线（阈值 12pt）；
  - DOTS 纸 → `GRID_INTERSECTION` 格点交点（6pt）；
  - LINES/PLAIN 等 → 无网格候选（`q3a` 空）；
  - 每个未选中元素 → 4 个 `OBJECT_CORNER` 角点（6pt）+ 2 条
    `OBJECT_CENTER` 中心线（6pt，guide 贯穿元素）+ 4 条 `OBJECT_EDGE`
    边线（8pt，guide 即边）。
- 判定（`m91.o`/`j`）：拖拽侧锚点 = 选区 bounds 四角 + 中心
  （`fi3.c`/`fi3.b`），各加位移后与全部候选比较；点候选测双轴，水平线
  仅 y，垂直线仅 x；阈值 = pt ÷ zoom。
- 胜者（`xe8.R`）：每轴取 `fjd.I` 优先级最高者
  （GRID_LINE/EDGE=1，INTERSECTION/CORNER=2，CENTER=3），同级取
  |delta| 最小。
- 参考线（`m91.i`）：仅绘制胜者候选的非空 `b()` 线段——即可见参考线
  只有元素边/中心线；网格线与点命中只吸附不画线。
- 消费：`avc.g` 移动会话吸附；`avc.h` 控制点会话由独立开关 `ac4.Y`
  （SHAPE_EDIT_SNAPPING）门控。

## Harmony 落地

- 新增 `core/model/OriginalSnapGuides.ets`：
  - `originalSnapGridCandidates` — GRID/DOTS 网格候选，网格线位数学与
    `PaperRenderer.gridPositions` 完全同源（含 centered/bleeds 偏移），
    按可视区过滤；
  - `originalSnapCandidatesForElementBounds` — 每元素 4 角点 + 2 中心线
    + 4 边线共 10 候选；
  - `originalSnapMoveAnchors` — 选区 bounds 四角 + 中心 5 锚点；
  - `planOriginalSnapMove` — `xe8.R` 胜者规则 + `m91.i` 参考线段收集；
    阈值换算 `pt × POINTS_TO_PAGE_UNITS / zoom`（Harmony 页面单位 =
    96/72·pt，原版文档坐标即 pt）。
- `NoteCanvasView`：选区拖拽的移动与抬手收尾两处接入
  `planSelectionSnap`，修正量叠加 `moveSelected`；候选每步重建并按
  当前可视区过滤；命中线段以 `theme.accent`、`1.5/zoom` 屏宽恒定线宽
  绘制；拖拽结束/取消清空参考线。

## 差异登记（fail-closed）

- 元素锚点一律取 bounds 四角（原版 `fi3.c` 无轮廓点分支）；Harmony
  元素变换已烘入 bounds，无独立旋转字段，语义等价。
- 控制点/顶点编辑吸附（`ac4.Y`）不移植：Harmony 无顶点/控制点编辑面。
- 吸附始终开启对齐原版远程默认 true；原版无用户可见开关，不新增设置项。
