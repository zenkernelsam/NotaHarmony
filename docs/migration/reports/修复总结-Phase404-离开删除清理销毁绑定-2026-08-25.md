# Phase 404：离开删除清理销毁绑定

日期：2026-08-25（Asia/Shanghai）

## 问题

离开编辑器的续体在画布 flush 后等待录音删除队列 flush。这个异步边界期间如果组件销毁，旧续体仍会继续结束录音会
话并永久释放播放控制器；而 `aboutToDisappear()` 的兜底路径也会执行同类释放，形成共享资源重复释放竞态。

## 修复

- 在删除队列 flush 返回后增加 `editorDisposed` 复查。
- 已销毁的迟到续体停止后续录音会话终止和播放器永久释放。
- 正常离开仍按工具状态、删除队列、录音会话、播放控制器的顺序清理并返回路由。
