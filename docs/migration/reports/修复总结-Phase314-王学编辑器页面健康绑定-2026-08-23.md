# Phase 314 修复总结：Math 编辑器页面健康绑定

日期：2026-08-23（Asia/Shanghai）

## 背景与缺口

Math insert/edit 执行持久 SQLite 事务，成功和失除分支使用弱守卫。同ID页面重载时迟到结果可污染新状态。
另外，cancelMathEditing() 在忙时早退，导致切换后 Math overlay 无法关闭。

## 实现

- 新增 detachMathEditorForNavigation() ：无条件隐藏编辑器、清空草稿和预览，在切换时从 cancelActiveInteraction() 调用
- confirmMathEditing/confirmMathInsert 共四处守卫替换为健康谓词
