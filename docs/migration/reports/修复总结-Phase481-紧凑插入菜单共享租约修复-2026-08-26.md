# 修复总结 — Phase 481 紧凑插入菜单共享租约修复

## 问题

Phase 479 已统一普通工具按钮与笔刷样式按钮的视觉禁用和回调控约，但紧凑工具菜单中的 Photo 与
Math 插入项仍直接调用父页回调。菜单在共享照片导入开始前打开时，action 缺少组件内第一层防线。

## 修复

两个插入 action 先拒绝 `photoImportLeaseActive`，再执行原有回调。Math 和照片信号的父页守卫、
页面操作与历史门禁、画布 `@Watch` 回调防线以及普通布局按钮行为均不变。
