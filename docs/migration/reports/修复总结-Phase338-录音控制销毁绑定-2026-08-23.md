# Phase 338 修复总结：录音控制销毁绑定

日期：2026-08-23（Asia/Shanghai）

## 缺陷与修复

- `pauseRecording()` / `resumeRecording()` / `stopRecording()` 直接调用会话操作，未检查编辑器是否存活；
  销毁后排队的控制回调可驱动已开始释放的会话。
- 三个入口现在检查 `editorDisposed`；销毁态不解析也不调用会话控制器。已释放控制器保持权威。
