# Phase 389：编辑器初始化取消绑定

日期：2026-08-25（Asia/Shanghai）

## 问题

`EditorViewModel.initialize()` 跨多个异步边界读取并写共享工具状态。NotePage 销毁后，迟到初始化仍可绑定仓库、发布旧 UI 状态，并对全局 `'primary-editor'` 执行默认或工具箱持久化写入。

## 修复

- 为 ViewModel 初始化增加可选生命周期取消门禁。
- 在保存链等待、工具读取、缺失写入、批量默认写入、工具箱读取和设置读取后检查门禁。
- NotePage 注入 `editorDisposed` 与加载代次联合判断；陈旧续体直接返回，不触达状态或存储。
- 复核缩略图渲染器候选：释放路径受 `thumbnailRefreshMutex` 保护，判定为假阳性并记录。
