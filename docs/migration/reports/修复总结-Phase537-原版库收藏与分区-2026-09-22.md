# Phase 537：原版库收藏（Favorites）与分区奇偶落地

日期：2026-09-22

## 选题

原版库有一等分区模型 `dk9`（ALL_NOTES / RECENT / FAVORITES /
UNFILED，`ua5.java:227` chip 行），收藏位 `isFavorited` 经
`modifyNote` 同步（`yp1.java`），上下文菜单 Favorite/Unfavorite
（`d5j.java:126`），卡片 `favorite_fill` 徽标（`pf9.java:49`）。
Harmony 侧 `note_meta.favorite` 与 `last_opened` 列早已存在，
但无查询/写入/展示路径——功能级差距，判定为 P1 交互缺陷。

## 原版现场重放（decompiled_1.0.3）

- `dk9.java`：四分区枚举绑定
  `feature_library__all_notes/recent_notes/favorite_notes/unfiled`。
- `ua5.java:227`：`for (dk9 dk9Var : dk9.M)` 四值 chip 行，
  `fk9Var.d == dk9Var` 选中态；`pk9.java:67` 默认 ALL_NOTES。
- `mk9.java`：RECENT = `au1.N1(au1.K1(list, new fh7(13)), 10)`
  ——新近度降序前 10，跳过 `pk9.s` 分区排序；卡片日期
  `dk9Var == dk9Var2 ? gb6.b0 : gb6.c0`（RECENT→lastOpened，
  其余→updatedAt）。
- `fh7.java` case 13 交换参数比较 = 降序；
  `apb.F` = `lastOpened` 覆盖否则回退笔记时间戳。
- `x17.java:143`：`COALESCE(cp.editFavorite, snm.favorite, 0)` /
  `COALESCE(cp.editLastOpened, snm.lastOpened)` ——favorite/
  lastOpened 是合并元数据；`setFavorite`/`setLastOpened` 部分
  EDIT 不带 createdAt/updatedAt —— **不推进 updatedAt**。
- `d5j.java:126` + `gj9.java`：菜单项标签/图标随当前标志
  在 Favorite ↔ Unfavorite 间翻转；原版位序 Favorite → Move →
  Delete（尾部）。
- `pf9.java:49`：卡片渲染 `ui_designsystem__favorite_fill`。
- `strings.xml`：`empty_favorite_notes_title`（No favorite
  notes）/ `empty_favorite_notes_body` 专属空态。

## Harmony 修改（ADR-0509）

- `RepositoryInterfaces`：`LibrarySection`（dk9 序）+ 接口新增
  `getFavoriteNotes` / `getRecentNotes` / `getUnfiledNotes` /
  `setNoteFavorite` / `touchNoteLastOpened` /
  `searchNotesInSection`。
- `NoteRepositoryImpl`：三条分区查询（favorite=1、lastOpened
  DESC LIMIT 10、folder_id IS NULL，均排已删）；两个**单列
  部分更新**（ValuesBucket 只写 `favorite` / `last_opened`，
  `updated_at` 不动）；分区搜索 = 分区谓词 + search_item
  EXISTS；全部走 `libraryMetadataMutationMutex`。
- `LibraryViewModel`：`currentSection`（默认 ALL_NOTES）；
  `setSection`/`setFolder` 互斥重置；`queryNotes` 统一派发；
  `toggleFavorite` 部分更新 + FAVORITES 分区就地剔除；
  `applySort` 在 RECENT 早退。
- `LibraryPage`：侧栏 + 紧凑抽屉各四枚 `SectionNavRow`；
  菜单 Favorite/Unfavorite 置于 Move 之前、Delete 尾部不变；
  卡片 `TopEnd` `♥` 徽标；RECENT 卡片显示 `lastOpened`；
  FAVORITES 空态文案；`currentFolderName` 分区感知。
- `NotePage`：打开笔记 `touchNoteLastOpened(noteId, Date.now())`。
- 资源：base/zh_CN 双语 `recent_notes` / `favorite_notes` /
  `unfiled` / `favorite_note` / `unfavorite_note` /
  `empty_favorite_notes_title/body`。
- 测试：`FakeNoteRepository` 实现新接口；新增 FAVORITES 过滤、
  RECENT 前十+排序免疫、UNFILED、toggle 投影一致性、文件夹
  选择重置分区共 5 个用例。

## 残留差异（如实登记）

1. 原版 `ua5` 分区是横向 chip 行；Harmony 落点为侧栏/抽屉的
   纵向导航行（选择语义一致）。
2. 图标 `favorite_fill/outline` → 文本字形 `♥`/`♡`。
3. `lastOpened` 打点目前仅覆盖编辑器打开路径；缩略图预览等
   其他原版打点位待登记观察。
4. favorite/lastOpened 当前作为本地元数据列直写；若未来接入
   原版笔记级操作管线，需迁移为 EDIT 行（ADR-0509 决策 6）。
