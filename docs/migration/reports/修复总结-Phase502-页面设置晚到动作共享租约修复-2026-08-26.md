# 修复总结 — Phase 502 页面设置晚到动作共享租约修复

## 问题

收藏、模板间距和自定义色关闭按钮已有响应式禁用，目标方法也会拒绝共享租约；但点击回调缺少
第二层拒绝，晚到事件可在租约收口窗口中先转发。

## 修复

三个回调先通过 `photoImportLeaseActive` 拒绝共享导入租约，再执行收藏切换、间距入口切换或
关闭自定义色展开。面板布局、草稿语义、能力边界和历史行为全部保留。

## 影响与验证

- 新增 ADR-0474，并在既有 Harmony evidence 文件追加本阶段增量段。
- 扩展页面设置共享租约 Replay 至 22 项，当前通过。
- ArkTS 目标无错误，仅既有警告与信息级提示。
- 全量 Desktop Replay `REPLAY_FILES=421 PASSED=421 FAILED_FILES=0`
  （32.242 秒）；clean 3.169 秒、ohosTest HAP 9.752 秒、default HAP 29.378 秒均静态构建成功。
- 未启动模拟器、虚拟机、真机或 Hypium；T-042 继续保留为 Goal 最后任务。
