# Phase 318 修复总结：延迟墨水重建页面健康绑定

日期：2026-08-23（Asia/Shanghai）

## 缺陷与修复

- 选区删除/剪切 flush、局部擦除 `.finally()`、普通粘贴 flush 都会在持久化完成后重建原版 CREATE_INK 预约。
- 旧守卫只比较 generation 与 loadedPageId，未检查 currentPage、loaded、加载中/失败和生命周期；同页重载、加载失败或画布销毁后的迟到结果仍可能触发预约。
- 三处后置刷新统一改为先通过 `isHistoryPageContextCurrent()`，再调用 `refreshOriginalInkReservation()`。过期路径跳过页面本地刷新；持久化结果和历史权威不受影响。
