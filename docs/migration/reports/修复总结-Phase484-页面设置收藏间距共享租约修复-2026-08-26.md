# 修复总结 — Phase 484 页面设置收藏间距共享租约修复

## 问题

页面设置弹窗已有整体租约禁用，但收藏星标、间距“⋯”、间距滑杆对应的直接回调缺少组件内
第二层防线。共享导入收口窗口内，这些回调仍可能切换收藏状态或改写共享纸间距。

## 修复

`toggleFavorite()`、`toggleSpacingSettings()`、`previewSharedSpacing()` 和
`saveSharedSpacing()` 先拒绝 `photoImportLeaseActive`，再执行原有状态变更或存储操作。
收藏与间距按钮同步补齐禁用条件。共享纸加载、乐观更新、失败恢复和普通纸张设置语义不变。
