# 修复总结 — Phase 490 纸色草稿共享租约修复

## 问题

页面设置弹窗的 legacy 色格、自定义色展开和 HSV 滑杆缺少组件内租约防线。共享导入收口窗口内，
晚到点击或拖动仍可能改写纸张颜色草稿。

## 修复

legacy 选择与自定义色开启的门禁加入共享导入租约；色相、饱和度、明度三个更新函数先拒绝该
租约，再执行原有夹取和 ARGB 草稿生成。无 alpha 语义、模板预览和普通纸张设置不变。

## 影响与验证

- 新增 ADR-0462，并在既有 Harmony evidence 文件追加本阶段增量段。
- 扩展页面设置共享租约专项 Replay 锁定五项新防线，当前 `TOTAL=19 FAILED=0`。
- ArkTS 目标无错误，仅既有警告与信息级提示。
- 相邻原版纸张设置、默认模板路由、紧凑页面设置、页面条共享租约通过。
- 全量 Desktop Replay `REPLAY_FILES=421 PASSED=421 FAILED_FILES=0`
  （30.895 秒）；clean 3.248 秒、ohosTest HAP 9.792 秒、default HAP 29.478 秒均静态构建成功。
- 未启动模拟器、虚拟机、真机或 Hypium；T-042 继续保留为 Goal 最后任务。
