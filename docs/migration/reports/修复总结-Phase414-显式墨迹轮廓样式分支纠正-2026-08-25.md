# Phase 414 修复总结：显式墨迹轮廓样式分支纠正

## 问题

Phase 412 根据 `customPath` 字段名推断“所有中心线样式都应裁剪后描边”，遗漏了 `e16` 中 `set.contains(inkStyle)` 分支。该集合只包含 DASH/DOTS；普通笔迹与荧光笔的显式轮廓实际使用 fillPaint 填充。此错误会让 MONO/Taper 显式形状被裁剪成中心线细线，丢失原版形状。

## 修复

现在恢复原版双分支：

- DASH/DOTS：先构建并裁剪 customPath，再用中心线 paint 描边，保留宽度、cap/join、dash 周期、backing phase 与荧光 alpha。
- 其他中心线样式：直接填充 customPath，荧光笔仍将 alpha 覆盖为 107。

## 证据

除 Java 源码外，本轮补充了 `iw4` fallback 反编译证据，确认 centralPathPaint 是 STROKE、fillPaint 是 FILL，排除了 paint 名称歧义。

## 验证

- 专项样式分支 Replay 12/12 通过。
- 辅助路径、渲染、样式映射、墨迹特效、局部擦除、创建墨迹和铅笔修改相邻 Replay 通过。
- ArkTS 检查无诊断。
