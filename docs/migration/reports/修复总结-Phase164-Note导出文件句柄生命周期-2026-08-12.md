# Phase 164 修复总结：Note 导出文件句柄生命周期

## 发现

`NoteExporter.exportToFile` 在读取、写入或 picker 流程抛错时，可能跳过文件句柄关闭；临时文件复用时也未显式截断，目标文件写入后未同步到存储介质。

## 修改

- `note/src/main/ets/data/NoteExporter.ets`
- 新增 `ADR-0141-note-export-file-handle-lifecycle.md`
- 新增 `d02-note-export-file-handle-lifecycle.mjs`

临时、源、目标句柄现在有明确所有权并在 `finally` 兜底关闭；临时文件使用 `TRUNC`，临时和目标写入后执行 `fsyncSync`。
