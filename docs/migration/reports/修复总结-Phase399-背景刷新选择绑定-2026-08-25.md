# Phase 399：背景刷新选择绑定

日期：2026-08-25（Asia/Shanghai）

## 问题

笔记背景设置在持久化完成后还要等待页列表刷新。这个第二个异步边界返回前，Canvas 的当前页可能已被用户切换；旧续
体随后才把 `selectedPageId` 发布给 Canvas，导致刚完成的用户切页被背景操作抢回目标页。

## 修复

- `updateNoteBackground()` 返回并通过销毁检查后，立刻按原目标页恢复选择。
- 之后再执行页列表刷新；刷新后继续沿用销毁门禁、发布物化背景和推入撤销栈的原有逻辑。
- durable 背景更新、失败提示和撤销语义不变。

  锁定 update → 目标页提前恢复 → 页列表刷新顺序。
