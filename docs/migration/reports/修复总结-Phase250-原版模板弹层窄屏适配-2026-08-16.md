# Phase 250 修复总结：原版模板弹层窄屏适配

## 目标

承接 Phase 249 留下的 M2-U-02 缺口：纸色/HSV/收藏/spacing 扩展后，编辑器页管理栏的固定 popup
可能在手机短屏裁切，页管理动作也可能在窄宽度同行溢出。严格参考原版 `fci/f2j/zci` 的纵向模板卡
弹层结构，修复 Harmony 侧可达性，不改变原版数据和提交语义。

## 已修改

1. `note/src/main/ets/ui/components/PageSettingsPanel.ets`
   - 增加 `popupMode`，仅 popup 实例包在最大 560vp 的纵向 `Scroll` 中；默认模板设置页仍使用外层
     `Scroll`，避免嵌套滚动。
   - 面板最小宽度调整为 280vp；尺寸网格、六色 legacy 行、模板卡行、HSV/spacing/错误提示改用
     `100%` 或 `layoutWeight`，消除 340vp 固定内容在手机上的水平溢出。
2. `note/src/main/ets/ui/editor/PageManagerBar.ets`
   - `<720vp` 进入 compact；设置入口改为带 accessibility 文案的 44vp 齿轮按钮。
   - 新建页和 overflow 均明确 44vp 触控区，前后移动/删除继续由原生 `bindMenu` 提供。
   - popup 调用显式传入 `popupMode: true`。

## 原版依据

`fci.java` 的模板卡组使用纵向弹层内容、48vp 行高和 8vp 分区间距；`f2j.java`/`zci.java` 负责组合
模板设置 UI。JADX 未给出 Harmony 断点，所以 720/560 是移植适配预算，已在证据和 ADR 中明确标注，
不冒充原版常数。完整取证见
`docs/migration/evidence/original-compact-page-settings-jadx-2026-08-16.md`。
