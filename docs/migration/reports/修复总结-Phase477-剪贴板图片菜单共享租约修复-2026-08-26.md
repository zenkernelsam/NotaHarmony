# 修复总结 — Phase 477 剪贴板图片菜单共享租约修复

## 问题

画布长按菜单可能在共享照片导入开始前已经显示；其“粘贴图片”项点击后直接启动导入，
可在导入收口窗口内再次翻转共享导入租约，缺少回调级防御。

## 修复

长按菜单项点击后先拒绝当前共享导入租约，再执行原有剪贴板图片导入。菜单可见性探测、
权限申请、锚点、上下文校验和持久化语义不变。
