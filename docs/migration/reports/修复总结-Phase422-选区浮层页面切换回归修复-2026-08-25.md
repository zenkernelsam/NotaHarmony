# Phase 422：选区浮层页面切换回归修复

## 结论

Phase 420 的恢复策略存在回归：页面切换会先调用临时编辑器取消路径，此时旧选区还未被目标页加载流程 deselect；
取消路径随后无条件把 `selectionVisible` 设为 true，导致旧浮层在新页上短暂复活，失败场景还可能残留。

## 根因与修复

根因是把“有概念选区”等同于“应显示”，而没有让恢复动作经过同一次 selection snapshot 的空态判定。

现在移除 Math 导航分离、Math 取消和图片裁剪取消中的显式 `selectionVisible = true`。它们统一依赖
`updateSelectionOverlay()`：SelectionTool 有效则刷新几何并显示；页面切换后已 deselect 则隐藏。
图片裁剪取消继续重装原图 ID 并发布 nullable Ink reset。

图片裁剪确认的两条成功路径保留显式恢复。它们的入口和提交点都绑定当前页，并在提交前重新选择本次确认的
图片 ID，不存在上述跨页窗口。

## 影响边界

- 正常取消 Math/图片裁剪且选区仍有效：浮层仍恢复。
- 页面切换、deselect 或权威退出后：不再复活旧浮层。
- 过期页上下文和空选区：不伪装成功，也不显示。

## 验证
