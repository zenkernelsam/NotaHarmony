# Phase 350 修复总结：偏好保存销毁绑定

日期：2026-08-24（Asia/Shanghai）

## 缺陷与修复

- SettingsPage 形状识别开关和 DefaultTemplatePage 默认模板均为乐观保存；两页没有销毁守卫。离开页面后，
  迟到失败仍可回滚内存设置并弹失败提示，迟到成功也会弹成功提示。
- 新增 pageDisposed 与每次保存独立的 lifecycle generation；保存 await 后、catch 回滚前检查完整生命周期身份。
- 加载成功/失败路径同步加入 pageDisposed，销毁后的迟到初始化不再发布状态或错误。
- 过期路径只执行 finally 的 saveBusy 复位；durable 偏好继续由 EditorSettingsStore 权威持有。
