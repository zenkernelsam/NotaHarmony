## 已完成修复

- type-19 encoder 新增可选 field 8，严格只接受 style 1..3；style 0、非整数与空更新均拒绝。
- render classifier 将 Shape `originalStyle` 纳入 byte-exact 投影与 batch tuple。生产预检比较 state 与
  **before style**，再写 after style，确保正向、Undo、Redo 都不会把目标值误当当前值。
- 选区 FIXED/DASH/DOTS 同时修改 Ink 与 Shape，沿用一个 `TRANSFORM_ELEMENTS` history action、一个事务和
  一次 revision；TAPER 只作用可变宽 Ink，不伪造 Shape 样式。
- Shape renderer 使用与已恢复原版 Ink 一致的 DASH `2w/1w`、DOTS `0.001w/2w`，并对齐 BUTT/ROUND cap
  与 DOTS MITER join；legacy/缺失 style 显式重置为实线。
- 含 Shape 或 Pencil 的选择会禁用 TAPER，避免提供必然失败的控制。
