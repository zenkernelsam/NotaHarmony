# Phase 305 修复总结：粘贴失败反馈页面绑定

## 缺陷

补审发现 Phase 304 只阻止了跨页读取和持久化副作用，但失败路径仍有全局 UI 污染：旧页粘贴在异步失败时若用户已
切走，会向新页显示失败 toast，并通过通用 `reportSaveFailure()` 把新页置为 `saveFailed`。

## 决策与实现

`insertOriginalPhotos()` 的保存失败状态只在捕获 generation/pageId/currentPage 完全匹配时报告；剪贴板专用失败
toast 只在同页上下文显示。跨页失败继续写 hilog，诊断不丢失；两个 busy 标志仍在 finally 释放。多图部分失败的
成功前缀、Undo/Redo 和持久化语义不变。
