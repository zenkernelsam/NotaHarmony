# 修复总结：Phase433 标题保存飞行计数（2026-08-25）

## 问题

Phase 432 后边修边补审发现，`titleSaveInFlight` 是布尔值，但 `titleSaveQueue` 允许多次保存
排队。第二次入队后，第一次任务的 `finally` 可能在新 durable commit 尚未开始时清零标志，
使 NOTE_TITLE 或 NOTE_METADATA 历史提前放行。

## 修复

将布尔标志改为权威计数 `titleSaveInFlightCount`：每次保存入队递增一次，对应 promise settle 后
递减一次。两个 note-level 历史入口统一要求计数归零后才允许 apply。串行队列、失败处理、disposal
守卫和导航租约释放语义不变。

## 证据与回放

- 新增 ADR-0405 记录所有权计数决策。
- 新增 Harmony evidence 固定缺口与断言。
- 新增专项 Replay 4/4；相邻标题、metadata 和页面历史回放通过。
