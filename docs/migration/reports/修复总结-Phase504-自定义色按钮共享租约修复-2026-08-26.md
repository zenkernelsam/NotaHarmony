# 修复总结 — Phase 504 自定义色按钮共享租约修复

## 问题

自定义色按钮已有响应式禁用，目标方法也会拒绝共享导入租约；但组件点击缺少第二层拒绝，晚到
事件可在租约收口窗口中先转发。

## 修复

按钮回调先通过 `photoImportLeaseActive` 拒绝租约激活状态，再执行原有自定义色展开与暂存流程。
布局、HSV 输入、纸色/方向草稿和历史语义全部保留。

  （31.962 秒）；clean 3.281 秒、ohosTest HAP 10.136 秒、default HAP 29.960 秒均静态构建成功。
