# Phase 383 修复总结：WebDAV 保存反馈换代绑定

日期：2026-08-24（Asia/Shanghai）

## 缺陷与修复

- 补审发现 WebDAVSettingsPage.saveConfigOnce 的迟到保存反馈依赖 safeToast；该方法只检查 pageDisposed，
  不校验捕获的 lifecycleGeneration。页面被替换但未销毁时，旧页仍可能弹出保存成功或失败。
- 现在 safeToast 接受可选预期代次并统一通过 isDisposed 检查；保存持久化后的成功、cleanup-pending、提交失败
  以及外层请求失败都显式传入捕获代次。
- 同步预检查提示维持当前代次语义，测试连接反馈不在本阶段扩大修改范围；活动页行为和 finally 清理不变。
