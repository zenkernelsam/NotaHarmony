# Phase 364 修复总结：画布加载失败生命周期绑定

日期：2026-08-24（Asia/Shanghai）

## 缺陷与修复

- 补审发现 `loadNoteData()` 失败续体只检查触发时 pageLoadGeneration；NoteCanvasView 销毁时只关闭
  lifecycle 而不递增该代数，迟到异常仍可清空元素、释放资源、重建空层并向旧组件弹提示。
- 现在失败路径通过代数门禁后先检查 `lifecycleActive`；销毁后的迟到失败不进入失败态也不弹 toast。
  同代 finally 继续权威清理 loading，成功路径、页面切换和 durable 数据语义不变。
