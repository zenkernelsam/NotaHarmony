# Phase 297 修复总结：剪贴板可用性探测代数守卫

## 缺陷

Phase 296 的 update probe 是异步 promise。连续系统剪贴板更新或页面切换后，较早 probe 的迟到结果可能晚于
新 probe 返回；旧结果只检查当前页面就绪，不检查自己是否已经过期，可能覆盖最新可用性并错误展示或隐藏
Paste 菜单。

## 决策与实现

新增 `systemClipboardImageProbeGeneration`。每次刷新先递增代数，异步结果回写前同时校验请求代数仍最新、
页面仍可插入。切页、生命周期清理或后续 update 触发的新刷新都会使旧 promise 失效。MIME exact match、
fail closed 和点击后 READ_PASTEBOARD 契约不变。

## 验证

- 剪贴板专项 Replay 从 21/21 扩展至 22/22，新增 stale async result 丢弃断言；
- 双 HAP 与全量 Replay 结果见总进展验证补录；
- 未启动模拟器、虚拟机、真机或 Hypium。

## 开放项

真实系统剪贴板高频更新、跨应用时序和厂商事件兼容仍需设备验收；`T-042` 继续严格留到 Goal 最后一项。
