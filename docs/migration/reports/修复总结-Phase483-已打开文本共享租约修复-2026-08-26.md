# 修复总结 — Phase 483 已打开文本共享租约修复

## 问题

画布触控入口已在共享导入期被阻断，但 `beginTextEditingAt()` 是已打开文本创建与编辑的直接
变更边界。该函数缺少与其他画布回调一致的第一层租约防线，可能绕过触控时序在导入收口窗口
内打开文本会话。

## 修复

`beginTextEditingAt()` 先拒绝 `photoImportBusy || historyBusy`，再执行原有文本块查找与编辑
状态切换。触控门禁、文本 overlay、提交/取消守卫、持久化、历史和页面语义全部保留。
