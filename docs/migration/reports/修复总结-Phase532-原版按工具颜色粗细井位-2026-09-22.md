# Phase 532：原版按工具颜色/粗细井位 + 全局最近色落地

日期：2026-09-22

## 选题

Phase 530（原版 Room schema 逐表比对）登记的 SCHEMA-D2：原版 ToolboxDatabase
持有三张井位表——`FavoriteColorWellEntity`（按 toolType 的收藏色井）、
`WidthSizeWellEntity`（按 toolType 的粗细井）、`RecentColorWellEntity`（全局最近色）；
Harmony 此前只在 `tool_state` 存两个选中下标，井位内容为 `ColorPicker` 内
12 色硬编码数组，粗细井与最近色完全缺失。

## 残留差异（如实登记）

1. 原版收藏井长按编辑（自定义色轮写井）；Harmony 已有仓库/VM 层 API，弹层
   尚无编辑交互入口——列为后续增强。
2. LASER 井位未播种（无 Harmony 工具）。
3. `selectedWellIndex=-1` 为 Harmony 对"非井位取色"的显式语义，原版未见直接
   写 -1 证据（ADR-0504 记录）。
