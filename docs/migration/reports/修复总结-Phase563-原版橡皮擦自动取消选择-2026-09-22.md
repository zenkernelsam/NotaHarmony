# 修复总结 — Phase 563：原版橡皮擦自动取消选择

日期：2026-09-22

## 原版行为（硬证据）

`x22.java` 渲染笔记编辑器设置的 "Handwriting & drawing" 小节；case 3
挂载开关行：

- `feature_settings__auto_deselect_eraser` — "Auto-deselect eraser"
- `feature_settings__auto_deselect_eraser_description` — "After erasing,
  the toolbox auto-switches back to your last used tool."

消费者在 `i8f.d`（工具栏控制器）：读取 `l59.f`
（autoDeselectEraser）；开启时经 `epi.c(toolbox)` 取"上一个选中工具"
并重新选中。

## 顺带修正：原版默认值真值表（o59.c）

研究 `o59` 的 `noteEditorSettings` datastore 读出侧得到原版缺省真值表，
修正 Phase 561 的登记假设：**hideStatusBar / hideNavigationBar 原版默认
true（opt-out）**，此前按无证据取关；同时确认 keepAwake=false、
noteNightView=false（Phase 560/562 假设获硬证据支持），
autoDeselectEraser=false。

## Harmony 落地

- `EditorSettingsStore.ets`：新增 `autoDeselectEraser` 偏好键（沿用
  原版 proto 键名），`getAutoDeselectEraser`/`saveAutoDeselectEraser`
  复用共享布尔助手；`DEFAULT_AUTO_DESELECT_ERASER=false`；
  `DEFAULT_HIDE_STATUS_BAR`/`DEFAULT_HIDE_NAVIGATION_BAR` 依 `o59.c`
  证据修正为 `true`。
- `EditorViewModel.ets`：`initialize` 与 `shapeDetectionEnabled` 同点
  加载 `autoDeselectEraser`；新增 `autoDeselectEraserAfterUse()` —
  开启且当前为橡皮擦时 `selectToolById(previousToolId)`（跳过隐藏/
  缺失/同工具行），等价 `i8f.d` 的 `epi.c` 语义。
- `NoteCanvasView.ets`：触摸抬手 `applyEraser()` 完成后调用
  `viewModel.autoDeselectEraserAfterUse()`（catch →
  `onPersistenceError`）；取消路径（`cancelActiveInteraction`）不触发，
  符合"擦除后"语义。
- `SettingsPage.ets`：开关行（标题+原版说明）置于 shape_detection 之后，
  对齐 `x22` 条目顺序。
