# Phase 335 修复总结：录音资产变更销毁绑定

日期：2026-08-23（Asia/Shanghai）

## 缺陷与修复

- `onRecordingAssetAvailabilityChanged()` 无条件刷新录音列表；hub 事件在编辑器销毁后送达时，过期回调仍可对
  已销毁页面发布快照。
- 处理器入口检查 `editorDisposed`；销毁态不匹配 noteId 也不调用 `loadRecordings()`。teardown 的退订保持不变，
  该守卫关闭同步送达窗口。
