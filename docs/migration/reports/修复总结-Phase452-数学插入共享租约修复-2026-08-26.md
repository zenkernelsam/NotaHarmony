# 修复总结 — Phase 452 数学插入共享租约修复

## 问题

照片导入异步持久化释放 `historyBusy` 后，外层 `finally` 还要释放 `photoImportBusy`
并向父页回报。此时工具栏数学入口仍可触发 `mathInsertSignal`，Canvas 打开数学编辑器
时不检查共享导入租约，形成与 Phase 451 选区菜单同源的旁路窗口。

## 修复

父页 `onInsertMath()` 先拒绝照片导入、页面操作、历史待定和页面结构租约，再递增
数学信号；Canvas `startMathInsert()` 在原有历史门禁前拒绝 `photoImportBusy`。两层
防御共同保证数学编辑器只在照片导入完全收口后打开，生产字段和后续确认流程不变。
