# Phase 306 修复总结：粘贴锚点跨页重置

## 缺陷

补审原版锚点证据后发现，Harmony 保存最近长按坐标以桥接异步菜单回调，但页面切换未清空它。用户在新页触发
系统剪贴板图片粘贴时，可能把旧页坐标当作本次 `DocPxOffset` 使用，导致图像落在错误位置。

## 决策与实现

新页数据成功 hydrate 后立即将 `clipboardPasteTarget` 置为 null。此后必须由新一次长按提供锚点；无锚点时保持既有
视口中心语义。该修复不改变权限、MIME 探测、页面 generation 守卫、失败反馈绑定或持久化事务。

## 验证

- 剪贴板专项 Replay 从 28/28 扩展至 29/29；
- ArkTS 目标文件无新增错误；全量 Desktop Replay `277` 个文件全部通过，FAILED_FILES=0；
- `git diff --check` 通过；`note@ohosTest` 与 `note@default` 分别 `BUILD SUCCESSFUL in 7 s 715 ms`
  与 `13 s 320 ms`，只做静态打包且跳过签名；
- 未启动模拟器、虚拟机、真机或 Hypium。

## 开放项

真实长按锚点、菜单边缘调整和跨页时序仍需设备验收；`T-042` 继续严格留到 Goal 最后一项。
