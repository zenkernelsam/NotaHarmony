# 修复总结 — Phase 493 工具栏插入按钮共享租约修复

## 问题

非紧凑工具栏 Photo 与 Math 插入按钮已有响应式禁用，父页回调也有四层防线；但组件内点击直接
转发，缺少与其他直改按钮一致的组件内第二层拒绝。

## 修复

两个按钮回调先拒绝 `photoImportLeaseActive`，再调用原有 `onInsertPhotos()` /
`onInsertMath()`。工具加载禁用、紧凑菜单、页面操作、历史挂起、结构租约和插入事务语义不变。

## 影响与验证

- 新增 ADR-0465，并在既有工具栏 Harmony evidence 文件追加本阶段增量段。
- 扩展工具栏 Builder 共享租约专项 Replay 锁定两项新防线，当前 `TOTAL=6 FAILED=0`。
- ArkTS 目标无错误，仅既有警告与信息级提示。
- 相邻工具直改、面板开关、按钮一致化通过。
- 全量 Desktop Replay `REPLAY_FILES=421 PASSED=421 FAILED_FILES=0`
  （33.131 秒）；clean 3.338 秒、ohosTest HAP 11.084 秒、default HAP 31.320 秒均静态构建成功。
- 未启动模拟器、虚拟机、真机或 Hypium；T-042 继续保留为 Goal 最后任务。
