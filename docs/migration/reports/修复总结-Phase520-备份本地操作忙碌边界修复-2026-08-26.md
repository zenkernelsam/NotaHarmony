# 修复总结 — Phase 520 备份本地操作忙碌边界修复

## 问题

`BackupPage` 的本地“导出全部笔记”和“导入笔记文件”按钮缺少忙碌态响应式禁用；直接点击回调也不先
拒绝 `isBusy`，长任务期间晚到点击只能依赖 `exportAllLocal()` / `importLocal()` 内部共享租约兜底。

## 修复

两个按钮统一加入 `.enabled(!this.isBusy)`；点击回调转发前显式拒绝忙碌态。共享操作租约、文件选择、
云端操作、错误重试、加载生命周期和正常语义不变。

## 影响与验证

- 新增 ADR-0492，并在既有备份页面加载 disposal-bound evidence 文件追加本阶段增量段。
- 扩展 `d02-backup-page-operation-lease.mjs` 至 11 项，当前通过。
- 全量 Desktop Replay 与 clean/dual HAP 静态构建结果见总进展更新。
- 未启动模拟器、虚拟机、真机或 Hypium；T-042 继续保留为 Goal 最后任务。
