# 修复总结 — Phase 497 笔记标题共享租约修复

## 问题

笔记标题的输入与点击编辑已有共享导入租约防线，提交事务内部也会 fail closed；但回车与失焦
直接调用 `saveTitle()`，缺少组件边界第二层拒绝。

## 修复

`TextInput.onSubmit()` 与 `onBlur()` 先通过 `photoImportLeaseActive` 拒绝租约激活状态，再执行
原有保存。标题队列、正常保存、离开流程、历史行为和清理逻辑全部保留。

## 影响与验证

- 新增 ADR-0469，并在既有 Harmony evidence 文件追加本阶段增量段。
- 扩展既有标题共享租约专项 Replay 锁定两项新防线，当前 `TOTAL=12 FAILED=0`。
- ArkTS 目标无错误，仅既有警告与信息级提示。
- 相邻标题生命周期 Replays 通过。
- 全量 Desktop Replay `REPLAY_FILES=421 PASSED=421 FAILED_FILES=0`
  （32.120 秒）；clean 3.252 秒、ohosTest HAP 9.818 秒、default HAP 29.981 秒均静态构建成功。
