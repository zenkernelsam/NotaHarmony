## 现场重放结论

旧总纲所写“completed layer 每帧 transfer、只有单 dirty rect、padding 不随 zoom、临时 bitmap 未释放”已经
不符合当前代码：

- `StrokeLayerManager` 持有 retained `completedBitmap`；普通合成帧只 `drawImage`。
- commit 仅在内容 mutation 时恢复工作层、增量绘制、发布一次新 snapshot，并关闭旧 snapshot；rebuild
  全部绘制后只发布一次。
- `DirtyRectTracker` 最多保留 8 个互不相交区域，超过上限才退化为 union；额外 3 屏幕像素按 `3/zoom`
  转为页面单位。
- ordered partial eraser 与 stroke mask 的临时 bitmap 都在 `finally` 中 `close()`。
- `BitmapTransferTracker` 已分类统计 completed/isolated/pencil transfer、逐帧峰值与 dirty-region 数。

因此没有重复实现 retained bitmap、multi-dirty 或第二套 tile 架构。M2-R-04 的静态主体早已完成，本阶段只补
深审暴露的真实异常边界。

## 实际修改

### Canvas 状态异常安全

以下生产路径的每个绘制状态作用域均改为 `save → try → finally restore`：

- 主画布 `NoteCanvasView.renderFrame()`；
- 普通 dirty composite 与 full-frame transfer 统计；
- `StrokeCanvasPainter` 的普通 Ink、Partial Eraser、mask crop、AudioLinked alpha 与 Pencil clip；
- `Canvas2DStrokeRenderer` 的 fill/custom/center/variable-width/Pencil/mask/Tape；
- `Canvas2DTextRenderer` 的正文与 text-paper clip；
- `PaperRenderer` 的页面、legacy texture filter 与 PDF rotation；
- Shape、Image 与 Thumbnail renderer。

异常没有被捕获或吞掉；只在重抛前恢复当前层的 transform、clip、alpha、filter、line dash 与 composite mode。
`StrokeLayerManager` 的帧统计也放进 finally，失败帧不会把 transfer 记到下一帧。

### 位图所有权

两个 isolated bitmap 路径在取得 `ImageBitmap` 后立即进入 `try/finally`；`recordTransfer()` 或 `drawImage()`
任一失败都执行 `bitmap.close()`。既有 retained bitmap 替换/释放协议保持不变。

### DirtyRect 非有限 zoom

`DirtyRectTracker.markDirty()` 从 `zoom > 0` 改为 `Number.isFinite(zoom) && zoom > 0`。旧条件会接纳
`+Infinity`，导致 `screenPadding / zoom === 0`；现在 `NaN/+Infinity/-Infinity/非正值` 全部回退 1。

更新 `DirtyRectTracker.test.ets`，新增三种非有限值的 ArkTS fixture。Phase 156 ADR、Report 与旧 replay
同步留下更正，避免历史文档继续声称一个当时并未完整实现的边界。
