# 修复总结 — Phase 455 图片裁剪共享租约修复

## 问题

图片裁剪会话可以在照片导入前打开。异步导入释放 `historyBusy` 后、共享租约收口前，
确认裁剪仍会替换图像元素、触发持久化并推入撤销栈，与照片插入结果形成同源并发窗口。

## 修复

裁剪启动与确认统一在内部历史门禁前拒绝 `photoImportBusy`。既有会话仍可调整、重置和
取消，但不能在导入收口前提交；生产字段和裁剪语义不变。
