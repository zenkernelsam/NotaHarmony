# 修复总结 — Phase 469 已打开文本共享租约修复

## 问题

文本提交与取消入口已有守卫，但导入前打开的 `TextBlockOverlay` 本身不感知共享照片导入。
输入仍可更新草稿并触发宽度自适应布局；Done 或 Cancel 可在导入收口窗口内调用父回调，
进而进入历史提交、选区重建或控件状态发布，与导入结果合并竞争。

## 修复

文本层接收共享导入租约并同步禁用 TextArea、Done 和 Cancel。父视图把 `photoImportBusy`
传入组件；`onDraftChange` 与 `onCancel` 先拒绝共享导入租约，再保留历史租约作为第二层
防御。文本草稿模型、宽度自适应语义、提交事务和取消清理不变。
