# 修复总结 — Phase 528 原版小图 EXIF 归一化边界修复

日期：2026-08-29

## 问题

继续复审图片主线时发现，`OriginalImageNormalizer` 将非零 EXIF rotation 作为
独立的 `needsNormalization` 条件。对于 oriented 宽高均不超过 3000px 的小图，
这会错误触发 PixelMap 解码、旋转、缩放和 WebP lossy 85 重编码；原版 `vuh.b()`
在该门限内直接返回原文件。

## 修复

规范化门禁改为只检查 oriented 宽高是否仍满足原版 3000px 安全边界。小图无论
EXIF 旋转角度如何都返回 stable 原始字节、源 MIME 和原始尺寸；显示端继续负责
应用 EXIF 方向。超大图的 encoded-axis 计划、先旋转后缩放、WebP 85、fail-closed
和资源释放逻辑保持不变。
