# Phase 401：移动页发起上下文绑定

日期：2026-08-25（Asia/Shanghai）

## 问题

移动页在 durable 重排序等待期间允许用户切页。旧续体仅检查销毁态，随后仍按原目标索引发布顺序并回设当前页；这会抢夺
导航，并让撤销记录中的页面顺序与真实上下文错位。

## 修复

- `reorderPages()` 返回后先确认当前页仍为发起时的 `selectedPageId`。
- 用户已切页时静默返回；durable 新顺序保留，但不发布 UI 页序、索引或撤销 action。
- 正常路径继续使用既有顺序发布、目标索引设置和撤销推入。
