# 修复总结 — Phase 494 选中自由手切换共享租约修复

## 问题

选中模式的自由手/矩形切换按钮已有响应式禁用；但点击直接调用 `setSelectionIsFreehand()`，
缺少与其他工具直改入口一致的组件内租约防线，导入收口窗口内可能竞态改写选中形状模式。

## 修复

按钮回调先拒绝 `photoImportLeaseActive`，再执行原有取反与持久化流程。工具加载禁用、按钮
标签语义、保存快照、提交回滚和失败提示不变。

## 影响与验证

- 新增 ADR-0466，并在既有 Harmony evidence 文件追加本阶段增量段。
- 扩展工具栏直改共享租约专项 Replay 锁定新防线，当前 `TOTAL=13 FAILED=0`。
- ArkTS 目标无错误，仅既有警告与信息级提示。
- 相邻选中样式共享租约与本地选中样式 Replay 通过。
- 全量 Desktop Replay `REPLAY_FILES=421 PASSED=421 FAILED_FILES=0`
  （32.290 秒）；clean 3.498 秒、ohosTest HAP 10.298 秒、default HAP 30.731 秒均静态构建成功。
- 未启动模拟器、虚拟机、真机或 Hypium；T-042 继续保留为 Goal 最后任务。
