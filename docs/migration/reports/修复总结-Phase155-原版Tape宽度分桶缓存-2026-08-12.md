# Phase 155 修复总结：原版 Tape 宽度分桶缓存与图案周期

## 原版证据

直读 `decompiled_1.0.3/sources/defpackage/qfe.java` 与 `mfe.java`：Tape pattern
缓存 key 包含 `scaleBucket = round(clamp(width, 1..8) * 2)`；bitmap 的创建尺寸按该
bucket 放大。只有 FLOWERS 的中心色额外使用 tapeColor，其他图案只使用 overlayColor。

## 修复

- `Canvas2DStrokeRenderer.renderTapePattern()` 将 `brushWidth` 传入 tile 缓存。
- `getTapePatternTile()` 按原版规则生成 2..16 bucket，并加入缓存 key。
- tile 的逻辑宽高和像素尺寸按 `bucket / 2` 同步放大，恢复不同 Tape 宽度的原版重复周期。
- 保留 32 项 LRU 和 FLOWERS 专属 tapeColor 维度。

## 验证

`d02-original-tape-pattern-scale-bucket.mjs`：`TOTAL=6 FAILED=0`。

本阶段未启动设备、模拟器、虚拟机或 Hypium；Canvas shader 的最终像素密度留待设备验收。
