# Phase 328 修复总结：录音删除失败销毁绑定

日期：2026-08-23（Asia/Shanghai）

## 缺陷与修复

- 录音删除控制器的失败监听器无条件弹 toast；延迟删除在编辑器销毁后失败时，过期回调仍会对已移除页面显示 UI。
- 现在监听器先记录日志，再检查 `editorDisposed`，销毁态跳过 toast。pending-delete 状态仍由控制器权威持有。
