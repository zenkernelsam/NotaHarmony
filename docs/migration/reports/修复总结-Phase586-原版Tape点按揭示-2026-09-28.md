## Harmony 实现

- `EraserEngine.hitStrokeAtPoint`：点命中笔迹渲染带宽（中心线 ±
  brushWidth·widthFactor·scale/2），复用采样管线的 transform/三次
  曲线/widthFactor 语义。
- `ShapeGeometry.tapeHitTestShape` + `shapeCoveredByPath`：与橡皮共用
  覆盖几何，不受 `positionLocked` 约束。
- `NoteCanvasView`：
  - `tapeIdsAtPoint`——笔画 `tapePattern != null` + 形状
    `originalTool === 3` 的全集合点命中收集；
  - `tapRevealTapeAt`——`xo5` toggle + `emitTapeRevealState` +
    `renderFrame(true)`，命中返回 true；
  - `onTouchDown` 在 DEFAULT 分支头部与选区菜单守卫之后先行探测，
    命中即早退（`isDrawing` 保持 false，手势被消费）；
  - `pageTapeIds` 扩展含 tape 形状（与 `vnd` 排序元素域一致）。
