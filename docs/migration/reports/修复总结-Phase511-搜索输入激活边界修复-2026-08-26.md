# 修复总结 — Phase 511 搜索输入激活边界修复

## 问题

库页搜索框 `onChange` 可在页面失活后直接修改 `searchText` 并递增笔记请求代数；虽然后续防抖有
丢弃防线，但入口已经污染共享状态。

## 修复

搜索输入回调先通过 `pageActive` 拒绝失活状态，再执行原查询更新、请求代数递增和防抖调度。
防抖上下文检查、请求身份、结果发布、缩略图刷新和失败提示全部保留。

## 影响与验证

- 新增 ADR-0483，并在既有库页搜索生命周期 evidence 文件追加本阶段增量段。
- 扩展库页搜索生命周期 Replay 至 8 项，当前通过。
- ArkTS 目标无错误，仅既有警告与信息级提示。
- 全量 Desktop Replay `REPLAY_FILES=421 PASSED=421 FAILED_FILES=0`
  （36.193 秒）；clean 3.770 秒、ohosTest HAP 11.303 秒、default HAP 34.820 秒均静态构建成功。
- 未启动模拟器、虚拟机、真机或 Hypium；T-042 继续保留为 Goal 最后任务。
