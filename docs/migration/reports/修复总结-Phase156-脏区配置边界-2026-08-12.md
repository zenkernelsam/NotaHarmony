# Phase 156 修复总结：DirtyRectTracker 配置边界

## 发现

`DirtyRectTracker` 构造函数对 `screenPadding` 和 `maxRegions` 只做 `Math.max`。传入
`NaN/Infinity` 时，异常值会继续进入脏区 padding 或区域上限比较，可能留下 NaN 矩形或使
多区域退化保护失效。

## 修复

- 非有限 padding 回退默认 3，有限值仍 clamp 到不小于 0。
- 非有限区域上限回退默认 8，有限值向下取整且不小于 1。
- 原有非法 zoom 回退 1 的行为保持不变。

## 验证

`d02-dirty-rect-config-boundaries.mjs`：`TOTAL=5 FAILED=0`。

本阶段未启动设备、模拟器、虚拟机或 Hypium；正常脏区合并和设备帧率仍按 M2-R-04 后续验收。

## 2026-08-17 复核更正

Phase 156 对 zoom 的文字结论比实现更强：`zoom > 0` 能回退 NaN/非正值，但会接纳 `+Infinity`，令
`screenPadding / zoom` 变成 0。Phase 258 已改为“有限且大于 0”，补充 ArkTS fixture 与原版 `v0g`
有限 zoom 证据；详见 ADR-0236 与 Phase 258 报告。历史 replay 的对应断言也已从宽松字符串升级为有限值条件。
