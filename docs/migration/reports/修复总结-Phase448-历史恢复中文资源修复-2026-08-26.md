# 修复总结 — Phase 448 历史恢复中文资源修复

## 问题

D-02 的损坏历史恢复功能最初只在默认资源中添加英文标题、说明、“继续编辑”、
“重置撤销历史”以及三种结果 toast。`zh_CN` 资源表后来持续演进，但这七项没有
同步。中文系统进入恢复路径时会回退英文，违反项目双语 UI 口径。

## 修复

在 `zh_CN` 资源中补齐全部七项，并保持与 base 英文逐句对应。中文文案明确笔记内容
安全、操作日志保留、只重置本地撤销栈，以及失败后仍可继续编辑。生产逻辑、按钮
顺序和 ADR-0368 的迟到 reset 防御不变。

## 影响与验证

- 新增 ADR-0420、Harmony evidence 与中文 Report。
- 新增专项 Replay `d02-history-recovery-zh-cn-localization.mjs`，当前
  `TOTAL=9 FAILED=0`；base 与 zh_CN JSON 可解析且键值匹配。
- 未启动模拟器、虚拟机、真机或 Hypium；T-042 继续保留为 Goal 最后任务。
