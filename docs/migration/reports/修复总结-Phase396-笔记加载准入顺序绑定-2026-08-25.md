# Phase 396：笔记加载准入顺序绑定

日期：2026-08-25（Asia/Shanghai）

## 问题

`loadPages()` 先递增 `pageLoadGeneration`，再检查 `editorDisposed || pageLoadInFlight`。因此被拒绝的重入、重复
retry 或销毁前迟到调用虽然没有启动新加载，也会让正在执行的当前加载代失效；活动续体会在下一个门禁处静默返回，
而系统没有新的替代加载。

## 修复

- 将销毁/in-flight 准入检查移动到加载代际递增之前。
- 只有成功取得执行权的加载才递增代际并设置 `pageLoadInFlight`。
- 所有 await 后生命周期/代际复查、异常状态回滚和 finally 清理保持不变。
