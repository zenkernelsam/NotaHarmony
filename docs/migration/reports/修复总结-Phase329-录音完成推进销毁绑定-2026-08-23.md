# Phase 329 修复总结：录音完成推进销毁绑定

日期：2026-08-23（Asia/Shanghai）

## 缺陷与修复

- `advanceAfterRecordingCompletion()` 在 `recordingController.load()` await 后没有生命周期检查；编辑器在录音
  播放完成时被销毁，过期续体可对已释放控制器驱动 load，且 `completionAdvanceInFlight` 可能永久卡住。
- 现在入口检查 `editorDisposed` 并重置标志后返回；load 完成后也重置标志，保证未来完成事件可正常推进。
  销毁后不再发起新的控制器 load。
