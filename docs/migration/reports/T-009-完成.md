## 改了什么

创建 2 个纯数学算法模块（零平台 import）：

1. `note/src/main/ets/core/algorithm/ForceSmoother.ets`
   - `interface ForceSmootherConfig`（enabled=true / smoothingWindowMs=8 / maxForceChange=0.15，对应 §17 dr4）
   - `class ForceSmoother`：smooth() 对每点限制相邻 pressure 变化 ≤ maxForceChange（clamp 到 lastForce ± 0.15）；pressure=-1 跳过；reset() 重置 lastForce；不修改原数组

2. `note/src/main/ets/core/algorithm/CubicFitter.ets`
   - `interface FitterConfig`（maxPointsPerSegment=200 / contextExpansion=5 / baseTolerance=0.5）
   - `class CubicFitter`：
     - fit()：动态容差 `(0.5 / ((((Math.log(baseWidth*zoom) - 2.6) / 15.4) * 1.5) + 1.0)) / zoom`（dd4.d() 用 Math.log 近似，注释标注待逆向确认）
     - fitCubic()：三次 Bernstein 基 + 2×2 正规方程最小二乘求 p1/p2；行列式 ≈0 或非有限结果 → 直线三等分回退；上下文 ±5 点扩展（拟合用扩展区间、误差验收用目标区间）
     - maxError()：t 步长 0.02 逐点采样曲线求最大欧氏距离
     - fitRecursive()：超容差二分分段，200 点上限截断
