# Phase 410 修复总结：资料库删除查询上下文绑定

## 背景

Phase 409 使删除能在权威读取期间接管 loading 并重查当前 folder。但 replacement read 未保留 `loadNotes(query)` 的搜索词；搜索加载中删除后，可能把未过滤列表发布回搜索视图。

## 修复

1. `LibraryViewModel` 保存最近权威读取的 `activeQuery`。
2. 删除接管 loading 时使用该 query 与当前 folder 构造替换读取。
3. 替换读取继续复用 search/floor 分支、stale/mutation 重试和 guarded finally。
4. 已提交删除保持不可撤销；后续 mutation 仍可让 replacement 失效。

## 证据与验证

- 新增 ADR-0387、Harmony evidence、中文 Report；专项 Replay 加强为 6/6。
- ArkTS fixture 覆盖搜索 `alp` 中删除 `Alpha` 的场景，确保未过滤 `Beta` 不进入 UI。
- 相邻资料库变更顺序 Replay 保持 8/8；相邻 mutation lifecycle Replay 保持 10/10。
- 全量 Desktop Replay 通过 `REPLAY_FILES=366 PASSED=366 FAILED_FILES=0`。

## 边界

本次没有启动模拟器、虚拟机、真机或 Hypium。静态验证不替代设备端到端验收；T-042 继续 Goal 最后一项。
