# Phase 159 修复总结：输入样本有限边界

## 发现

输入适配器对 pressure、tilt、orientation 只检查非负数。`Infinity` 会被错误地 clamp 为合法输入，方位角可能归一化为 `NaN`；非法 timestamp 也会污染 elapsed time。

## 修改

- `note/src/main/ets/core/adaptation/InkInputProviderImpl.ets`
- 新增 `ADR-0136-input-provider-finite-sample-boundaries.md`
- 新增 `d02-input-provider-finite-sample-boundaries.mjs`

非法浮点样本现在回退到契约 sentinel `-1`，非法时间回退零 elapsed；有限真实样本的原有映射不变。

- `note@ohosTest assembleHap`：`BUILD SUCCESSFUL`
