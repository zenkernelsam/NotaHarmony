# 修复总结 — Phase 436 录音列表页面失败代际修复

日期：2026-08-25

## 问题

`loadPages()` 成功读取 note、页面和背景后调用 `loadRecordings()`。若录音查询仍在飞时出现第二次录音
加载，旧录音续体可先发布新快照；随后当前代页面加载失败，catch 会重置页面和录音失败投影，但不会递增
`recordingLoadGeneration`。更旧的录音续体仍能通过自身代际检查，把失败界面覆盖回过期录音数据。

## 修复

页面失败路径在通过当前代与未销毁检查后、应用失败投影前递增 `recordingLoadGeneration`，使所有先前
录音请求失效。过期或已销毁的页面续体仍直接返回；`loadRecordings()` 的成功/失败守卫和同代
`recordingsLoading` 清理语义保持不变。

## 验证

新增专项 Replay `d02-recording-list-page-failure-generation-bound.mjs`，锁定失效顺序、显式失败投影和
过期发布边界，结果 4/4。既有编辑器初始化与录音列表 failure disposal Replay 继续通过。其余全量验证见
总进展补录。未启动模拟器、虚拟机、真机或 Hypium。
