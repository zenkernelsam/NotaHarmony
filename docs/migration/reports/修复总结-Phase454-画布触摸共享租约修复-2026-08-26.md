# 修复总结 — Phase 454 画布触摸共享租约修复

## 问题

照片导入异步持久化释放 `historyBusy` 后、外层 `finally` 收口前，画布触摸入口仍能启动
新交互。文本双击可立即替换复选框、创建文本块并推入撤销栈；书写、擦除和选区拖拽也会在
结束时进入同一文档状态，形成 Phase 451-453 之后的相邻旁路窗口。

## 修复

`onCanvasTouch()` 统一入口在内部历史门禁前拒绝 `photoImportBusy`。所有新触摸交互等待
照片导入完全收口；既有加载、裁剪、数学编辑器和下游历史防御不变。
