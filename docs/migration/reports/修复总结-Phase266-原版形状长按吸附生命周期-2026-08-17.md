## 修复前真实缺陷

### 计时器被每个 Move 重置

旧 Canvas 在每个 Move 都调用 `scheduleShapeDetection()`。即使笔尖只抖动 1px，也会取消并重建 500ms timer，
导致真实手写几乎无法稳定达到吸附窗口。

### 吸附后候选会被撤回

旧实现每次 schedule 先清空 `heldShapes`。用户看到候选后继续移动，Canvas 会恢复活动原笔迹并重新计时；这与
原版保持 Shape 并调整终点/尺度的交互相反，Up 最终点也不会参与候选调整。

### confidence 和近圆规则偏离原版

默认 gate 为 0.5 且等于阈值会通过；近圆只在轴差小于 5% 时归零，还在归一化后重新评分。原版分别是严格
`>0.2`、两分支宽松近圆和“先评分、后归一化”。

### 内部分类名与持久联合混淆

旧进展曾把资源/内部八类名称当作需要扩展八种持久 Shape。原版实际只发布 LINE/POLYGON/ELLIPSE 最终联合，
若新增任意 Path/Arrow 持久类型会偏离 wire 和 renderer 契约。

## 实际修改

### 纯逻辑 hold lifecycle

- 新增 `ShapeHoldLifecycle.ets`：精确 500ms 常量、handwriting ×4 规则、明确命名的 Harmony touch fallback 和
  `ShapeHoldPauseTracker`。
- pause tracker 使用 screen coordinates；首点启动，sub-slop 返回 false 保留 timer，达到阈值才推进 anchor。
- baseSlop 只接受有限且大于 0 的值；NaN、0、负数不会把阈值变成不可用状态。

### 吸附后非累积 adjustment

- 新增 `ShapeHoldAdjustment.ets`，在识别成功时深拷贝 base Shapes；所有后续结果都从 base 计算，避免累计漂移。
- 单 LINE 固定 start，移动 end，并以 parallel/perpendicular 分解相似变换 cp1/cp2；ID、arrow、Tape、force、
  effect/tint 和 originalCreate 均由共享 clone 保留。
- 非 LINE 实施 5px gate；Ellipse 围绕中心统一缩放半径且保留 rotation，Polygon/多定义结果围绕聚合 anchor 缩放。
- malformed geometry、非有限 point/transform、坏半径或坏 vertices fail closed。

### Canvas 生命周期接线

- Down 调用 `beginShapeHold()`；Move 在未吸附时只按 pause tracker 决定是否重启，吸附后直接调整 Shape。
- timer callback 先把 ID 置 `-1`，再核对 drawing/tool/session；成功后启动 adjustment，不再清空已吸附 Shape。
- Up 的 final changedTouch 先进入 adjustment，再提交整批 Shapes；normal Up、Cancel、第二指、指针丢失、翻页、
  load failure 和 `aboutToDisappear()` 都共享完整 reset。
- 取消候选会触发重绘，避免 held preview 残留。

### Detector 接受规则

- `ShapeDetector` 默认 confidence 改为原版 0.2，并以 `<= threshold` 拒绝等值。
- Ellipse 先计算 fit score，再按原版两分支规则改为平均半径圆；大椭圆 ratio=0.6 不套用小椭圆例外。
- 文件头明确内部八类到最终三类的映射，并公开箭头/圆弧/曲线主动分类器仍未等价实现。
