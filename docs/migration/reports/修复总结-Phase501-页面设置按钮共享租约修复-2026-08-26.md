# 修复总结 — Phase 501 页面设置按钮共享租约修复

## 问题

页面设置按钮已有响应式禁用，弹窗内容也会在共享导入租约激活时被抑制；但点击回调没有组件级
拒绝，仍可提前把弹窗状态置为可见。

## 修复

按钮点击先通过 `photoImportLeaseActive` 拒绝租约激活状态，再打开原有页面设置弹窗。弹窗布局、
状态回流、纸色草稿能力和父页防线全部保留。

- 扩展页面条共享租约 Replay 至 16 项，当前通过。
- ArkTS 目标无错误，仅既有警告与信息级提示。
- 全量 Desktop Replay `REPLAY_FILES=421 PASSED=421 FAILED_FILES=0`
  （35.580 秒）；clean 3.524 秒、ohosTest HAP 11.445 秒、default HAP 32.259 秒均静态构建成功。
