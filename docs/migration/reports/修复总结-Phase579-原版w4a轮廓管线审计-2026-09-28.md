# Phase 579 — 原版 w4a 可变宽度轮廓管线审计（2026-09-28）

## 目标

关闭审计注册表挂起的 `w4a.java`（可变宽度轮廓）可验证半区。

## 关键解码（1.0.1 混淆表；1.0.3 的 w4a 是无关 switchmap）

- `w4a.a(xw0, d2)`：累积距离简化。建轮廓前 `y5a.n` 用 0.0（规范化），
  擦除产出 `lqh.b`/`b2j` 用 0.1 抽稀。
- `w4a.b(xw0, scale)`：轮廓生成器。退化单点 → 半径 `w·0.5·scale`
  的圆（z71）；宽度链常量与 Phase 269 移植逐字一致（1e-6 弦长、
  PCHIP 导数、0.25/0.5/0.75 探针、1.2 安全系数、0.5% 容差、2..6
  细分钳制）。
- `y5a.n` 分派：DASH/DOTS 走中心线描边，实心走填充轮廓 —— 与
  Harmony `renderCenterPath`/轮廓填充一致。
- `lqh.b`：擦除轮廓 `b2j.a` 自交检查 + 递归二分。Harmony 用
  `drawing.Path.op` 原生布尔 —— 有意发散（能力更强），ADR-0550。

## 决策

不改代码。可验证半区全部对齐或为超集；装配几何（offset/内部弧）
因 JADX `??` 破型继续挂起，维持 ADR-0002 近似与 M2-A-09 决策门。
