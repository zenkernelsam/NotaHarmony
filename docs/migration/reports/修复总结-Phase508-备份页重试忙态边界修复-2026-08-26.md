# 修复总结 — Phase 508 备份页重试忙态边界修复

## 问题

备份页错误态重试按钮依赖 `.enabled(!isBusy)` 作为唯一防线；若备份操作切换竞态导致晚到点击，
回调可直接执行 `reloadPage()`，递增加载代数并把配置状态切回 LOADING。

## 修复

重试按钮回调先通过 `isBusy` 拒绝进行中的备份事务，再调用原有 `reloadPage()`。页面初始化、返回
刷新、共享备份操作租约、生命周期守卫和正常错误恢复全部保留。

- ArkTS 目标无错误，仅既有警告与信息级提示。

  （32.477 秒）；clean 3.255 秒、ohosTest HAP 9.810 秒、default HAP 29.377 秒均静态构建成功。
