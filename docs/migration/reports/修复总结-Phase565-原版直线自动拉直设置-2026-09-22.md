# 修复总结 — Phase 565：原版直线自动拉直设置

日期：2026-09-22

## 原版行为（硬证据）

`x22.java` 的 "Handwriting & drawing" 小节中，**直线拉直与形状识别是
两个独立开关**（`l59.c`/`l59.d`，datastore 键 `straightLinesEnabled`/
`shapeDetectionEnabled`，o59.c 均缺省 true），共用同一按住手势：

- case 0 "Straight lines" + v22 case 20 说明："用钢笔/铅笔/荧光笔画线，
  继续按住即自动拉直"（LINE 结果）
- case 1 "Shapes detection" + v22 case 21 说明："画形状，继续按住即
  自动识别"（其余形状结果）

移植前缺陷：Harmony 只有 `shapeDetectionEnabled` 单一开关，关掉它会
连直线拉直一起关掉，且没有直线开关。

## Harmony 落地

- `EditorSettingsStore.ets`：`straightLinesEnabled` 偏好键（沿用原版
  键名），共享布尔助手；`DEFAULT_STRAIGHT_LINES=true`。
- `EditorViewModel.ets`：`initialize` 同点加载。
- `NoteCanvasView.ets`：
  - `shapeDetectionAvailable()` 改为 `straightLinesEnabled ||
    shapeDetectionEnabled`（任一开启即允许按住手势），工具集仍为
    钢笔/铅笔/荧光笔（原版说明明确列出）。
  - `tryShapeDetect` 对 `result.elements` 按类别过滤：LINE 需
    `straightLinesEnabled`，其余需 `shapeDetectionEnabled`。
- `SettingsPage.ets`：新增 "直线" 行（标题+原版说明）置于 "Shapes
  detection" 之前（对齐 x22 顺序），并为 shape_detection 行补上
  原版说明（此前缺失）。
