# 修复总结 — Phase 491 选中样式按钮共享租约修复

## 问题

工具栏选中样式按钮已有响应式禁用，父页与画布信号也有多层防线；但组件内点击直接转发，租约
切换竞态中仍可先发布样式变更。

## 修复

按钮回调先拒绝 `photoImportLeaseActive`，再调用原有父页回调。工具加载禁用、Taper 可用性、
页面操作、历史挂起、结构租约和选中墨迹事务语义不变。

- ArkTS 目标无错误，仅既有警告与信息级提示。
