# Phase 247 修复总结：原版默认模板设置路由与 Picker 提交边界

## 本阶段目标

纠正 Phase 246 临时放置的默认纸张 UI 入口，严格区分原版设置页 `rge` 与编辑器 `vge` 的职责，并恢复
“尺寸/方向先暂存、点模板卡才提交”的原版 picker 交互。

## 原版硬结论

- `kge` 是设置导航的 `TemplateRoute`；`x90/a1/z22` 把 `feature_settings__template` 接到 `fcj/rge`。
- `rge → nge case 1 → o59.d(ss8)` 才会写 `selectedDefaultTemplate`。
- 编辑器 `vge/xyd` 没有 `o59` 依赖，只通过 `uge` 写当前 note background。
- 两套 ViewModel 的 size/orientation callback 都只修改草稿 state，选择模板卡时才组合提交。
- 收藏与非 Plain spacing 由两端共享的 `BackgroundInfo/rs0/ige` 数据库维护，Harmony 尚未移植。

完整证据见
`docs/migration/evidence/original-default-template-route-jadx-2026-08-16.md`。

## 已完成修复

1. 新增 `DefaultTemplatePage.ets`，在 Settings 中提供独立“Template”入口，并注册页面路由。
2. 默认页从 `EditorSettingsStore` 读取 root `nz9` 默认模板；保存仍写同一个
   `noteEditorSettings.selectedDefaultTemplate`，失败回滚 UI 并提示。
3. 新增 `OriginalTemplatePickerState.ets`，把 paper size/orientation 建模为草稿，模板卡选择作为唯一提交边界。
4. picker 在同线型尺寸/方向变化时保留现有颜色、spacing 与 legacy paper index；跨线型使用内建 spacing。
5. `PageSettingsPanel` 改为受控 picker：切换尺寸/方向不再关闭或立即写数据，点模板卡才调用 `onApply`。
6. `PageManagerBar` 保持模板 popup 打开，让用户连续比较和选择；busy 时整面板禁用，避免并发提交。
7. `NotePage` 删除 `saveDefaultNoteBackground()` 和 editor default callback。编辑器不再污染新笔记默认值。
8. 中英文资源补齐独立页面标题、说明、loading/error/save failure 与 picker 操作提示。

## Phase 246 更正

Phase 246 对二进制偏好、bootstrap 与两页创建的结论仍然有效；仅“把设为默认纸张按钮放在编辑器 popup”这一
UI 接入被本阶段原版证据推翻。对应 ADR、evidence、旧 replay 和旧报告已追加 correction，避免以后重新引入。

## 边修边审新增缺口

- 原版 favorite/unfavorite 不是普通 Preferences，而是 `BackgroundInfo` 数据库中的完整 `l3a` 集合；设置页与
  编辑器共享同一收藏状态。
- Lines/Grid/Dots 各自有独立 spacing 流；Harmony 当前只有背景内的单一 spacing 值，跨线型无法恢复用户为
  每种纸张分别保存的间距。
- 原版默认页与编辑器还支持 paper color 和 legacy paper index UI；当前 codec 能保留，但 UI 尚不可编辑。

这些项已记录为后续静态可闭环任务，不在本阶段宣称完成。
