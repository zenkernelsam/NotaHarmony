# Phase 548：原版文件夹搜索域

日期：2026-09-22

## 选题

原版文件夹内搜索默认限定文件夹，搜索激活时给出
"Show results for all notes" 开关（`bk9` FolderFilter）扩至全部
笔记而不离开文件夹；占位符为 `Search in "{folder}"`。Harmony 已有
文件夹限定搜索，但缺扩展开关与占位符。

## 原版现场重放

- `bk9` = `FolderFilter(name, isShowingAllNotes)`。
- `yj9:852` 占位符按文件夹态切换；`yj9:1726` 搜索激活时渲染
  `folder-filter-toggle`；`mhh` = 标签 + `e9e.a` 开关。

## Harmony 落地

- VM `searchAllNotes` 标志：`setFolder`/`setSection` 重置（含回滚
  恢复），`queryNotes` 在开启时改走全库 `searchNotes(query,null)`；
  `setSearchAllNotes(on,query)` 重新加载。
- 页面：`searchPlaceholder()` 文件夹态用 `search_in_folder`；
  搜索激活且处于文件夹时渲染"显示所有笔记的结果"Switch，切换走
  笔记请求代际守卫。
- 双语言字符串（EN 值与原版一致）。
