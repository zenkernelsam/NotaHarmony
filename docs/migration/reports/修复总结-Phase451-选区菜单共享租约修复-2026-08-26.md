# 修复总结 — Phase 451 选区菜单共享租约修复

## 问题

照片导入的异步持久化在释放 `historyBusy` 后、`finally` 收口前留下一个窗口。
选区菜单入口未检查 `photoImportBusy`，因此 CUT、GROUP、UNGROUP、排序、翻转、锁定
或粘贴可在该窗口改写元素与撤销状态，绕过 Phase 447 引入的照片导入共享租约。

## 修复

`onSelectionMenuAction()` 在原有健康、页身份和 `historyBusy` 门禁前增加
`photoImportBusy` 检查。所有菜单命令统一等待导入收口；COPY 虽然无文档写入副作用，
也保持同一入口语义。生产状态字段和各 action 逻辑不变。
