## 改了什么

创建 `note/src/main/ets/core/algorithm/PencilSplatGenerator.ets`（纯数学模块，§18 xaa.b()/xaa.d() 完整公式）：

- `interface SplatGeneratorConfig`：spacing=2.0 / pressurePower=5 / tiltNormalize=-0.94248 / ellipseShrink=0.9 / angleStep=π/125 / maxSubdivisions=26 / lcgMultiplier=1118393071 / lcgModulus=1946926193
- `interface CurveWalkPoint`（pos + tangent，ArkTS 不允许对象字面量类型）
- `class PencilSplatGenerator`：
  - generate()：沿曲线等距行走（spacing），弧长比例插值 pathPoints 属性（width 由 widthFactor 插值，pressure 反推 0.3+0.7 映射），逐位置 generateAtPosition
  - generateAtPosition()：完整公式——压感⁵ `sizePressure = 1-(1-min(p,2)/2)⁵`、倾斜归一 `sizeTilt = 1-min((tilt-π/2)/(-0.94248),1)⁵`、sizeFactor 混合、scaleBase/angleDiff/splatCount(≤26)/ellipseR/ellipseS/baseScale、每 splat 的 θ/r/椭圆收缩 0.9/len/切线偏移/rotation/opacity（(1-√u1)·edgeFactor·scaleBase）
  - nextRandom()：LCG 拆分乘法（基数 2^10）模拟取模，避免 double 精度丢失，确定性可复现；默认 seed=42
  - advanceByDistance()：段定位 + 段内二分弧长（40 次迭代）；pointOnSegment() 提供位置与单位切线
  - 无能力输入 fallback：pressure=-1→0.5、tilt=-1→π/4、orientation=-1→0；spacing≤0 返回空
