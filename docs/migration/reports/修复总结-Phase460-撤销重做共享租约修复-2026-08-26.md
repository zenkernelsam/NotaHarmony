# 修复总结 — Phase 460 撤销重做共享租约修复

## 问题

照片导入释放内部历史租约但尚未收口共享租约时，工具栏撤销/重做仍可进入统一历史
路径。该路径会取消裁剪、应用元素或页历史并推进撤销栈；跨页分支还可请求切页，
与照片结果竞争。

## 修复

父页撤销/重做回调在发信号前拒绝照片导入租约；Canvas `performHistory()` 在内部
历史门禁前拒绝同一租约。双层闸门不新增状态字段，不改变历史分组、跨页恢复或
裁剪取消语义。
