# 修复总结 — Phase 485 工具颜色粗细共享租约修复

## 问题

工具面板的颜色格与粗细滑杆已有响应式禁用，但直接回调缺少组件内第二层防线。共享导入收口
窗口内，晚到的点击或滑杆事件仍可能更新选中墨迹属性或活动笔刷状态。

## 修复

`ColorPickerView` 点击回调和 `WidthSlider` 变更回调先拒绝 `photoImportLeaseActive`，再执行
选中模式或普通笔刷的原有逻辑。父页选中回调既有防线、工具状态乐观更新和持久化语义不变。

## 影响与验证

- 新增 ADR-0457、Harmony evidence 增量段和本中文 Report。
- 扩展工具控件共享租约专项 Replay 锁定两项新防线，当前 `TOTAL=11 FAILED=0`。
- ArkTS 两个目标无错误，仅既有警告与信息级提示。
- 相邻工具直改、面板开关、按钮一致化和选中样式 Replay 通过。
- 全量 Desktop Replay `REPLAY_FILES=421 PASSED=421 FAILED_FILES=0`
  （35.912 秒）；clean 3.544 秒、ohosTest HAP 11.218 秒、default HAP 34.746 秒均静态构建成功。
