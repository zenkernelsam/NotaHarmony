# 修复总结 — Phase 509 文件夹展开忙态边界修复

## 问题

文件夹展开/折叠按钮依赖 `.enabled(!folderBusy)` 作为唯一防线；若忙碌事务切换导致晚到点击，
回调可直接修改展开集合，并在选择、增删改或拖放收尾时发布过期树形状态。

## 修复

`toggleFolderExpanded()` 现在先通过 `folderBusy` 拒绝进行中的文件夹事务，再执行原有展开集合
更新。按钮禁用、文件夹菜单、选择、拖放、生命周期守卫和原子持久化全部保留。
