# Phase 546：原版库排序字段与方向

日期：2026-09-22

## 选题

原版库排序为字段×方向二维（`he7`/`je7`），UI 为字段 chip + 方向
箭头（`inh.b`），下拉含字段行与方向行（`vc2`）；Harmony 此前只有
3 个固定方向模式，无法表达 Modified-asc、Name Z→A。

## 原版现场重放

- `z97`：prefs 默认 MODIFIED_DATE + DESCENDING。
- `pk9.s`：NAME→collator 排序、CREATED→fh7(10) asc、
  MODIFIED→fh7(11) asc；DESC 经 `au1.E1` 反转；RECENT 区段
  在 `mk9` 中绕过（已落地）。
- `inh.b`：字段 chip（点击开下拉）+ `SortDirectionArrow` 按钮
  （desc 旋转 180°，点击直接切反向）。
- `vc2`：下拉 = 3 字段行（当前 ✓）+ 分隔线 + 2 方向行，方向标签
  随字段变化（NAME→"A to Z"/"Z to A"；日期→"Oldest/Newest"）。

## Harmony 落地

- VM 新增 `sortDescending`（默认 true）+ `setSortDescending`；
  `applySort` 改为字段升序 + reverse（pk9.s 逐行对应）。
- 页面新增 `library_sort_dir` 持久化；侧栏头部 = 字段名 chip
  （菜单含 3 字段 + 2 方向行）+ ↑/↓ 方向按钮；紧凑模式复用同一
  菜单构造器。
- 方向标签字段感知；新增 7 条双语言字符串。

## 登记差异

- bindMenu 无 ✓/分隔线；箭头为字形切换而非旋转；NAME 用
  localeCompare（原版为 collator）；`ie7` 网格/列表视图切换未移植。
- 旧 TITLE 模式默认方向由 asc → desc（Z→A），与原版一致。
