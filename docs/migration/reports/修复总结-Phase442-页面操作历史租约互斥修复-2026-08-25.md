# 修复总结 — Phase 442 页面操作历史租约互斥修复

日期：2026-08-25

## 审计范围

复核 `NoteCanvasView.performHistory()` 触发跨页 undo/redo 时，`NotePage.historyPending`
能否覆盖所有会改变页序、页面内容或选中页的路径；相邻核对删除租约、翻页导航和标题保存队列。

## 缺陷

`historyPending` 只阻断上一页/下一页导航，`runPageOperation()` 仅检查
`pageOperationBusy`。因此跨页历史等待目标页时，新增、删除、移动、背景等页面操作仍可运行，
可能使挂起命令持续等待错误目标或在旧状态上失败。

## 修复

`runPageOperation()` 现在在执行前拒绝忙碌页面操作、跨页历史租约或删除结构租约。
三个页级历史回调统一改走 `runPageHistoryOperation()`：包装器在整个持久化历史应用期间持有
`pageOperationBusy`，并在 `finally` 精确释放。标题与元数据原有的飞行计数门禁保留。

## 变更证据

新增 ADR-0414、Harmony evidence、中文 Report 和专项 Replay
`d02-page-operation-history-lease-bound.mjs`（10/10），锁定结构入口三重门禁、历史包装器
获取/释放顺序、三类回调路由以及相邻导航与删除租约不变量。验证结果见总进展补录。
