# Phase 365 修复总结：录音列表失败销毁绑定

日期：2026-08-24（Asia/Shanghai）

## 缺陷与修复

- `loadRecordings()` 成功续体已联合检查销毁态与请求代数，但失败续体只比较代数；同一 await 的同步失败或
  代数更新与异常同轮完成时，已销毁 NotePage 仍可清空 recordings、重建时间线并弹 toast。
- 现在失败续体使用与成功续体相同的 `editorDisposed || generation mismatch` 门禁；陈旧或销毁失败不发布本地
  UI。同代 finally 继续权威清理 loading，成功路径与刷新契约不变。
