# Phase 340 修复总结：原版粘贴预留销毁绑定

日期：2026-08-23（Asia/Shanghai）

## 缺陷与修复

- `pasteClipboard()` 在等待 `reserveOriginalInkCreate()` 前设置 `historyBusy`；成功回调未检查编辑器生命周期，失败路径无条件发布保存失败。页面在异步预留期间离开时，迟到结果可进入过期或销毁上下文。
- 成功与失败发布现在统一使用 `isHistoryPageContextCurrent(generation, pageId)`；该判定包含 `lifecycleActive`。过期失败只记录日志，不再触达当前页面 UI。`.finally()` 保持无条件复位 `historyBusy`，避免新页面死锁。
