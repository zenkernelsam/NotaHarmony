# Phase 321 修复总结：录音会话定时器销毁绑定

日期：2026-08-23（Asia/Shanghai）

## 缺陷与修复

- 录音进行中时，`NotePage` 用 250ms 定时器轮询会话快照；但页面销毁只调用 `finishRecordingSession()`，
  没有先取消该定时器。
- 销毁与录音释放竞争时，迟到 timer 可在控制器释放开始后再次读取快照、更新已销毁页面的状态并重新排程。
- 现在进入 `aboutToDisappear()` 后立即调用 `cancelRecordingSessionRefresh()`；标题保存、监听退订、播放器释放、
  删除 flush 和会话 finish 都在其后执行。活跃录音的正常轮询路径保持不变。
