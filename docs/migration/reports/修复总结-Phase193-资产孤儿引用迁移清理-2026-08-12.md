# Phase 193 修复总结：资产孤儿引用迁移清理

## 发现

历史数据库中的 `note_asset.note_ids` 可能包含已删除笔记、重复 ID 或失效 JSON；新写入
门禁无法自动修复这些旧数据。

## 修改

- 数据库版本提升至 62
- `DatabaseManager` 启动事务中结构化清理资产引用
- 新增 ADR、replay 和本报告

## 验证

- Replay：`TOTAL=10 FAILED=0`
- 后续补强：非法 JSON/元素的损坏记录在事务内移除，单条损坏不再阻塞整个数据库启动；物理文件留给后续垃圾回收。
- HAP/设备测试：本轮未执行

## 未闭环

本迁移不删除已无引用的物理文件；垃圾文件需要后续可观测清理任务。
