# 修复总结 — Phase 573：原版编辑器 ⋮ 选项菜单（App settings）

## 目标

补齐原版编辑器工具行尾端的 ⋮（More options）溢出菜单：原版生产
构建中该按钮无条件渲染，Harmony 此前完全没有编辑器溢出菜单入口。

## 原版行为（decompiled_1.0.3）

- `x90.java:10582`：`rh8.f(...)` 无条件调用——⋮ 按钮始终可见。
- `rh8.java:1504`：hamburger 图标 + `toolbar_more_menu` =
  "More options" 无障碍描述。
- 菜单项（`rh8.java:1530~1600`）：
  1. Template settings — `lc4.a(ac4.P)`（TEMPLATE_SELECTION，
     PRODUCTION + 远端键 androidTemplateSelection）。
  2. Version history — `lc4.a(ac4.d0)`（VERSION_HISTORY，
     PRODUCTION + 远端键 androidVersionHistory）。
  3. **App settings — 无条件**（`rh8.java:1563`，无旗标包裹）。
  4. Inky — `sc9.j` 运行时状态门控（AI 吉祥物）。
  5. Disconnect stylus — `t9f.e`/`t9f.f` 手写笔连接状态门控。
- 本 Phase 同时纠正了早期排查的一个误记：⋮ 菜单并非
  INTERNAL_USERS_ONLY 门控——`ac4.O0` 实为
  NOTE_YOUTUBE_TRANSCRIPTION，控制的是工具行中另一内部按钮。

## Harmony 实现

- `NotePage.ets`：导航行 Recordings 之后新增 `...` 按钮
  （a11y = `toolbar_more_menu`），`bindMenu` 绑
  `buildEditorOptionsMenu()`；enabled 守卫与 Recordings 一致。
- 菜单仅含无条件项 "App settings"（`options_menu_app_settings`，
  EN "App settings" / zh "应用设置"）→ `navigateToSettings()` →
  `router.pushUrl('ui/settings/SettingsPage')`，与 LibraryPage
  同路由同守卫。
- 旗标/状态项（Template settings、Version history、Inky、
  Disconnect stylus）fail-closed 不移植：原版旗标关闭时项整体
  不渲染而非灰显，Harmony 无对应屏/状态面，菜单不放占位项。

## 验证

- 新增 Replay：`d02-original-editor-options-menu.mjs`（28/28）。
- 全量 Desktop Replay：468/468 全绿。
- `note@default`、`note@ohosTest` HAP 构建成功。

## 差异与局限

- 原版为 hamburger 矢量图标，Harmony 沿用工程内文本 `'...'` 按钮
  惯例（与 PageManagerBar more-actions 一致）。
- 旗标项缺失使菜单更短，属主动 fail-closed。
- 详见 ADR-0544 与证据文档
  `original-editor-options-menu-harmony-2026-09-22.md`。
