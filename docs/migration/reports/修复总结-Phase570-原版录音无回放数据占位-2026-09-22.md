# 修复总结 — Phase 570：原版录音面板“无回放数据”占位文案

## 目标

对齐原版录音回放面板的空态：当录音已选中但时间线无可用数据时，显示原版
占位文案而非禁用的 `0:00` 滑块。

## 原版证据

- 类：`faj.java`（decompiled_1.0.3）
- 资源：`feature_note_toolbox__no_playback_data_available`
  = "No playback data available"
- 逻辑：时间线空变体 `jpa.a` → 渲染占位文案；数据变体 `kpa` → 渲染播放器
  控件（滑块/时间戳/±10s/倍速）。

## Harmony 修改

`note/src/main/ets/ui/editor/RecordingPanel.ets`：

- 时间线块改为 `cumulativeDurationMs <= 0` 分支：
  - 空态：仅 `Text($r('app.string.no_playback_data_available'))`，居中、
    次要文本色、12sp。
  - 数据态：滑块 + 时间行（当前时间、±10s、总时长）。
- 时间行整体移入 else 分支——空态不再显示 `0:00` 或跳转按钮。

资源：

- `base/element/string.json`：`no_playback_data_available`
  = "No playback data available"（逐字）
- `zh_CN/element/string.json`：无可用的回放数据

## 差异

- 无功能差异；倍速行保留原位置（原版空态下倍速控件归属无独立证据）。

## 回放与验证

- 新 fixture：`d02-original-no-playback-data.mjs`（10 断言：
  字符串逐字、空分支结构、滑块/时间行归属 else、seek 钳位不变）。
- 全套回放：465/465 通过。
- `note@default` + `note@ohosTest` HAP 构建成功。
