# Phase 416 修复总结：选区寄存器页面作用域重置

## 问题

Phase 415 让工具栏正确回显选中笔迹样式后，补审发现更早的生命周期缺口：翻页成功会取消选区，但
NotePage 里的 `selectionInkColor`、`selectionInkWidth` 和 `selectionInkStyle` 不重置。这些值既是工具栏
上下文，也是 Canvas 收到 signal 后执行批量修改的来源。

## 修复

- `onSelectionInkControlsChanged` 改为 nullable 寄存器更新；正常选择只写入实际观察到的字段。
- 页面数据加载完成并执行 deselect 后，Canvas 显式发布默认寄存器：color/width/style 为 null，
  宽度范围回到 0.5–30，Taper 可用。
- NotePage 对 null 不覆盖，对实际值同步；UI 下一次渲染自然回到默认态。
- 加载失败回滚到原页时不重置，避免丢失原页有效上下文。

## 原版对照

1.0.3 `xsc.m()/s()/t()` 把 selection state 原子重置为空态；`xsc.v()` 遇到跨页选择显式失败。
因此选区命令上下文不应跨 page identity 存活。

## 验证

- ArkTS 检查 Canvas/Page/Toolbar 无错误；既有 warning/info 保持不变。
- 专项 Replay 加强断言 nullable 回调、翻页 reset 和同页首合格笔迹策略。
- 相邻 Ink color/width 与 style Replay 通过；全量 Replay 370/370 通过；clean + 双 HAP 静态构建成功。
