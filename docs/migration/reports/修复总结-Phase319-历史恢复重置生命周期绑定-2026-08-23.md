# Phase 319 修复总结：历史恢复重置生命周期绑定

日期：2026-08-23（Asia/Shanghai）

## 缺陷与修复

- 损坏历史重置在等待 SQLite 完成前没有生命周期守卫；若用户离开编辑器，迟到成功仍会清空已销毁组件的 Undo/Redo、
  改写恢复状态并弹出完成或失败提示。
- 现在持久化重置成功后先检查 `lifecycleActive`；画布已销毁时只记录 durable reset 已保留，不再触碰内存栈、恢复标志或 UI。
- 失败路径和 finally 双 busy 门保持不变；持久化重置仍是权威边界。
