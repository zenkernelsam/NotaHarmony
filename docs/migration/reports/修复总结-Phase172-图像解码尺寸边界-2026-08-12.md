# Phase 172 修复总结：图像解码尺寸边界

## 发现

`ImageAssetLoader` 原先直接使用底层 `ImageInfo.size` 计算最大边和缩放尺寸，未拒绝零、NaN、无穷或非整数尺寸。

## 修改

- `note/src/main/ets/core/adaptation/ImageAssetLoader.ets`
- 新增 `ADR-0149-image-decode-dimension-boundary.md`
- 新增 `d02-image-decode-dimension-boundary.mjs`

现在异常图像尺寸直接返回 `FAILED`，不会继续计算 `desiredSize` 或构造 ImageBitmap。
