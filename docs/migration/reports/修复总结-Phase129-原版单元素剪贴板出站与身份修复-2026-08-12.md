# Phase 129 修复总结：原版单元素剪贴板出站与身份修复

## 原版证据与边修边审

- 原版 `lg2.g()` 会递归收集选中 Group 的后代，再由 `u5j.c()` 进入模型复制路径并生成全新的操作；
  Paste 不能复用源实体的 CREATE operation identity。
- 原版 `lg2.e()` 从实际生成的操作中提取 CREATE_GROUP，排除嵌套 child Group，再用顶层 Group
  恢复选择。因此完整 Group Paste 是“叶实体 CREATE + 嵌套 Group CREATE + 顶层 Group CREATE”的
  原子图操作，不等价于扁平复制叶子。
- 复核未提交实现时发现，普通剪贴板通过 `transform[2/5]` 表示偏移，但原版 CREATE_INK 与
  CREATE_SHAPE 编码器只接受 identity transform。若直接落盘会在持久层严格预检时失败。另发现
  Stroke clone 漏拷 `isPartialEraser`，会把原版 tool 5 静默降成普通 Pen。

## 已完成修复

- Ink、Shape、Text 剪贴板快照统一移除源 `originalCreate`，杜绝复用源 CREATE identity。
- 剪贴板记录选择是否包含原版 Group；Group、Image/Math、多元素、空 Text、Styled Text 和 Shape
  RichText 均不冒充本阶段的单元素原版 CREATE。
- 单个 canonical Ink/Shape/Text 在预留身份前使用生产 `encodeOriginalLocalCreate*` 严格预检。
  Shape tool/style、填充、锁定、几何或 Text 默认 Block state 不可表示时保守走 compatibility Paste。
- 预检成功后通过既有 reservation 分配全新 canonical ID，把匹配 CREATE metadata 只挂到新元素，
  再由既有持久层写 type 17 CREATE_INK、type 18 CREATE_SHAPE，或 type 22 CREATE_BLOCK + type 8
  INSERT_STRING；operation journal 保持 upload-immediate。
- 原版 Ink 粘贴偏移现固化到 path points、cubic/splat、style-map reference 等页坐标；Shape 偏移
  固化到 line/polygon/ellipse 语义几何，然后恢复 identity transform。Text 继续由 CREATE_BLOCK
  表示 origin/rotation/scale。
- 单元素 Paste 继续使用 `ADD_ELEMENTS` 历史；Undo/Redo 经既有严格 visibility classifier 生成
  type-25 delete/undelete，保留同一新 identity、单 revision 与事务回滚语义。
- 补齐 Stroke clone 的 `isPartialEraser`，避免复制原版 partial eraser Ink 时工具类型退化。
