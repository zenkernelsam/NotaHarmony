# Phase 308 修复总结：照片反馈页面绑定

## 缺陷

补审发现照片插入入口的两个失败 toast 仍是全局副作用。异步选择、导入和多图提交期间切换页面后，旧页的部分失败或
整批失败提示会错误显示在新页。

## 决策与实现

照片入口捕获发起页 generation/pageId。部分失败 toast 必须仍在发起页且存在严格成功前缀；整批失败 toast 也只在同页
显示。跨页异常保留 hilog，并正常释放 `photoImportBusy`。持久化、Undo history、outcome 和保存状态绑定不变。

## 验证

- 照片部分失败专项 Replay 从 9/9 扩展至 10/10；
- ArkTS 目标文件无新增错误；全量 Desktop Replay `277` 个文件全部通过，FAILED_FILES=0；
- `git diff --check` 通过；`note@ohosTest` 与 `note@default` 分别 `BUILD SUCCESSFUL in 7 s 850 ms`
  与 `13 s 340 ms`，只做静态打包且跳过签名；
- 未启动模拟器、虚拟机、真机或 Hypium。

## 开放项

真实 picker 中断、跨页矩阵和端到端体验仍需设备验收；`T-042` 继续严格留到 Goal 最后一项。
