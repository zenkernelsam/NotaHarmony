# Phase 313 修复总结：Group/Ungroup 作者骄证页面健康绑定

日期：2026-08-23（Asia/Shanghai）

## 背景与缺口

Group/Ungroup 作者调用 createOriginalGroup() / ungroupOriginalGroup() 执行持久 SQLite 事务，可跨越页面导航。成功和失除分支使用弱守卫，仅比较 pageLoadGeneration、loadedPageId和currentPage.pageId。同ID页面重载或加载健康状态变化时，迟到结果可能污染新状态。

## 实现

- Group success: replaced 3-line weak guard with !this.isHistoryPageContextCurrent(generation, pageId)
- Group catch: replaced 3-line weak guard with this.isHistoryPageContextCurrent(generation, pageId)
- Ungroup success: replaced 3-line weak guard with !this.isHistoryPageContextCurrent(generation, pageId)
- Ungroup catch: replaced 3-line weak guard with this.isHistoryPageContextCurrent(generation, pageId)

Durable SQLite commits remain authoritative. Stale successes push undo history but skip local mutations.
