# Phase 405：纸张设置加载销毁绑定

日期：2026-08-25（Asia/Shanghai）

## 问题

页面设置面板加载共享纸张配置时，先等待数据库初始化，然后创建仓库、读取背景信息和收藏。第一次销毁/换代检查
位于两个列表读取之后；面板已销毁或已有新加载时，旧续体仍可能发布陈旧数据并重新绑定 `paperStore`。

## 修复

- 数据库初始化返回后立即检查 `panelDisposed || generation !== sharedLoadGeneration`。
- 无效续体不再创建仓库、不再访问存储、不发布背景信息或收藏，也不覆盖 `paperStore`。
- 收藏写入、间距保存、失败处理和 busy 清理的既有门禁全部保持不变。

  锁定初始化 → 联合门禁 → 仓库创建顺序。
