# Phase 304 修复总结：授权后切页粘贴中止

## 缺陷

补审发现 Phase 303 只在请求 `READ_PASTEBOARD` 权限前确认页面未变。授权是异步边界：用户在授权弹窗等待期切换
页面或笔记后，旧粘贴流程会在权限成功后继续读取剪贴板、规范化 PixelMap，并把图像持久化到已离开的旧页。
完成后的剪贴板缓存虽有页面守卫，但数据库副作用已经发生。

## 决策与实现

粘贴入口继续捕获 `pageLoadGeneration` 与 `loadedPageId`。现在权限网关成功后立即再次绑定同一页面上下文；发现
generation 或 pageId 变化则静默中止。该路径不读取 PasteData、不解码图像、不构造 draft，也不触发任何持久化。
同页流程的 MIME 复查、busy 串行化、失败提示和完成后重同步不变。

## 验证

- 剪贴板专项 Replay 从 26/26 扩展至 27/27，新增“paste aborts after permission when the page changed”；
- ArkTS 目标文件无新增错误；全量 Desktop Replay `277` 个文件全部通过，FAILED_FILES=0；
- `git diff --check` 通过；`note@ohosTest` 与 `note@default` 分别 `BUILD SUCCESSFUL in 8 s 767 ms`
  与 `14 s 882 ms`，只做静态打包且跳过签名；
- 未启动模拟器、虚拟机、真机或 Hypium。
