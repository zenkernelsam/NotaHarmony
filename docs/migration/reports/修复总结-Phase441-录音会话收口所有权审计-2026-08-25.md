# 修复总结 — Phase 441 录音会话收口所有权审计

日期：2026-08-25

## 审计范围

复核 `NotePage.finishRecordingSession()` 与 `performLeaveEditor()`、`aboutToDisappear()` 的
协作，以及 `OriginalRecordingSessionController.finishAndRelease()` 对活动采集、音频焦点、监听
器和后续控制的终态处理；相邻核对刷新定时器与对话框后启动入口。

## 裁决

当前所有权正确且是有意设计：页面同步置空会话指针防止同页二次收口；控制器 `AsyncMutex` 串行化
直接控制、中断停止与终态释放；`released` 门禁保证排队回调不会触碰已释放采集。销毁路径的定时器
取消、迟到回调守卫和对话框后启动检查共同保持 fail-visible/fail-closed。

忽略 `finishRecordingSession()` 返回值不构成静默数据丢失：保存失败已由控制器发布失败并显示 UI，
释放异常也记录警告。路由离开仍按顺序等待删除冲刷与会话收口后再导航。

## 变更

新增 ADR-0413、中文证据与本报告；新增专项 Replay
`d02-recording-session-finish-ownership-bound.mjs`（11/11），锁定页面指针所有权、销毁顺序、
离开顺序、互斥终态与对话框启动门禁。生产代码零改动。
