# Phase 361 修复总结：资料库偏好写入生命周期绑定

日期：2026-08-24（Asia/Shanghai）

## 缺陷与修复

- 排序和主题的 `getPreferences()` 成功续体缺少销毁/换代复查；离开或重建资料库后的迟到结果仍可
  `putSync` + flush，覆盖较新的全局偏好并影响下次启动。
- 现在两个入口捕获 lifecycle generation，并在取得 Preferences 后、写入前校验活动页与同代身份。陈旧
  续体不触达 durable 写入；同步 UI 效果与失败日志语义不变。
