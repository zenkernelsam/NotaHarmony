# Phase 327 修复总结：纸张设置销毁绑定

日期：2026-08-23（Asia/Shanghai）

## 缺陷与修复

- `PageSettingsPanel` 的收藏切换和间距保存在持久化 await 后没有销毁检查；用户关闭面板后，迟到成功可覆盖
  favorites/backgroundInfos 或改写预览状态，失败路径可对已销毁组件弹 toast。
- 现在销毁入口设置 `panelDisposed = true`；两个操作的每个持久化 await 后和 catch 路径均检查该标志，
  过期路径跳过所有内存发布和 UI 反馈。durable 收藏/间距结果保持权威。
