# Phase 196 修复总结：系统 Backup 版本身份门禁

## 发现

系统快照 manifest 的 `bundleVersion` 被写死为 `1.0.0`，恢复回调收到的真实
`BundleVersion` 只用于完成状态文本。版本升级后，快照无法证明自身来源，也可能把未来
版本生成的原始数据库直接覆盖到较旧应用。

## 修改

- 从运行时 BundleInfo 写入真实 `versionName` 和 `versionCode`
- 校验版本名的非空、字节预算、首尾空白与控制字符边界
- 校验版本码的安全整数及平台上限
- 恢复前绑定 manifest 与 CoreFileKit 来源版本
- 拒绝来源版本码高于当前安装版本的原始快照
- `bundleVersionCode` 保持可选，兼容旧 schema-1 manifest
- 修正 Phase 195 后一条仍断言旧 `..` 子串策略的历史 replay
