# 修复总结 — Phase 512 文件夹确认激活边界修复

## 问题

文件夹弹窗确认入口缺少激活防线；页面失活后的晚到确认仍可进入仓库调用和忙态事务，造成无意义
持久化和状态竞争。

## 修复

`onFolderDialogConfirm()` 先通过 `pageActive` 拒绝失活状态，再执行原确认流程。生命周期捕获、忙态
拒绝、创建/重命名事务、失败提示、成功发布与弹窗关闭全部保留。

## 影响与验证

- 新增 ADR-0484，并在既有库页变更边界 evidence 文件追加本阶段增量段。
- 扩展库页文件夹变更专项 Replay 至 8 项，当前通过。
- ArkTS 目标无错误，仅既有警告与信息级提示。
- 全量 Desktop Replay `REPLAY_FILES=421 PASSED=421 FAILED_FILES=0`
  （32.546 秒）；clean 3.140 秒、ohosTest HAP 9.930 秒、default HAP 31.181 秒均静态构建成功。
- 未启动模拟器、虚拟机、真机或 Hypium；T-042 继续保留为 Goal 最后任务。
