## 缺陷与修复

- `selectFolder()` 的迟到成功可发布 notes、刷新缩略图并关闭抽屉；迟到失败可在页面销毁或重建后恢复 folder 状态
  并弹出加载失败提示。原因是请求身份未绑定触发时的 lifecycle generation。
- 现在进入函数即捕获 lifecycleGeneration；查询后发布、缩略图刷新后的 UI 收尾和 catch 失败提示都使用完整身份校验。
- 失败路径从弱化 inline tuple 改为共享 isCurrentNotesRequest 契约；finally 的 busy 清理保留。
