## 改了什么

1. `note/src/main/ets/data/NotePackageSpec.ets`：.note 包 JSON 结构定义
   - `NoteManifest`（format/version/title/noteId/createdAt/updatedAt/pageCount/appVersion/source）
   - `PageData`（pageId/pageIndex/paperSize/paperTemplate/orientation/elements）
   - `serializeManifest` / `parseManifest`（严格校验 format=nota.note + version=1）/ `serializePage` / `parsePage`
2. `note/src/main/ets/data/ZipArchive.ets`：最小 ZIP 读写器（纯 ArkTS 零第三方库）
   - CRC32 查表法（256 项表，`0xEDB88320` 多项式）
   - little-endian 手写读写（ByteWriter/readU16/readU32）
   - `ZipWriter.addEntry(name, data, compress?)` + `async build()`（Local File Header + Central Directory + EOCD）
   - `ZipReader.parse()`（**从 Central Directory 定位**，兼容 data descriptor 标准 ZIP；STORE/DEFLATE 双模式；逐条目 CRC32 校验，损坏返回 null 不抛异常）
   - raw DEFLATE（RFC1951）：`zlib.createZipSync() → getZStream()` + `deflateInit2(windowBits=-15)` / `inflateInit2(-15)`（ZIP 格式要求 raw，非 zlib 包装）
   - 压缩无收益（deflated.length >= raw.length）自动回退 STORE
   - 文件名 UTF-8（general purpose bit 11）
