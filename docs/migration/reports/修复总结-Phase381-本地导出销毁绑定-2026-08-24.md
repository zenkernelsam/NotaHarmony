# Phase 381 修复总结：本地导出销毁绑定

日期：2026-08-24（Asia/Shanghai）

## 缺陷与修复

- 补审发现 `BackupPage.exportAllLocal()` 只在获取笔记后检查一次生命周期。每条笔记的 `exportToFile()` 可打开系统
  保存器，await 期间离开或换代后，旧循环仍会继续导出剩余笔记。
- 导出返回后的成功计数和最终 toast 也缺少门禁，迟到续体可能触达旧页面。
- 现在每次导出前、每次导出返回后都复用捕获的 `lifecycleGeneration` 检查；陈旧态直接静默返回，不启动新保存器、
  不递增成功数、不发布最终提示。
- 活动页导出语义、用户取消语义以及 finally 的 busy/status 清理与操作租约释放保持不变。
