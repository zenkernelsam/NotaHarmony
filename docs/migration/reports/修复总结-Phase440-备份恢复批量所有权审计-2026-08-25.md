# 修复总结 — Phase 440 备份恢复批量所有权审计

日期：2026-08-25

## 审计范围

复核 `restoreFromCloud()` 到 `BackupBatchApplier` 的应用级批量事务，以及 `removeImportedNote()`
补偿路径；相邻核对普通本地导入、WebDAV 配置保存和导出快照门禁，确认没有绕开批量所有权的入口。

## 裁决

恢复创建与补偿通过同一 nominal adapter 绑定到权威 importer。批量协调器只删除本次跟踪的新身份
或 importer 明确报告的残留身份；补偿清理重新进入 `NoteImporter.importMutex`，单点失败不会静默
伪装成完整回滚。共享 `backupOperationLease` 已串行化页面侧备份变更入口。

导出链的编辑保存终态、逐笔记 revision 和最终整库快照复核保持完整；该路径已有既有 Replay 与
ArkTS 测试，不需要重复修改。

## 变更

新增 ADR-0412、中文证据与本报告；新增专项 Replay
`d02-backup-restore-batch-ownership-bound.mjs`（11/11），锁定租约串行化、身份所有权、互斥补偿
和导出快照 fail-closed 顺序。生产代码零改动。
