# 修复总结 — Phase 505 文件夹重排忙态边界修复

## 问题

库页文件夹上下移动菜单项只在生成时判断能否移动，最终移动方法虽有忙态防线，但入口辅助方法
可先行读取过期兄弟顺序；并发状态切换下晚到菜单事件会进入不一致路径。

## 修复

`moveFolderBy()` 先通过 `folderBusy` 拒绝忙态，再计算兄弟索引并调用既有移动事务。菜单可见性、
生命周期守卫、失败反馈、文件夹排序和历史持久化全部保留。
