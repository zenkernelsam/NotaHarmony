# Phase 187 修复总结：文件夹兄弟序号归一化

## 发现

文件夹移动和删除只改变目标记录，不压缩兄弟 `sibling_order`。重复操作会留下空洞，
使本地顺序逐渐依赖历史操作次数。

## 修改

- `note/src/main/ets/data/FolderRepositoryImpl.ets`
- 新增 ADR、静态 replay 和本报告

移动后重排旧/新父级，删除后重排受影响父级；排序使用现有序号、创建时间和 ID 的
确定性 tie-breaker，并在同一事务中写回连续 `0..N-1`。
