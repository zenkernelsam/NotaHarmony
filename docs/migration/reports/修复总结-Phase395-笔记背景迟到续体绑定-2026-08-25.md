# Phase 395：笔记背景迟到续体绑定

日期：2026-08-25（Asia/Shanghai）

## 问题

笔记编辑器加载链在发布页列表后读取 `getNoteBackground()`。这个异步边界返回后缺少销毁态与加载代际复查，旧续
体可以直接覆盖 `noteBackground`、把页索引重置为 0 并继续触发录音加载。Phase 394 只封堵了零页恢复分支的先行发
布，尚未覆盖这条后续边界。

## 修复

- 将背景查询结果先保存到局部变量。
- 在 `getNoteBackground()` await 后增加 `editorDisposed || loadGeneration !== this.pageLoadGeneration` 联合门禁。
- 只有仍属于当前加载代且未销毁的续体才发布背景并继续页索引初始化；持久化背景数据和正常加载语义不变。
