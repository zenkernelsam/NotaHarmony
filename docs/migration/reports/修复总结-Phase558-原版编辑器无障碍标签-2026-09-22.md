# 修复总结 Phase 558 — 原版编辑器无障碍标签

日期：2026-09-22

## 原版证据

`decompiled_1.0.3` 为编辑器工具区定义了专用 contentDescription：

- `toprighttoolbar_undo_action` = "Undo Action" → 撤销按钮
- `toprighttoolbar_redo_action` = "Redo Action" → 重做按钮
- `cd_quick_tool_color` = "Color" → 色板圆钮
- `toolbar_more_menu` = "More options" → 工具栏溢出菜单
- `feature_note_toolbox__settings_close` = "Close" → 工具设置关闭
- `page_indicator` = "%1$d of %2$d" → 页码指示器描述

原版这些控件都是纯图标按钮，描述是唯一可及名。

## Harmony 落地

- `EditorToolbar.ets`：↶/↷ 加 `cd_undo_action`/`cd_redo_action`；
  无标签色板圆钮加 `cd_quick_tool_color`；`...` 溢出把 `more_tools`
  （"More Tools"）换成 `toolbar_more_menu`（"More options" 原文）。
- `PageManagerBar.ets`：页码指示器 cd 由 `jump_to_title` 换成
  `cd_page_indicator`（"%1$d of %2$d"，传双参）——与原版一致，
  播报页数而非跳转动作；点击仍开跳转对话框。
- `ToolboxSettingsDialog.ets`：`✕` 加 `close`（原版 settings_close
  同值 "Close"）；单项工具 `⋯` 菜单加 `toolbar_more_menu`。
- `NoteCanvasView.ets`：缩放 `-`/`+` 加 `zoom_out`/`zoom_in`
  （T-034 缩放条是 Harmony 适配控件，原版无对应 cd，登记差异）。

## 登记差异

- 工具按钮本身渲染文字标签（toolTypeLabel），自播报；原版
  `cd_quick_tool_{pen,pencil,highlighter,eraser}` 仅因图标按钮
  才需要 cd —— 不另加标签。
- `toprighttoolbar_share_action` 无承载面（编辑器无分享按钮）。
- `page_indicator` 仅改播报文案；跳转行为与对话框标题不变。
