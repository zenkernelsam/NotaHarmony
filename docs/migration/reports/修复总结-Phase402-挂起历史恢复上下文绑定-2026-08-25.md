# Phase 402：挂起历史恢复上下文绑定

日期：2026-08-25（Asia/Shanghai）

## 问题

跨页撤销/重做会把 pending 方向保存到目标页加载完成后恢复。旧逻辑只判断方向非零，没有确认生命周期、加载健康、忙
碌状态和当前页身份；销毁后、失败页上或重入状态下仍可能立即启动下一段 durable 历史操作。

## 修复

- 恢复前联合检查 lifecycleActive、loaded、加载失败与 historyBusy。
- 无效上下文清除 pending 方向，避免迟到的跨页命令复活。
- 要求 loadedPageId 与 currentPage.pageId 一致；不一致保留 pending，等待匹配页面加载后再恢复。
