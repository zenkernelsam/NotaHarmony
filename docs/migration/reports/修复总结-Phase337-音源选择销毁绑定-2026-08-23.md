# Phase 337 修复总结：音源选择销毁绑定

日期：2026-08-23（Asia/Shanghai）

## 缺陷与修复

- `startRecording()` 在音源对话框 await 后直接启动所选来源的录音；用户在对话框打开期间离开编辑器时，
  迟到的对话框响应仍可在已销毁页面上启动捕获。
- 现在两个对话框分支（麦克风/设备内录）在 `session.start()` 前检查 `editorDisposed`，销毁态返回不启动。
  无对话框直连路径保持不变（决策与启动之间无 await 边界）。
