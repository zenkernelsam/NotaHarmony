# Phase 348 修复总结：WebDAV 设置页迟到结果销毁绑定

日期：2026-08-24（Asia/Shanghai）

## 缺陷与修复

- WebDAV 设置页的风险确认、连接测试、配置加载和保存事务都是异步续体，但页面缺少销毁守卫；离开页面后迟到
  结果仍可覆盖输入/开关状态、发布连接结论或弹出保存提示。
- 新增 `pageDisposed` 和 `lifecycleGeneration`；每个关键 await 后校验完整生命周期身份，过期续体直接返回。
- `safeToast()` 拒绝销毁态调用。durable 配置保持权威，共享备份操作租约继续在 `finally` 中释放。
- 成功路径、失败路径、重复提交门禁和既有规范化契约不变。
