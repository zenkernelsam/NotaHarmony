# 真机验收清单汇总证据（Phase 571）

## 背景

交接文档第四节 P1(d) 要求：把所有“必须真机验证”的项汇总为一张表，作为
将来模拟器/真机启动后第一天的高优先级 checklist。

此前 150+ 处 ADR 在“限制/后续验收”段落散落标注“未启动模拟器/真机”、
“需真机验证”、“真机仍需……”等运行态缺口，没有集中清单。

## 方法

1. 全量扫描 `docs/migration/adr/*.md` 中含 `真机` / `模拟器` 的行
   （约 155 行命中），剔除纯样板“本阶段不启动设备”声明，提取其中有具体
   验证对象的条目。
2. 补充 Phase 559–570 新引入的运行态项（录音指示、±10s、空态、常亮、
   沉浸栏、夜间、掌触、主题、识别语言、吸附参考线）。
3. 按子系统分 9 组输出
   `docs/migration/audit-2026-08/真机验收清单-2026-09-22.md`：
   手写渲染 / 数学公式 / 图片素材 / 录音音频 / PDF 页面 / 备份同步 /
   生命周期竞态 / 资料库交互 / 设置与系统栏。

## 清单规模

- 9 个分组、41 行验证项（R-01~E-06）。
- 每行含：验证项、关联 ADR/Phase 证据、建议验证方法。

## 规则

- 只登记“桌面 replay + HAP 构建无法覆盖”的运行态事项。
- 新 Phase 引入新的“仅真机可验”项时必须同步登记到清单。
