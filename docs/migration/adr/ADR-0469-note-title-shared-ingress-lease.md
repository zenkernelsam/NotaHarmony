# ADR-0469: 笔记标题提交边界纳入共享照片导入租约

日期：2026-08-26

## 状态

Accepted

## 背景

标题 `TextInput` 的输入与点击编辑已拒绝 `photoImportLeaseActive`，`commitTitle()` 也在仓储
访问前拒绝共享导入和结构租约。但回车与失焦仍会直接调用 `saveTitle()`，可在租约切换竞态中先
关闭编辑态并排队提交。

## 决策

`onSubmit()` 和 `onBlur()` 先检查 `photoImportLeaseActive` 并立即拒绝，再执行原有保存。
标题序列化队列、幂等发布、失败恢复、离开兜底、销毁守卫和历史语义不变。

## 结果

共享照片导入窗口内，晚到的回车或失焦不会再提前收起标题编辑或进入持久化队列。正常标题保存
保持不变。专项 Replay 锁定两项组件级防线。
