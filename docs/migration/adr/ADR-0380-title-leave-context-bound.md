# ADR-0380：标题提交与离开上下文绑定

- 状态：已接受（2026-08-25）
- 场景：离开编辑器在等待画布 flush 后继续释放工具、录音资源并路由返回，缺少销毁复查；标题持久化返回后只检查销毁态，若用户已切页仍会发布标题、推入跨页撤销并可能触发 Canvas 加载。
- 决策：画布 flush 返回后先复查 `editorDisposed`，销毁则停止剩余清理与导航；标题持久化成功且未销毁时，再确认当前页仍为发起页。页身份漂移时仅同步 durable 物化标题，不修改 action 或推入历史。
- 结果：迟到离开续体不再操作已销毁编辑器；切页后的标题续体不会把撤销命令投递到新页上下文，durable 标题保持一致。
