# ADR-0473: 页面设置按钮纳入共享照片导入租约

日期：2026-08-26

## 状态

Accepted

## 背景

页面设置按钮已响应式禁用，弹窗构建器也在共享导入租约激活时抑制内容；但点击回调仍可直接把
`showSettings` 置真。租约切换竞态中，晚到点击可先打开空设置弹窗。

## 决策

按钮回调先检查 `photoImportLeaseActive` 并立即拒绝，再打开设置弹窗。响应式可用性、弹窗状态
回流、内容抑制和父页纸色操作防线不变。

## 结果

共享照片导入窗口内，晚到设置点击不会再改变弹窗状态。正常页面设置入口保持不变。专项 Replay
锁定该新防线。
