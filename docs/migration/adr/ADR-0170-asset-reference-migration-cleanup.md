# ADR-0170：启动迁移清理资产孤儿引用

## 决策

数据库版本 62 在迁移事务中解析全部 `note_asset.note_ids` JSON，过滤不存在或重复的
笔记 ID；无有效引用的合法记录删除，有效集合则规范化写回。非法 JSON/元素不会阻塞
数据库启动，而是把资产隔离为 `note_ids=[]`、`status=FAILED`，保留行供诊断。

## 原因

此前各新写入路径已拒绝孤儿引用，但旧数据库仍可能保留它们。启动时清理可恢复历史
一致性，且事务失败会整体回滚。

## 边界

本迁移不删除资产文件，避免事务提交前不可回滚的文件系统副作用；后续垃圾文件清理由
独立可观测任务处理。
