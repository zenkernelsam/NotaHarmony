# ADR-0493: 页面管理条回调守卫方向修正

日期：2026-08-26

## 状态

Accepted

## 背景

继续补审发现 Phase 519 引入的忙碌条件方向相反：七处页面管理条直接点击回调在空闲时提前返回，
却在忙碌或照片导入租约活跃时继续执行。响应式禁用掩盖了部分路径，但可触发回调仍依赖父级异步
兜底。

## 决策

紧凑新增、常规新增、删除、前移、后移、导航和页面设置的直接回调统一改为先拒绝 `busy` 或共享导入
租约，再执行原动作。溢出菜单既有正向守卫、父级串行化、边界检查、弹层行为和正常语义不变。

## 结果

页面管理条组件层防线恢复 fail-closed；对应 Replay 现在要求七个正向早退守卫，并显式禁止旧的
反向早退模式。
