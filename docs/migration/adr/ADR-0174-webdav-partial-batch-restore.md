# ADR-0174：WebDAV 批次恢复保留已验证对象

## 决策

WebDAV 批次恢复按对象独立处理：manifest 校验或下载 hash 校验失败的对象计入失败数，
但不阻止其余已验证对象进入 `.note` 导入；只有当整个批次没有任何可验证对象时才提前
结束。UI 汇总“已恢复 / 总数 / 校验或导入失败 / 部分恢复”四个计数。

恢复器在异步下载前创建并使用结构化校验后的 manifest 快照，不再在 await 期间继续读取
调用方传入的可变对象。

## 原因

恢复器已经提供 `verified` 与 `failedNoteIds` 两路结果，原 `BackupPage` 却看到任一失败就
直接 return，并报告恢复 0 篇，导致单个远端损坏把整个完成批次变成全量不可恢复。该行为
违背批次协议的 PARTIAL 语义，也浪费了已经通过 SHA-256 的数据。

## 边界

每篇 `.note` 的内部导入仍可能返回 PARTIAL/失败；跨多篇数据库事务不在本阶段新增，
因此报告继续明确逐篇导入边界。
