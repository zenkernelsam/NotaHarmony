# ADR-0470: 页面前移/后移按钮纳入共享照片导入租约

日期：2026-08-26

## 状态

Accepted

## 背景

`PageManagerBar` 的普通前移和后移按钮已有响应式禁用，溢出菜单也有共享租约防线；但两个直接
点击回调没有组件级拒绝。共享导入收口窗口内，晚到事件可先调用父页页面操作。

## 决策

两个按钮回调先检查 `photoImportLeaseActive` 并立即拒绝，再执行原有父页转发。响应式可用性、
边界条件、溢出菜单、设置弹窗抑制和 `runPageOperation()` 防线不变。

## 结果

共享照片导入窗口内，晚到的前移或后移点击不会再进入页面结构事务。正常页面移动保持不变。
专项 Replay 锁定两项新防线。
