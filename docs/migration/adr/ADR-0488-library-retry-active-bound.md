# ADR-0488: 库页初始化重试纳入激活边界

日期：2026-08-26

## 状态

Accepted

## 背景

库页初始化错误态的重试按钮直接调用 `activatePage()`；该方法会在非激活状态下重新置位并递增生命
周期代数。晚到点击可在页面销毁后复活生命周期，进而重新执行数据库、仓库和缩略图初始化。

## 决策

初始化重试回调先拒绝非 `pageActive` 状态，再调用原 `activatePage()` 与 `initData()` 流程。生命周期
捕获、加载守卫、失败日志、状态发布和提示语义保持不变。

## 结果

已销毁库页的晚到重试不会再重建激活上下文；正常错误恢复入口不变。库页初始化失败处置边界 Replay
锁定该防线。
