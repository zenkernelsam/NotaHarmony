# ADR-0441: 已打开文本编辑纳入共享照片导入租约

日期：2026-08-26

## 状态

Accepted

## 背景

文本提交与取消入口已有共享导入租约守卫，但已打开的 `TextBlockOverlay` 仍可继续交互。
输入会改写草稿并可能触发自适应宽度布局，完成或取消会在导入收口窗口内进入历史事务、
重建选区或发布控件状态，与照片导入结果竞争。

## 决策

`TextBlockOverlay` 接收共享导入租约，并在输入框、Done 和 Cancel 上禁用交互。父视图的
`onDraftChange` 与 `onCancel` 先拒绝共享导入租约，再保留历史租约防御。文本草稿模型、
自适应宽度语义、提交事务和取消清理不变。

## 结果

导入前打开的文本编辑在导入窗口内不会改写草稿、触发布局或越过提交/取消续体；导入完成后
用户可继续编辑。焦点 Replay 锁定属性传递、三处控件禁用和两项回调双层守卫。未启动模拟器、
虚拟机、真机或 Hypium；T-042 保持 Goal 最后任务。
