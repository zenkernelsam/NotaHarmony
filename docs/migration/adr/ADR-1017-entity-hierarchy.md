# ADR-1017：实体接口层级 = be5→qsa→xy3→类别

## 状态

已接受（Phase 1073）。

## 决策

Harmony 实体能力分解：

- `be5` 变换源；
- `qsa extends be5` + `d(uq9,ie8)` = 可应用实体；
- `xy3` + `build()→yy3` = 可快照实体；
- `o06`/`k5d`/`wy0`/`fkb` = 类别接口（各表索引）。

## 依据

`qsa.d` apply 签名、`xy3.build`、`v69` t/u/s 类别表 +
`xhe` 子类型特例。

## 后果
