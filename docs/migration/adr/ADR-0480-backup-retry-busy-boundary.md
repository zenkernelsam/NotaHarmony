# ADR-0480: 备份页错误重试纳入忙态边界

日期：2026-08-26

## 状态

Accepted

## 背景

备份页错误态重试按钮已有响应式禁用，但仍直接调用 `reloadPage()`；若导出、导入、云备份或恢复
尚未收尾而晚到点击触发，可能递增加载代数并覆盖当前配置展示状态。

## 决策

错误重试回调先检查 `isBusy` 并立即拒绝，再调用原重载流程。初始化、页面返回刷新、共享备份操作
租约、生命周期守卫和四类备份操作语义保持不变。

## 结果

备份或恢复未收尾时，晚到重试不会再重置加载状态或代数；正常错误恢复入口不变。备份页面加载处置
边界 Replay 锁定该双层防线。
