# ADR-0446: 工具栏按钮禁用与回调租约一致化

日期：2026-08-26

## 状态

Accepted

## 背景

Photo/Math 插入和 Undo/Redo 的父页回调已拒绝共享照片导入租约，但四个工具栏按钮的启用
条件仍不包含该租约。导入窗口内控件保持视觉可点，形成“可点击但必然拒绝”的不一致体验，
也使防线分散在父页与子组件之间。

## 决策

四个按钮在既有加载或历史能力门禁外叠加 `photoImportLeaseActive` 禁用；父页回调和画布内部
双层防御保持不变。插入模型、历史方向、能力状态和持久化语义不变。

## 结果

共享照片导入收口窗口内四个入口同步呈现禁用态，且仍保留回调级防御。焦点 Replay 锁定四处
一致化绑定。未启动模拟器、虚拟机、真机或 Hypium；T-042 保持 Goal 最后任务。
