# ADR-0460: 录音面板动作纳入共享照片导入租约

日期：2026-08-26

## 状态

Accepted

## 背景

`RecordingPanel` 已通过 `controlsEnabled` 响应式禁用全部控件；父页十个回调也先拒绝共享导入
与结构租约。但关闭、进度拖动、录音暂停/恢复/停止、开始、倍速、播放切换、删除和撤销删除都是
组件内直接转发边界，租约切换竞态中仍可先触发父页流程。

## 决策

十个组件内回调先拒绝 `photoImportLeaseActive`，再调用原有父页回调。响应式禁用、可用状态、
待删行展示、父页共享/结构双层防线、录音会话、播放控制和持久化语义不变。

## 结果

共享照片导入窗口内，晚到的面板事件不会再启动录音、改写播放或进入删除流程。正常录音与回放
行为保持不变。专项 Replay 锁定十项新防线。
全量 Desktop Replay 421/421（31.046 秒）；clean 3.189 秒、ohosTest HAP 10.610 秒、default HAP
29.614 秒静态构建成功。
未启动模拟器、虚拟机、真机或 Hypium；T-042 保持 Goal 最后任务。
