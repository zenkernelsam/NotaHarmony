# ADR-0476: 自定义色按钮纳入共享照片导入租约

日期：2026-08-26

## 状态

Accepted

## 背景

自定义色按钮已响应式禁用，`activateCustomColor()` 也拒绝共享导入租约；但点击回调仍可直接转发。
租约切换竞态中，晚到事件可先展开自定义色面板或暂存颜色。

## 决策

按钮回调先检查 `photoImportLeaseActive` 并立即拒绝，再调用原方法。响应式可用性、HSV 输入、
纸色草稿、模板预览和父页防线不变。

## 结果

共享照片导入窗口内，晚到自定义色事件不会再改变草稿状态。正常纸色设置保持不变。专项 Replay
锁定该新防线。
