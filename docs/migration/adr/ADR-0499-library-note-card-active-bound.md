# ADR-0499：资料库笔记卡片打开入口激活边界

日期：2026-08-29

## 状态

Accepted

## 背景

`LibraryPage.NoteCard` 的单击回调直接调用 `router.pushUrl('ui/editor/NotePage')`，没有检查页面生命周期。卡片树销毁或页面切换后，已排队的晚到点击仍可能再次发起编辑器路由；缩略图可见性回调和长按菜单动作已有各自防线。

## 决策

卡片单击在路由前先要求 `pageActive`；失活时立即返回，不触达路由。长按上下文菜单、删除/移动入口和活动页正常打开语义保持不变。

## 结果

失活资料库不会因陈旧卡片事件重新导航到编辑器；活动卡片仍按原有 noteId 打开。专项 Replay 锁定守卫顺序和单击/长按分流。全量 Desktop Replay `422/422`（38.759 秒），clean 2.908 秒、ohosTest HAP 9.343 秒、default HAP 48.457 秒静态构建成功。
