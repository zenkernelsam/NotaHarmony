# ADR-0483: 库页搜索输入纳入激活边界

日期：2026-08-26

## 状态

Accepted

## 背景

库页搜索框 `onChange` 回调直接写入 `searchText` 并调用 `beginNotesRequest()`。若晚到输入事件在
页面失活后触发，会在旧生命周期中发布查询状态并递增请求代数；后续防抖虽有上下文守卫，但入口
状态已被污染。

## 决策

搜索输入回调先拒绝非 `pageActive` 状态，再更新查询、启动请求代数和防抖。防抖回调、请求身份、
生命周期丢弃、成功发布和失败提示保持不变。

## 结果

失活库页不会再接受晚到搜索输入或抢占请求代数；正常搜索语义不变。库页搜索生命周期边界
Replay 锁定该防线。
