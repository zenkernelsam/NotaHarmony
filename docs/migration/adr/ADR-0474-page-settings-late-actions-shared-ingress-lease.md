# ADR-0474: 页面设置晚到动作纳入共享照片导入租约

日期：2026-08-26

## 状态

Accepted

## 背景

页面设置面板的收藏、间距入口和自定义色关闭按钮已响应式禁用，核心方法也有共享租约防线；
但三个点击回调仍可直接转发。租约切换竞态中，晚到事件可先改变收藏、间距编辑态或关闭自定义色。

## 决策

三个回调先检查 `photoImportLeaseActive` 并立即拒绝，再执行原有转发或状态收起。响应式可用性、
方法级防线、纸色草稿、间距预览与保存语义不变。

## 结果

共享照片导入窗口内，晚到事件不会再触发三项页面设置动作。正常设置操作保持不变。专项 Replay
锁定三项新防线。
