# ADR-0440: 视口续体纳入共享照片导入租约

日期：2026-08-26

## 状态

Accepted

## 背景

视口按钮已在导入期禁用，但手势和定时器续体仍可跨入导入窗口。PDF 栅格刷新定时器可
触发异步重栅格、替换位图并强制重绘；防抖视图保存可执行数据库写入。捏合/平移的结束
与取消回调还会立即安排零延迟栅格刷新。

## 决策

`schedulePdfRasterRefresh()` 在生命周期门禁后显式拒绝共享导入与历史租约，阻止新定时器。
普通 `saveViewportState()` 拒绝两类租约；销毁路径的最终保存通过 `allowDisposedFinalSave`
保持豁免。捏合和平移的结束/取消回调在共享导入期不再安排零延迟刷新，但手势状态复位不变。

## 结果

导入前启动的视口续体不会在收口窗口内发布位图或写库；导入完成后用户下一次交互恢复。
焦点 Replay 锁定调度守卫、保存豁免语义和四项手势回调。未启动模拟器、虚拟机、真机或
Hypium；T-042 保持 Goal 最后任务。
