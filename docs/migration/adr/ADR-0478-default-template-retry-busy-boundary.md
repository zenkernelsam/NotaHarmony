# ADR-0478: 默认模板错误重试纳入保存忙态边界

日期：2026-08-26

## 状态

Accepted

## 背景

默认模板页错误态的重试按钮直接调用 `reloadDefaultTemplate()`；该方法会递增加载代数、进入
LOADING 并清空 `saveBusy`。若保存收尾与晚到点击竞态，可能中断当前状态并造成重复加载。

## 决策

错误重试回调先检查 `saveBusy` 并立即拒绝，再调用原重载流程。保存乐观更新、失败回滚、
生命周期守卫和正常加载路径不变。

## 结果

保存未收尾时，晚到重试不会再重置加载状态或代数。正常错误重试保持不变。既有默认模板路由
Replay 锁定该边界。
