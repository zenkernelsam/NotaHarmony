# ADR-0497：资料库文件夹选择入口激活边界

日期：2026-08-29

## 状态

Accepted

## 背景

Phase 354 已为 `selectFolder()` 的查询成功/失败续体绑定生命周期代数，但入口首行仍只检查 ViewModel 与 `folderBusy`。页面销毁后已经打开的菜单或抽屉可能发送晚到点击；该点击会先改写 `currentFolderId`、递增请求代数并调用 ViewModel，再由后续 guard 丢弃结果。

## 决策

`selectFolder()` 第一条准入检查统一要求 `pageActive`、ViewModel 存在且没有文件夹操作忙态。未获准入时不改写当前文件夹、不递增请求代数、不启动查询；已有生命周期、请求 tuple、缩略图和抽屉关闭续体保持不变。

## 结果

失活 Library 页面不再被晚到文件夹选择事件污染，也不会为已销毁页面启动新的查询。活动页面的文件夹切换语义不变。
