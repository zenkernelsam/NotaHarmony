# ADR-0456: 页面设置收藏与间距纳入共享照片导入租约

日期：2026-08-26

## 状态

Accepted

## 背景

Phase 476 与 Phase 482 已为页面设置弹窗、模板应用和多数草稿入口补上共享导入租约防线；
但收藏切换、间距设置开关、间距预览与间距保存仍只依赖忙碌状态或根容器响应式禁用。若信号
先于租约生效，已打开弹窗中的直接回调仍可能改写共享纸设置。

## 决策

`toggleFavorite()`、`toggleSpacingSettings()`、`previewSharedSpacing()` 和
`saveSharedSpacing()` 的第一层门禁加入 `photoImportLeaseActive`；模板收藏星标与间距
“⋯”按钮的 `.enabled()` 同步拒绝该租约。共享纸存储读写、乐观更新、失败提示、销毁防护、
普通纸张草稿和默认模板页行为不变。

## 结果

已打开的页面设置弹窗不会再在共享照片导入窗口内修改收藏或间距。正常收藏、间距预览与保存
语义保持不变。专项 Replay 锁定六项新防线。
未启动模拟器、虚拟机、真机或 Hypium；T-042 保持 Goal 最后任务。
