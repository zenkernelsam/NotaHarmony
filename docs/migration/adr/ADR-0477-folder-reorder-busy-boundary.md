# ADR-0477: 文件夹上下移动纳入 folderBusy 边界

日期：2026-08-26

## 状态

Accepted

## 背景

文件夹上下移动菜单项由 `canMoveFolderBy()` 控制可见性，最终 `moveFolder()` 会拒绝忙态；
但 `moveFolderBy()` 在读取兄弟顺序前没有入口防线。竞态中晚到菜单事件可先读取过期顺序。

## 决策

`moveFolderBy()` 先检查 `folderBusy` 并立即拒绝，再计算兄弟位置和调用原有移动事务。
菜单可见性、排序不变量、生命周期守卫、失败提示和持久化语义不变。

## 结果

文件夹操作进行中，晚到的上移或下移不会再基于过期快照进入移动流程。正常重排保持不变。
专项 Replay 锁定该新边界。
