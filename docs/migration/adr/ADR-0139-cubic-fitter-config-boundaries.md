# ADR-0139: CubicFitter 配置边界

## 决策

`CubicFitter` 继续使用原版默认配置：每段最多 200 个点、上下文扩展 5 个点、基础容差 0.5。外部配置只有在有限、整数且满足范围时才覆盖默认值；`maxPointsPerSegment` 最小为 2，`contextExpansion` 不得小于 0，`baseTolerance` 必须大于 0。

## 原因

分段循环依赖正整数上限。NaN、无穷、小数或小于 2 的值可能使索引不前进、上下文索引异常或让容差退化。该保护只约束配置输入，不改变原版拟合与动态容差公式。

## 验收

纯文本 replay 检查三组边界条件和默认值，随后执行双 HAP 构建；设备运行态仍待后续验收。
