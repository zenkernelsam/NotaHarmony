# ADR-0435: 标题提交与离开编辑器纳入共享照片导入租约

日期：2026-08-26

## 状态

Accepted

## 背景

Phase 462 后继续盘点共享照片导入租约，发现返回按钮触发的离开流程只拒绝结构租约。
照片导入释放内部 `historyBusy` 后、外层收口前，离开仍可保存标题、flush 当前页、释放
录音资源并路由返回。排队中的标题提交也只检查结构租约，可在导入窗口内捕获当前页、
准备 NOTE_TITLE 历史并执行 SET_METADATA 事务。

## 决策

`performLeaveEditor()` 与 `commitTitle()` 都在原结构租约检查中加入
`photoImportLeaseActive`。未变更标题的幂等发布保持不变；标题失败保留、页身份绑定、
销毁守卫和 finally 释放不变。不新增状态字段。

## 结果

照片导入收口前不能保存标题或离开编辑器；导入完成后重试可恢复原语义。焦点 Replay
锁定两个入口守卫及副作用顺序；相邻离开与标题上下文 Replay 同步更新。未启动模拟器、
虚拟机、真机或 Hypium；T-042 保持 Goal 最后任务。
