# ADR-0458: 图片裁剪把手纳入共享照片导入租约

日期：2026-08-26

## 状态

Accepted

## 背景

`ImageCropOverlay` 已在共享导入租约激活时禁用关闭、重置和确认按钮；父页 `onMove()` 也拒绝
共享导入与历史租约。但把手 `PanGesture.onActionUpdate()` 是组件内直接变更边界，租约切换竞态
中仍可发布移动增量并改写裁剪选区。

## 决策

把手拖动更新回调先拒绝 `photoImportLeaseActive`，再计算增量并调用父页 `onMove()`。响应式按钮
禁用、父页双层防线、选区模型、确认事务、撤销语义和销毁清理不变。

## 结果

共享照片导入窗口内，晚到的把手手势不会再移动裁剪选区。正常裁剪调整行为保持不变。专项
Replay 锁定组件内新防线。

30.383 秒静态构建成功。
