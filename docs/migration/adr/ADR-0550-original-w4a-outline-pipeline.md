# ADR-0550: w4a 轮廓管线审计 —— 可验证半区闭环，装配几何保持近似

## Status

Accepted, 2026-09-28.

## Context

审计注册表长期挂起 `w4a.java`（可变宽度轮廓，仅方法论级还原）。本轮
在 1.0.1 反编译树定位到真身（1.0.3 的 `w4a` 是无关 synthetic
switchmap，属混淆表差异），并完成调用链解码：

- `y5a.n`：DASH/DOTS 走原始中心线描边；实心走 `w4a.b` 填充轮廓。
- `w4a.a`：累积距离简化（入参 d2；建轮廓前 0.0 = 规范化，擦除产出
  后 0.1 = 抽稀）。
- `w4a.b`：退化单点 → 半径 `w·0.5·scale` 的圆；宽度链常量（1e-6 /
  PCHIP / 0.25-0.5-0.75 探针 / 1.2 / 0.5% / 2..6）与 Phase 269 移植
  逐字一致。
- `lqh.b`：擦除轮廓先 `b2j.a` 自交检查，自交则递归二分组件。

## Decision

1. **不改代码。** 可验证半区（简化、退化圆、宽度链、渲染分派）经
   逐行对照已与 Harmony 语义对齐或为严格超集（Harmony 保留压感峰、
   轮廓更密）。
2. **擦除自交策略记录为有意发散**：原版递归二分 + 自交检查是因
   Android Path 布尔能力受限；Harmony `drawing.Path.op` 原生布尔
   天然消解自交，能力更强，不回退成二分。
3. **装配几何继续挂起**：`w4a.b` 的 offset/内部弧装配含 JADX
   `??` 破型不可逐行还原；最终轮廓维持 ADR-0002 自适应展平 +
   圆弧外接头近似（M2-A-09 决策门不变，不整体关闭 A-21~A-24）。

## Consequences

- `w4a` 审计的"方法论级还原"标签收窄为"装配几何待定"；宽度链、
  退化、分派、简化四处已有逐行证据。
- 回放 `d02-original-w4a-outline-audit.mjs` 钉死上述契约；若后续
  以 dex2jar 等工具恢复装配段字节码，可再开一轮逐行比对。
