# ADR-0438: 已打开数学编辑器纳入共享照片导入租约

日期：2026-08-26

## 状态

Accepted

## 背景

Math 插入与提交入口已有共享租约守卫，但已打开的编辑器仍可在照片导入窗口内继续输入、
取消或确认。取消会释放预览并重建选区；确认可提交持久化 Math 事务并入栈历史。

## 决策

`MathEditorOverlay` 接收共享导入租约，导入期禁用文本输入、取消和完成。父视图的
`onDraftChange/onCancel/onConfirm` 再按序拒绝共享导入与历史租约。Done 启用函数新增
租约参数，保持 busy 与 OK 状态语义。启动入口、提交内部守卫和销毁清理不变。

## 结果

已打开 Math 编辑器在导入收口前不能触发渲染、状态发布或持久化副作用。焦点 Replay 锁定
属性传递、控件禁用和三回调双层防御。未启动模拟器、虚拟机、真机或 Hypium；T-042 保持
Goal 最后任务。
