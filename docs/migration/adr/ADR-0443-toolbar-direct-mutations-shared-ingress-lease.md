# ADR-0443: 工具栏直改入口纳入共享照片导入租约

日期：2026-08-26

## 状态

Accepted

## 背景

Phase 470 已禁用导入前打开的颜色与宽度面板，但继续补审发现工具栏仍有直改
`EditorViewModel` 的路径。普通工具按钮可切换工具并排队持久化；笔刷样式按钮可改写样式；
选区手绘/矩形切换可直接改写选区偏好；紧凑模式更多菜单也可在租约内触发工具切换。

## 决策

普通工具按钮和笔刷样式按钮在共享照片导入期保留既有加载禁用态，并在回调内先拒绝该租约。
紧凑更多入口、四个紧凑工具菜单项以及选区手绘/矩形切换均纳入同一租约禁用；选区样式按钮
继续保留 TAPER 可用性规则并叠加租约禁用。`NotePage` 信号回调、工具状态模型、保存链和回滚
语义不变。

## 结果

照片导入收口窗口内不能通过工具栏直改工具或笔刷状态，也不能触发新的持久化任务；
导入完成后交互恢复。焦点 Replay 锁定五类控件防线与四个紧凑菜单项守卫。
未启动模拟器、虚拟机、真机或 Hypium；T-042 保持 Goal 最后任务。
