# ADR-0472: 画布缩放控件纳入共享照片导入租约

日期：2026-08-26

## 状态

Accepted

## 背景

画布缩放条的缩小、放大和适配宽度按钮已响应式禁用；视口保存与 PDF 续体也有共享租约防线。
但三个点击回调没有组件边界拒绝，租约切换竞态中晚到事件可先改写视口。

## 决策

三个回调先检查 `photoImportBusy` 并立即拒绝，再执行原有缩放流程。响应式禁用、缩放锚点、
范围钳制、视口保存语义、PDF 重栅格和手势行为不变。

## 结果

共享照片导入窗口内，晚到的缩放按钮事件不会再改写视口。正常缩放操作保持不变。专项 Replay
锁定三项新防线。
