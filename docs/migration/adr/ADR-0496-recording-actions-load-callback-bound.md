# ADR-0496：录音动作回调纳入列表加载边界

日期：2026-08-29

## 状态

Accepted

## 背景

Phase 518 已让 `RecordingPanel.controlsEnabled` 同时拒绝共享照片导入租约与录音列表 `loading`，但九个动作事件的组件级回调仍只检查照片导入租约。列表刷新期间的晚到 seek、倍速、播放、删除、撤销或录音会话事件仍可能穿过响应式禁用并转发到父页。

关闭面板不读取或改写录音列表，也不停止正在进行的录音；加载期间仍应允许用户收起面板。

## 决策

- seek、暂停、恢复、停止、开始、倍速、播放、删除和撤销删除九类动作回调统一先拒绝 `photoImportLeaseActive || loading`。
- 关闭回调继续只拒绝共享照片导入租约，保留加载期间可关闭面板的原有语义。
- 父页共享/结构租约、播放与录音状态机、删除撤销窗口和离开编辑器收尾不变。

## 结果

响应式禁用与组件级动作门禁在列表加载状态下保持一致；晚到事件不再基于旧录音快照进入业务层，同时面板关闭仍可用。全量 Desktop Replay `421/421`（35.203 秒），clean 7.567 秒、ohosTest HAP 12.544 秒、default HAP 30.794 秒静态构建成功。
