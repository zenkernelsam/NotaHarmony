# ADR-0465: 工具栏插入按钮纳入共享照片导入租约

日期：2026-08-26

## 状态

Accepted

## 背景

非紧凑工具栏的 Photo 与 Math 按钮已按工具加载状态与共享导入租约响应式禁用；父页两个回调也
拒绝共享导入、页面操作、历史挂起和结构租约。但组件内点击直接转发，租约切换竞态中可先发布
插入信号。

## 决策

Photo 与 Math 按钮回调先拒绝 `photoImportLeaseActive`，再调用原有父页回调。响应式可用性、
紧凑菜单防线和父页多层守卫不变；正常图片与公式插入流程不变。

## 结果

共享照片导入窗口内，晚到的工具栏点击不会再发布插入信号。正常插入入口保持不变。专项 Replay
锁定两项新防线。
全量 Desktop Replay 421/421（33.131 秒）；clean 3.338 秒、ohosTest HAP 11.084 秒、default HAP
31.320 秒静态构建成功。
未启动模拟器、虚拟机、真机或 Hypium；T-042 保持 Goal 最后任务。
