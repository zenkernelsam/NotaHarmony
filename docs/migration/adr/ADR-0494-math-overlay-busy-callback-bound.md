# ADR-0494: Math 覆层忙碌回调边界

日期：2026-08-26

## 状态

Accepted

## 背景

Math 编辑覆层的取消和完成按钮已有响应式禁用，但直接回调只拒绝共享照片导入租约。忙碌期间晚到
点击可进入组件回调，依赖父级历史租约和确认方法内部防御才能避免重复提交或取消竞态。

## 决策

取消与完成直接回调统一先拒绝 `this.busy || this.photoImportLeaseActive`，再转发原动作。文本输入
onChange、Done 四态模型门禁、父级历史串行化、失败保留草稿和正常语义不变。

## 结果

Math 覆层在组件层形成忙碌与共享导入双重 fail-closed 防线；既有共享租约 Replay 扩展到 15 项，锁定
两处组合早退并禁止仅租约的旧点击模式。
