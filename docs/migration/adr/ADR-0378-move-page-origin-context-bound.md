# ADR-0378：移动页发起上下文绑定

- 状态：已接受（2026-08-25）
- 场景：`moveCurrentPage()` 在 durable 重排序 await 期间，用户可从原页切走。旧续体通过销毁检查后仍发布基于原索引的顺序并把当前页改回目标索引，抢夺导航且撤销记录与真实上下文错位。
- 决策：重排序返回后先确认父级当前页仍为 `selectedPageId`；不一致则静默返回，保留 durable 顺序但不发布 UI 或撤销 action。成功路径沿用既有顺序、索引和撤销发布。
- 结果：用户切页不再被移动页续体回抢；durable 排序保持可恢复，正常同上下文移动行为不变。
