# ADR-1282：库页 + 设置 UI

## 状态

已接受（Phase 1339）。

## 决策

库页 = grid/list（`ie7` 默认 GRID）+文件夹 emoji/color
（`e47`/`du3`/`pdb.d` 语义）；设置 5 页 —— 原版语义
保真，未反编译资源显式近似。

## 理由

`LibraryPage` 逐项对照原版（文件夹 color/emoji `e47`；
emoji 分类网格 `du3` 按原序策划子集；视图 `ie7` 默认
GRID+`z97` pref；`yj9` grid/list 选 `b5j.b`/`m5j.b`）——
未反编译处（调色板/ML-Kit 上限）显式文档化近似。
`ui/settings` 5 页（Settings/Backup/WebDAV/Template/
RecentlyDeleted）。

## 后果

库/设置 UI 保真；不可恢复资源诚实近似而非臆造。
