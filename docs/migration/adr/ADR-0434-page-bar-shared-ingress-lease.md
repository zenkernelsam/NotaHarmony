# ADR-0434: 页面管理条与纸张设置纳入共享照片导入租约

日期：2026-08-26

## 状态

Accepted

## 背景

Phase 461 后继续盘点共享照片导入租约，发现页面管理条只把 `pageOperationBusy`
传给按钮启用状态。导入释放内部 `historyBusy` 后、外层收口前，新增/删除/移动页、
纸张设置弹层和背景应用仍可进入。`runPageOperation()` 虽会拒绝共享租约，但缺少
第一层交互禁用；`applyNoteBackgroundSettings()` 作为操作体也缺少结构租约防御。
已展开的纸张设置面板可在导入窗口内继续提交 NOTE_BACKGROUND。

## 决策

父页向 `PageManagerBar` 传递共享租约状态，并把 busy 计算为共享租约或页面操作忙。
导航、增删移动、设置和溢出菜单在共享导入期间禁用；`applyNoteBackgroundSettings()`
再显式拒绝共享导入与结构租约，作为第二层防御。不改变持久化事务和历史元数据语义。

## 结果

照片导入收口前页面管理条不能发起新结构操作或应用纸张设置；导入完成后恢复。
焦点 Replay 锁定属性传递、按钮绑定、统一入口与背景防御。未启动模拟器、虚拟机、
真机或 Hypium；T-042 保持 Goal 最后任务。
