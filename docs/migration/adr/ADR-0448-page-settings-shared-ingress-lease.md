# ADR-0448: 页面设置面板纳入共享照片导入租约

日期：2026-08-26

## 状态

Accepted

## 背景

页面设置按钮已受共享导入租约约束，但弹出内容仍可在导入窗口打开；`PageSettingsPanel`
内部尺寸、自定义色和方向入口只检查忙碌、共享纸设置与间距保存状态。这些路径可改写草稿、
展开 HSV 编辑器或预览共享间距，与外层禁用语义不一致。

## 决策

编辑器弹窗在租约激活时不再构建面板；面板新增租约属性并在根容器禁用。尺寸卡片、自定义色
开关和方向按钮在原门禁前叠加租约，HSV 滑杆随容器禁用。默认模板页不传该属性以保留全局设置
可用性；父页背景应用防御保持双层防线。

## 结果

共享照片导入收口窗口内不能进入或操作编辑器页面设置；全局模板设置语义不变。
焦点 Replay 锁定属性传递、弹窗抑制和四处入口防线。
未启动模拟器、虚拟机、真机或 Hypium；T-042 保持 Goal 最后任务。
