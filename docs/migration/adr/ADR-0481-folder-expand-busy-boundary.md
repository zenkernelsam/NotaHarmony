# ADR-0481: 文件夹展开折叠纳入忙态边界

日期：2026-08-26

## 状态

Accepted

## 背景

文件夹行的展开/折叠按钮已有响应式禁用，但 `toggleFolderExpanded()` 回调仍可直接修改展开集合。
若按钮禁用与 `folderBusy` 切换竞态，晚到点击会在文件夹选择、增删改或拖放收尾期间发布过期树形状态。

## 决策

`toggleFolderExpanded()` 先拒绝 `folderBusy`，再复制并更新展开集合。响应式禁用、文件夹行菜单、
选择、拖放、生命周期守卫和持久化语义保持不变。

## 结果

忙碌事务未收尾时，晚到展开或折叠不会再覆盖树形展示；正常交互入口不变。库页文件夹变更边界
Replay 锁定该双层防线。
