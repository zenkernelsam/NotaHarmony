# ADR-0377：新增页发起上下文绑定

- 状态：已接受（2026-08-25）
- 场景：`addPage()` 在 durable 建页 await 期间，用户可从原页切走。旧续体通过销毁检查后仍无条件把当前页改回新页，抢夺导航并让撤销记录的 `selectedPageIdBefore` 与真实上下文不一致。
- 决策：建页返回后先确认父级当前页仍是发起时的 `selectedBefore`；不一致则静默返回，保留 durable 新页但不发布 UI 或撤销 action。成功路径在发布更新列表后再设置新页索引。
- 结果：用户切页不再被新页续体回抢；durable 新页保持可恢复，正常同上下文新增行为不变。
