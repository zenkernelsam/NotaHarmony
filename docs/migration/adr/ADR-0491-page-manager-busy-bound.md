# ADR-0491: 页面管理条动作纳入忙碌边界

日期：2026-08-26

## 状态

Accepted

## 背景

页面管理条的按钮可用性已拒绝 `busy`，但七处直接点击回调只拒绝共享导入租约。晚到点击可在页面
操作尚未收尾时进入添加、删除、移动或设置回调，依赖父级 `runPageOperation` 兜底才能避免重复
持久化。

## 决策

紧凑新增、常规新增、删除、前移、后移、导航和页面设置的点击回调统一先拒绝 `busy`，再保留共享
导入租约与既有业务检查。响应式禁用、菜单守卫、父级操作串行化和正常交互语义不变。

## 结果

页面管理条在忙碌竞态中具备组件层 fail-closed 防线；既有共享租约 Replay 扩展至 22 项并锁定
组合条件。
