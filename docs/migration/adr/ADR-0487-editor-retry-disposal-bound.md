# ADR-0487: 编辑器错误重试纳入销毁边界

日期：2026-08-26

## 状态

Accepted

## 背景

编辑器页加载失败的重试按钮直接调用 `loadPages()`；该方法内部虽有销毁与代数守卫，但入口未先拒绝
已销毁页面。晚到点击可重置加载状态、进入 in-flight 并重新绑定仓库回调。

## 决策

错误重试回调先检查 `editorDisposed` 并立即拒绝，再调用原加载流程。加载代数、初始化取消门禁、
零页恢复、标题/背景读取和失败发布保持不变。

## 结果

已销毁编辑器的晚到重试不会再启动页面加载；正常错误恢复入口不变。编辑器初始化处置边界 Replay
锁定该防线。
