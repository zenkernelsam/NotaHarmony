# ADR-0425: 选区样式纳入共享照片导入租约

日期：2026-08-26

## 状态

Accepted

## 背景

Phase 451 已串行化选区菜单，但工具栏选区样式、颜色和宽度回调仍会直接发布信号。
Canvas 的 `modifySelectedInkRegisters()` 只检查 `historyBusy`、加载健康和选区状态。
照片导入异步持久化释放 `historyBusy` 后、外层 `finally` 收口共享租约前，这些入口可
改写笔迹或形状并推入撤销栈，再与照片插入合并结果竞争。

## 决策

三个父页回调在发信号前拒绝照片导入、页面操作、历史待定与页面结构租约；三个 Canvas
watcher 在调用修改函数前先拒绝共享导入租约，再执行内部历史、健康与页身份防御。
`modifySelectedInkRegisters()` 的既有最终防线保留，不新增生产状态字段。

## 结果

选区样式变更不再于照片导入收口前进入文档或撤销栈；导入完成后恢复交互。专项 Replay
锁定三入口双层守卫及顺序。未启动模拟器、虚拟机、真机或 Hypium；T-042 保持 Goal
最后任务。
