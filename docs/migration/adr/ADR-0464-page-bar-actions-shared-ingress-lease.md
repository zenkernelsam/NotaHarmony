# ADR-0464: 页面管理条动作纳入共享照片导入租约

日期：2026-08-26

## 状态

Accepted

## 背景

`PageManagerBar` 已通过响应式禁用阻断多数页面操作，菜单项也有回调防线；但紧凑新增、导航、
普通新增和删除仍是组件内直接转发。租约切换竞态中，晚到点击可先进入父页页面操作队列。

## 决策

四处直接点击先拒绝 `photoImportLeaseActive`，再执行原有父页回调。响应式禁用、可用边界、
设置弹窗抑制和父页 `runPageOperation()` 防线保留；正常翻页、增删页行为不变。

## 结果

共享照片导入窗口内，晚到的页面条事件不会再启动页面结构事务。正常页面管理保持不变。专项
Replay 锁定四项新防线。
全量 Desktop Replay 421/421（32.294 秒）；clean 3.439 秒、ohosTest HAP 10.355 秒、default HAP
31.368 秒静态构建成功。
未启动模拟器、虚拟机、真机或 Hypium；T-042 保持 Goal 最后任务。
