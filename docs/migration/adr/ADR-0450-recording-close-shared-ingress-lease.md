# ADR-0450: 录音面板关闭纳入共享照片导入租约

日期：2026-08-26

## 状态

Accepted

## 背景

录音面板的录制、播放、进度、倍速、删除与撤销删除回调均已按共享导入租约和页面结构租约
防御，但面板右上角关闭回调直接隐藏 `showRecordings`。该入口可在导入收口窗口内改变可见
状态，形成面板内部防线的一致性缺口。

## 决策

`RecordingPanel.onClose` 回调先拒绝共享照片导入租约，再拒绝页面结构租约，最后执行原有
`closeRecordings()`。关闭仍只隐藏面板，不停止或释放录音会话；父级退出路径继续负责会话
收尾。相邻 Replay 的九项回调清单同步扩展为十项。

## 结果

共享照片导入收口窗口内录音面板保持稳定且全部交互防线一致；导入完成后恢复可用。
焦点与相邻 Replay 锁定该语义。未启动模拟器、虚拟机、真机或 Hypium；
T-042 保持 Goal 最后任务。
