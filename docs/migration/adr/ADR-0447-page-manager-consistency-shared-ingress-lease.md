# ADR-0447: 页面管理一致化纳入共享照片导入租约

日期：2026-08-26

## 状态

Accepted

## 背景

页面管理条已传递共享导入租约，多数按钮也据此禁用，但普通布局的删除页按钮只检查忙碌与
页数；紧凑“...”菜单中的前移、后移和删除三项只检查忙碌。这些入口可在共享照片导入期打开
或点击，形成视觉可用但回调被拒绝的不一致，并暴露可交互菜单。

## 决策

删除页按钮在既有忙碌和页数门禁外叠加共享导入租约，透明度同步反映禁用态；三个紧凑菜单项
在执行动作前同样拒绝该租约。父页 `runPageOperation` 与背景应用防御保持双层防线。

## 结果

共享照片导入收口窗口内页面移动、添加、设置和删除入口呈现一致的不可用语义；持久化、
历史、选页与页面结构模型不变。焦点 Replay 锁定四处一致化绑定。
未启动模拟器、虚拟机、真机或 Hypium；T-042 保持 Goal 最后任务。
