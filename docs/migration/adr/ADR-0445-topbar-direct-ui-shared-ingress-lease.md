# ADR-0445: 顶栏直改纳入共享照片导入租约

日期：2026-08-26

## 状态

Accepted

## 背景

Phase 472 已收口工具栏面板开关，但顶栏仍可在共享照片导入期直改状态：非编辑态标题
可进入编辑态，编辑态输入可直接改写 `titleDraft`；录音面板外层开关也可打开或关闭面板。
虽然后续标题提交已有租约防御，但入口和草稿路径不一致，且会在导入窗口内暴露可变 UI。

## 决策

标题点击入口、标题草稿输入和录音开关统一先拒绝共享导入租约；录音按钮同时禁用，
开启与关闭都受同一门禁约束。标题提交与失焦继续走既有串行队列：未变更标题保持幂等
发布，变更标题由 `commitTitle` 原有租约防御拒绝。录音控制器、持久化和历史语义不变。

## 结果

共享照片导入收口窗口内不能进入标题编辑、不能改写标题草稿，也不能翻转录音面板可见
性；导入完成后交互恢复。焦点 Replay 锁定三处入口防线及既有提交与关闭语义。
未启动模拟器、虚拟机、真机或 Hypium；T-042 保持 Goal 最后任务。
