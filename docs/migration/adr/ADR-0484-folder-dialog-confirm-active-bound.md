# ADR-0484: 文件夹弹窗确认纳入激活边界

日期：2026-08-26

## 状态

Accepted

## 背景

文件夹新建/重命名弹窗的确认回调先捕获生命周期，再检查仓库和忙态；但入口未拒绝已经失活的页面。
晚到确认可在旧界面状态下启动持久化事务，即使后续成功路径会被丢弃。

## 决策

`onFolderDialogConfirm()` 第一条语句拒绝非 `pageActive` 状态。原有生命周期捕获、忙态拒绝、创建/
重命名事务、失败提示、成功发布和弹窗关闭语义保持不变。

## 结果

失活库页不会再发起文件夹弹窗持久化；正常确认路径不变。库页文件夹变更边界 Replay 锁定该防线。
