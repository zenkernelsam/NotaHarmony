# ADR-0468: 图片裁剪按钮纳入共享照片导入租约

日期：2026-08-26

## 状态

Accepted

## 背景

`ImageCropOverlay` 的关闭、重置和确认按钮已通过 `controlsEnabled` 响应式禁用；父页回调与把手
拖动也有共享导入及历史防线。但三个按钮点击仍是组件内直接转发边界，租约切换竞态中可先调用
父页流程。

## 决策

关闭、重置和确认按钮回调先检查 `controlsEnabled`，禁用时立即拒绝，再执行原有父页转发。
响应式可用性、按钮语义、选区模型、确认事务、历史语义和销毁清理不变。

## 结果

共享照片导入窗口内，晚到的裁剪按钮事件不会再触发关闭、重置或确认。正常裁剪操作保持不变。
专项 Replay 锁定三项新防线。
全量 Desktop Replay 421/421（35.720 秒）；clean 3.611 秒、ohosTest HAP 11.619 秒、default HAP
35.182 秒静态构建成功。
未启动模拟器、虚拟机、真机或 Hypium；T-042 保持 Goal 最后任务。
