# ADR-0482: 库页设置导航纳入激活边界

日期：2026-08-26

## 状态

Accepted

## 背景

库页“⋯”菜单中的设置导航直接调用 `router.pushUrl()`，没有检查页面是否仍处于激活生命周期。
若晚到菜单动作在页面失活后触发，可能基于过期界面状态再次发起路由。

## 决策

`navigateToSettings()` 先拒绝非 `pageActive` 状态，再执行原路由。菜单结构、设置页入口、页面返回
刷新和失败日志语义保持不变。

## 结果

失活库页不会再发起设置导航；正常菜单路径不变。页面显示重载上下文边界 Replay 锁定该防线。
