# ADR-0479: 设置页错误重试纳入保存忙态边界

日期：2026-08-26

## 状态

Accepted

## 背景

设置页错误态重试按钮直接调用 `reloadSettings()`；该方法会递增加载代数、进入 LOADING 并清空
`saveBusy`。若形状识别保存尚未收尾而晚到点击触发，可能中断状态收尾并重复加载。

## 决策

错误重试回调先检查 `saveBusy` 并立即拒绝，再调用原重载流程。初始化、页面返回刷新、保存乐观
更新、失败回滚与生命周期守卫保持不变。

## 结果

保存未收尾时，晚到重试不会再重置加载状态或代数；正常错误恢复入口不变。偏好保存处置边界
Replay 锁定该防线。
