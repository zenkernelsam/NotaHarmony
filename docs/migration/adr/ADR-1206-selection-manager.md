# ADR-1206：joe 选区管理器

## 状态

已接受（Phase 1262）。

## 决策

`joe` TextFieldSelectionManager+`mse`/`r95`/`zne` 句柄
枚举+`tr1`/`wc5`/`yla` → Harmony `TextInput`/
`SelectController`+`CaretStyle`。

## 理由

`joe`={pdf,ype,k6f,hi2,yla,tr1,wc5,Function0×2} 选区
控制器；`mse`=HandleState、`r95`=Handle、`zne`=
TouchMode —— 句柄/选区管理。

## 后果

Harmony 选区 = SelectController+CaretStyle —— 选区
语义保真。
