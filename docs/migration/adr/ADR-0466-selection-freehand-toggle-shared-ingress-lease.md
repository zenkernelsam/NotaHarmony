# ADR-0466: 选中自由手切换纳入共享照片导入租约

日期：2026-08-26

## 状态

Accepted

## 背景

选中模式的自由手/矩形切换按钮已按工具加载状态与共享导入租约响应式禁用；`setSelectionIsFreehand()`
内部持久化也有失败恢复。但组件内点击直接调用视图模型，租约切换竞态中可先改写选中形状模式。

## 决策

切换按钮回调先拒绝 `photoImportLeaseActive`，再调用原有 `setSelectionIsFreehand()`。响应式
可用性、当前标签展示、持久化事务和失败恢复不变。

## 结果

共享照片导入窗口内，晚到的切换点击不会再改写选中形状模式。正常自由手与矩形选择行为保持不变。
