# ADR-0492: 备份本地动作纳入忙碌边界

日期：2026-08-26

## 状态

Accepted

## 背景

`BackupPage` 的云备份、云恢复和错误重试已用响应式禁用与回调忙碌检查，两个本地操作方法内部也通过
共享操作租约拒绝并发。但“导出全部笔记”和“导入笔记文件”按钮缺少 `.enabled(!this.isBusy)`，直接
回调也会在长任务期间进入组件层并依赖业务层兜底拒绝。

## 决策

两个本地备份按钮统一采用既有组件层边界：响应式禁用 `!isBusy`，点击后立即再次拒绝 `isBusy` 再转发
到原方法。导出/导入文件选择、共享租约、状态提示和正常备份语义不变。

## 结果

本地导出与导入获得可见禁用态和 fail-closed 回调防线。操作租约 Replay 扩展至 11 项，锁定视觉状态
与回调前置条件。
