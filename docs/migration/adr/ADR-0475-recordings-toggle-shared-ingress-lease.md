# ADR-0475: 录音面板开关纳入共享照片导入租约

日期：2026-08-26

## 状态

Accepted

## 背景

录音按钮已有响应式禁用，父页回调也会拒绝共享导入和结构租约；但顶部栏点击仍可直接切换
`showRecordings`。租约切换竞态中，晚到事件可先打开录音面板。

## 决策

顶部栏录音回调在读取当前可见性前拒绝 `photoImportLeaseActive`。打开、关闭、父页回调防线、
响应式可用性和录音面板组件防线不变。

## 结果

共享照片导入窗口内，晚到录音开关事件不会再改变面板可见性。正常录音面板操作保持不变。专项
Replay 锁定该新防线。
