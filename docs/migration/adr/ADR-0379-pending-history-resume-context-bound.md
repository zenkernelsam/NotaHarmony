# ADR-0379：挂起历史恢复上下文绑定

- 状态：已接受（2026-08-25）
- 场景：跨页撤销/重做会保存 pending 方向并在目标页数据加载完成后调用 `resumePendingHistory()`；旧实现只检查方向非零，销毁、加载失败、忙碌或身份不一致时仍可立即执行历史命令。
- 决策：恢复前先检查生命周期、加载健康和 `historyBusy`，无效上下文消费并清除 pending；再要求 `loadedPageId === currentPage.pageId`，页身份不一致则保留 pending 等匹配重载。
- 结果：陈旧挂起方向不会在错误页或异常状态执行 durable 历史；正常跨页移动仍会在目标页就绪后自动继续。
