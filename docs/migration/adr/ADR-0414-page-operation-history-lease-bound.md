# ADR-0414: 页面操作与页级历史租约互斥裁决

日期：2026-08-25

## 状态

Accepted

## 背景

Phase 441 后窄审跨页历史等待窗口。`NoteCanvasView` 在目标页不在当前页时先置位导航历史
租约并请求切页；但 `NotePage.runPageOperation()` 只检查 `pageOperationBusy`，新增、删除、
移动、背景等页面结构操作仍可在等待期间改写页序、选中页或页面内容，导致挂起历史命令被饿死
或落到错误源状态。

## 决策

1. 页面结构操作的统一入口在执行前检查 `pageOperationBusy`、跨页 `historyPending` 与
   `pageStructureLeaseActive`。任一所有权活跃时 fail closed，不重排队、不改写选中页。
2. 三个页级历史回调统一进入 `runPageHistoryOperation()`。该包装器以 `pageOperationBusy`
   拥有整个持久化历史应用过程，成功与失败路径都在 `finally` 精确释放。
3. 标题与元数据继续保留各自的专用前置门禁：标题保存飞行计数仍优先拒绝，包装器只负责与
   页面结构操作互斥。
4. 跨页导航请求本身保持现有检查，不因本修复引入自动重试；用户重新触发时按当前状态重新裁决。

## 结果

跨页历史从“等待切页”到“持久化应用完成”形成单一互斥窗口。页面结构操作不能重定向挂起命令，
页级历史也不能与结构变更交错；既有导航租约释放顺序、删除租约和标题保存队列语义不变。
