# ADR-0437: 已打开图片裁剪纳入共享照片导入租约

日期：2026-08-26

## 状态

Accepted

## 背景

既有守卫只覆盖 `startImageCrop()` 与 `confirmImageCrop()` 的入口，以及画布触摸。
裁剪会话打开后进入照片导入窗口时，拖动把手、重置草稿、关闭会话和确认按钮仍可执行；
关闭还会重建选区并发布墨迹控件状态。这些路径与导入结果合并竞争。

## 决策

`ImageCropOverlay` 接收共享导入租约，导入期禁用关闭、重置、确认和把手拖动。父视图的
`onMove/onClose/onReset/onConfirm` 回调再显式按顺序拒绝共享导入与历史租约。裁剪模型、
确认事务、撤销入栈和生命周期销毁清理语义不变；`aboutToDisappear()` 仍直接取消会话。

## 结果

已打开裁剪在照片导入收口前不能产生新副作用；导入完成后恢复。焦点 Replay 锁定属性传递、
三按钮禁用与四回调双层守卫。未启动模拟器、虚拟机、真机或 Hypium；T-042 保持 Goal 最后任务。
