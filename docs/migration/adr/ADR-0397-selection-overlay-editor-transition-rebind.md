# ADR-0397：临时编辑器后重绑选区浮层

## 状态

已接受（2026-08-25，Phase 420）。

## 背景

Harmony 选区进入 Math 编辑或图片裁剪时会隐藏 `selectionVisible`，但保留 SelectionTool 中的概念选区。
取消或确认编辑器后，现有路径会刷新能力寄存器和几何缓存，却没有把非空几何重新发布为可见状态。
结果包括：恢复后的选区不可见、无法拖拽或打开菜单；视口与容器 resize 因可见性门禁跳过刷新；
粘贴目标继续读取陈旧屏幕矩形。权威退出、绘制开始和空选区仍必须保持隐藏，不能通过全局改写可见性复活。

## 决策

1. 将 Math 编辑和图片裁剪归类为保持概念选区的临时转换。
2. 导航分离、取消、Math 确认投影以及图片裁剪取消/确认在调用 `updateSelectionOverlay()` 后，
   对已计算出的非空几何显式执行 `selectionVisible = true`。
3. 不修改 `updateSelectionOverlay()` 自身的空态隐藏语义，避免覆盖 Phase 418 的权威退出结果。
4. 权威退出继续使用统一清空与寄存器重置；临时转换不重置选区身份或 Ink 寄存器上下文。

## 后果

临时编辑器关闭后，SelectionTool、selectionRect、selectionVisible 与渲染层重新一致；
后续 viewport/container resize 能继续维护浮层。原版 1.0.3 的 `xsc` 状态机把 Math/文本转换作为选区控制器内的
过渡状态，成功或失败都会回到空闲以外的选区上下文，支持该恢复语义。静态 Replay 覆盖隐藏、恢复、resize 可修复
与权威退出不复活四类断言；运行态体验仍留待最终允许设备后的回归验收。
