# ADR-0451: 工具与笔刷样式按钮禁用纳入共享照片导入租约

日期：2026-08-26

## 状态

Accepted

## 背景

普通工具按钮和笔刷样式按钮的回调已拒绝共享导入租约，但两个 Builder 的启用条件只检查
工具状态加载。导入窗口内这些按钮保持视觉可点，形成回调防御与控件禁用不一致。

## 决策

`ToolButton` 与 `StyleButton` 在既有 `toolStateLoading` 门禁外叠加共享导入租约；原有回调
守卫保留为第二层。工具模型、样式模型、紧凑菜单和选区样式语义不变。

## 结果

共享照片导入收口窗口内普通工具与笔刷样式入口同步呈现禁用态，且仍有双层防线。
焦点 Replay 锁定两组一致化绑定和两项回调守卫。
未启动模拟器、虚拟机、真机或 Hypium；T-042 保持 Goal 最后任务。
