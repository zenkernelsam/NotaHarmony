# ADR-0489: 标题输入提交纳入加载边界

日期：2026-08-26

## 状态

Accepted

## 背景

标题 `TextInput` 的输入、回车与失焦回调已拒绝共享导入租约，但未拒绝页面加载失败或加载中的状态。
晚到事件可更新草稿、关闭编辑态并排队 SET_METADATA，即使当前没有已验证的选中页。

## 决策

三个标题回调在共享租约检查中同步加入 `pageLoadFailed || pageLoading` 拒绝。序列化保存队列、幂等
发布、失败恢复、销毁守卫、历史语义和点击编辑入口的既有防线保持不变。

## 结果

页面未就绪时，晚到标题输入不会再修改草稿或启动持久化；正常编辑路径不变。标题共享租约 Replay
锁定该防线。
