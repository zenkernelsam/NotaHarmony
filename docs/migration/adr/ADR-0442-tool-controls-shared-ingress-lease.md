# ADR-0442: 已打开颜色与宽度面板纳入共享照片导入租约

日期：2026-08-26

## 状态

Accepted

## 背景

选区样式信号入口已有共享导入租约，但导入前打开的颜色网格和宽度滑块仍可继续交互。
非选区路径会直接调用 `setBrushColor()` 或 `setBrushWidth()`，先改写内存工具状态再排队
持久化；选区路径也会在父回调内被共享租约拒绝。两类操作都可能与照片导入收口竞争。

## 决策

`ColorPickerView` 与 `WidthSlider` 接收共享导入租约并禁用色块和滑杆交互。
`EditorToolbar` 把父页 `photoImportLeaseActive` 传入两个面板；既有 `onSelectionColor`
与 `onSelectionWidth` 回调继续按序拒绝共享导入、页面结构、历史等待和加载健康租约。
工具状态模型、保存链、回滚和选区墨迹语义不变。

## 结果

已打开工具面板不能在照片导入窗口内改写笔刷或选区墨迹，也不能排队新的工具状态写入；
导入完成后下一次交互恢复。焦点 Replay 锁定属性传递、两处控件禁用和两项回调守卫。
未启动模拟器、虚拟机、真机或 Hypium；T-042 保持 Goal 最后任务。
