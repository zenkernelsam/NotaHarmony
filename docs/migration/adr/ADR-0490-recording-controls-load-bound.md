# ADR-0490: 录音面板控件纳入加载边界

日期：2026-08-26

## 状态

Accepted

## 背景

录音面板 `controlsEnabled` 只拒绝共享导入租约；`recordingsLoading` 期间列表可能正在替换、清空或
重建时间线。晚到点击可基于过期快照调用播放、删除、撤销或会话控制回调。

## 决策

`controlsEnabled` 同时拒绝 `loading`，使响应式禁用与回调门禁覆盖加载中状态。共享租约、结构租约、
录制状态机、播放快照和父页业务防线保持不变。

## 结果

录音列表未收尾时，面板控件不会触发动作；正常交互路径不变。录音面板共享租约 Replay 锁定该防线。
