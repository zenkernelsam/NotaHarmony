# ADR-0542：真机验收清单的集中登记

## 状态

已实施（Phase 571）

## 背景

交接文档第四节 P1(d) 要求在端到端验收前把“必须真机验证”的项汇总为一
张表。此前相关事项散落在 150+ 个 ADR 的限制章节中，无单一入口，真机
首次可用时无法快速枚举待验项。

## 决策

- 新建 `docs/migration/audit-2026-08/真机验收清单-2026-09-22.md` 作为
  唯一集中清单，按子系统 9 组登记 41 项，每行关联 ADR/Phase 证据与
  建议验证方法。
- 登记口径：仅收录“桌面 replay + HAP 静态构建无法覆盖”的运行态事项；
  已由 replay/构建证明的静态语义不重复登记。
- 维护规则写入清单尾部：新 Phase 引入“仅真机可验”项必须同步登记；
  真机验收完成后在对应 ADR/evidence 回填结论。

## 差异

- 无产品行为差异；本阶段为审计/文档工件，不改 Harmony 源码。

## 验证

- fixture `d02-device-verification-checklist.mjs` 校验清单结构与引用
  完整性；全套 replay 与双 HAP 构建通过。
