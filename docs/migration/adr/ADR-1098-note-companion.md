# ADR-1098：x09 标记 + m09 伴生

## 状态

已接受（Phase 1154）。

## 决策

- `x09` = 笔记聚合标记 iface（`m09.a` 伴生，无方法）。
- `m09` = 伴生：镜 `a79.N/O/P` 默认（qed scale、vy7
  margins、hu1/nz9/float）+ `a(r29,cl9)` 工厂。

## 依据

`x09{a=m09.a}` + `m09` 静态默认镜 `a79.N/O/P` + 工厂。

## 后果

Harmony：note 种类接口 + defaults 常量 + create 工厂；
`a79` 默认值集中伴生。
