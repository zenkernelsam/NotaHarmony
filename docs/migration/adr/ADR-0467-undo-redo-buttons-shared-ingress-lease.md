# ADR-0467: Undo/Redo 按钮纳入共享照片导入租约

日期：2026-08-26

## 状态

Accepted

## 背景

工具栏 Undo/Redo 按钮已按可用性与共享导入租约响应式禁用；父页回调和画布历史执行也拒绝共享
导入及页面操作/历史租约。但组件内点击直接转发，租约切换竞态中可先递增历史方向信号。

## 决策

两个按钮回调先拒绝 `photoImportLeaseActive`，再调用原有 `onUndo()` / `onRedo()`。响应式
可用性、父页页面操作与历史挂起防线、历史执行顺序和撤销/重做语义不变。

## 结果

共享照片导入窗口内，晚到的 Undo/Redo 点击不会再触发历史信号。正常撤销重做行为保持不变。
