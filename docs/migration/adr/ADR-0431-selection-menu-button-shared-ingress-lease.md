# ADR-0431: 选区菜单按钮纳入共享照片导入租约

日期：2026-08-26

## 状态

Accepted

## 背景

Phase 451 已在 `onSelectionMenuAction()` 统一拒绝共享导入租约，但选区菜单按钮可在导入开始前
保持展开。照片导入异步持久化释放内部历史租约后、外层 `finally` 收口前，用户仍可点击 COPY；
该动作会基于当前元素数组准备并发布剪贴板快照。多数变更动作会被入口守卫拒绝，COPY 的内存快照
仍可能与随后照片结果不同步。

## 决策

`SelectionOverlay` 新增 `menuEnabled` 属性，菜单按钮按 Canvas 当前健康、历史与共享导入状态禁用；
统一入口守卫保留为第二层防御。不新增生产状态字段，不改变各 action 逻辑或剪贴板格式。

## 结果

照片导入收口前不能通过已展开菜单发布新快照；导入完成后按钮恢复。焦点 Replay 锁定属性、按钮
绑定与第二层守卫。未启动模拟器、虚拟机、真机或 Hypium；T-042 保持 Goal 最后任务。
