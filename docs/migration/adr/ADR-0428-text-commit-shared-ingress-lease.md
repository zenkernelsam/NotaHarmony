# ADR-0428: 文本提交纳入共享照片导入租约

日期：2026-08-26

## 状态

Accepted

## 背景

Phase 454 阻止照片导入期间新建触摸交互，但既有文本编辑会话可在导入前打开。其统一提交
入口 `onTextCommit()` 原只检查 `historyBusy`。异步图片持久化释放内部历史租约后、外层
`finally` 收口共享租约前，确认编辑可替换或新增文本块、更新 elementOrder 并推入撤销栈。

## 决策

`onTextCommit()` 在内部历史门禁前拒绝 Canvas `photoImportBusy`，返回 false 让用户保留
草稿；不自动取消会话。空新建文本的原有取消语义和原版 CRDT 预览流程不变。

## 结果

既有文本编辑不再于照片导入收口前提交文档变更；导入完成后可重新确认。焦点 Replay 锁定
守卫存在与顺序。未启动模拟器、虚拟机、真机或 Hypium；T-042 保持 Goal 最后任务。
