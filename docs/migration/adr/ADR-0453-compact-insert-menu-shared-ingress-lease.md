# ADR-0453: 紧凑工具菜单插入项纳入共享照片导入租约

日期：2026-08-26

## 状态

Accepted

## 背景

Phase 479 后，普通与笔刷样式按钮的启用条件和回调均已消费共享照片导入租约；但紧凑工具菜单中的
Photo 与 Math 两项仍只依赖父页入口守卫。若菜单在租约开始前打开，点击动作缺少组件内第一层防线，
与同菜单其他直改项不一致。

## 决策

`buildCompactToolMenu()` 的 `insert_photo` 与 `insert_math` action 先拒绝
`photoImportLeaseActive`，再调用原有回调。父页 Math 信号、照片信号、页面操作、历史挂起和页面
结构租约防线保持不变；普通布局 Photo/Math 按钮继续由禁用条件与父页守卫保护。

## 结果

已打开的紧凑菜单在共享导入收口窗口内不会重新排队插入信号。正常交互语义不变。
专项 Replay 锁定两项 action 的租约防线。
未启动模拟器、虚拟机、真机或 Hypium；T-042 保持 Goal 最后任务。
