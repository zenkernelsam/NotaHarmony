# ADR-0376：背景刷新选择绑定

- 状态：已接受（2026-08-25）
- 场景：`applyNoteBackgroundSettings()` 持久化成功后先等待页列表刷新，再向 Canvas 发布 `selectedPageId`；该 await 期间的用户切页可被旧续体改回目标页，形成背景操作抢夺导航。
- 决策：`updateNoteBackground()` 返回并通过销毁检查后，立即按原目标页恢复选择，再执行页列表刷新；后续仍保留既有销毁检查、背景发布和撤销推入顺序。
- 结果：用户在持久化与列表刷新之间完成的切页不被旧背景续体回抢；durable 背景、撤销记录和失败处理不变。
