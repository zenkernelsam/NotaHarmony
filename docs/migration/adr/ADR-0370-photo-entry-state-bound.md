# ADR-0370：图片入口启动状态绑定

- 状态：已接受（2026-08-25）
- 场景：相册插入与剪贴板粘贴的启动谓词缺少 `lifecycleActive` 与 `loadedPageId === currentPage.pageId`，迟到信号可在销毁或切页边界进入选择器/权限流程。
- 决策：两个入口统一要求画布 active、页面身份一致、加载健康、无忙碌冲突且持久化就绪；剪贴板入口继续要求缓存可用。
- 结果：陈旧启动不再打开系统选择器、请求 READ_PASTEBOARD 或设置 busy；活动页入口与既有迟到续体门禁不变。
  验证为专项 15/15、相邻照片销毁 8/8、既有剪贴板入站 29/29、全量 Desktop Replay 360/360；clean 后双 HAP 静态构建通过。
