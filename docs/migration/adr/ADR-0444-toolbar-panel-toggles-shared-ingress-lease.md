# ADR-0444: 颜色与宽度面板开关纳入共享照片导入租约

日期：2026-08-26

## 状态

Accepted

## 背景

Phase 470 已禁用已打开的颜色网格和宽度滑杆，Phase 471 已收口工具栏其他直改路径，但两个
面板开关按钮仍可在共享照片导入期改写 `showColorPicker` 与 `showWidthSlider`。这会重新挂载
已被租约禁用的面板并翻转互斥 UI 状态，造成导入窗口内的可见状态竞争。

## 决策

颜色开关与粗细开关在既有工具上下文、选区上下文和加载门禁之外叠加共享导入租约；回调内先
拒绝该租约，再执行原有切换和互斥关闭逻辑。面板内容模型、选区/笔刷语义和既有回调防御不变。

## 结果

导入前打开的开关不能在导入收口窗口内重新展开或隐藏面板，也不能改变互斥面板状态；
导入完成后交互恢复。焦点 Replay 锁定两处控件禁用、两项回调和原有互斥语义。
未启动模拟器、虚拟机、真机或 Hypium；T-042 保持 Goal 最后任务。
