# ADR-0455: 已打开文本编辑纳入共享照片导入租约

日期：2026-08-26

## 状态

Accepted

## 背景

共享照片导入租约已覆盖画布触控入口和文本提交/取消回调；但 `beginTextEditingAt()` 作为
已打开文本创建与编辑的直接变更边界，此前缺少组件内第一层防线。若调用信号在租约开始前
入队，仍可能在导入收口窗口内打开文本会话并进入提交链。

## 决策

`beginTextEditingAt()` 先拒绝 `photoImportBusy || historyBusy`，再查找并激活既有文本块。
触控入口抑制、overlay 控件、提交/取消双层守卫、持久化、历史和页面上下文校验保持不变。

## 结果

已打开文本路径不会再于共享导入窗口或历史租约期内启动编辑事务；正常点击编辑行为不变。
既有专项 Replay 扩展锁定新防线。未启动模拟器、虚拟机、真机或 Hypium；T-042 保持 Goal
最后任务。
