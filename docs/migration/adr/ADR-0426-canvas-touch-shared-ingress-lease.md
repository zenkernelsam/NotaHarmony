# ADR-0426: 画布触摸纳入共享照片导入租约

日期：2026-08-26

## 状态

Accepted

## 背景

Phase 451-453 已关闭选区菜单、数学插入和选区样式入口，但画布统一触摸入口只检查加载
健康与 `historyBusy`。照片导入异步持久化释放内部历史租约后、外层 `finally` 收口共享
导入租约前，触摸仍可启动书写/擦除/选区交互，或经文本双击切换复选框、创建文本块并推入
撤销栈，与照片插入合并结果竞争。

## 决策

`onCanvasTouch()` 在内部 `historyBusy` 前拒绝 Canvas `photoImportBusy`；既有健康、
数据失败、图片裁剪和数学编辑器门禁保留。触摸入口串行化后，不改变各工具的下游校验、
手势语义或持久化流程。

## 结果

照片导入收口前不再接受新的画布触摸交互；已进入的交互仍由原有提交路径和历史防御处理。
新增焦点 Replay 锁定守卫存在与检查顺序。未启动模拟器、虚拟机、真机或 Hypium；
T-042 保持 Goal 最后任务。
