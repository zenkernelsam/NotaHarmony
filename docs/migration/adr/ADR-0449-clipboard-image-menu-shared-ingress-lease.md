# ADR-0449: 剪贴板图片菜单动作纳入共享照片导入租约

日期：2026-08-26

## 状态

Accepted

## 背景

画布长按菜单的可见性已依赖 `canUseOriginalClipboardImage()`，该函数拒绝共享导入租约；
但 ArkUI 菜单可能在租约开始前构建并保持显示。其唯一“粘贴图片”项点击后直接启动剪贴板
图片导入，可在导入收口窗口内再次翻转 `photoImportBusy`，与既有入口双层防御不一致。

## 决策

长按菜单项点击后先拒绝当前共享导入租约，再调用原有导入函数。可见性探测、权限申请、
锚点捕获、上下文校验、插入事务和失败反馈不变。

## 结果

共享照片导入收口窗口内遗留的长按菜单不能重复进入剪贴板图片导入；正常入口仍由可用性和
回调防御共同保护。焦点 Replay 锁定菜单守卫与绑定。
未启动模拟器、虚拟机、真机或 Hypium；T-042 保持 Goal 最后任务。
