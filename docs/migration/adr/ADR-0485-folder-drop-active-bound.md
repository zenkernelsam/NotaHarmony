# ADR-0485: 文件夹拖放收尾纳入激活边界

日期：2026-08-26

## 状态

Accepted

## 背景

文件夹 `onItemDrop` 收尾会读取捕获的拖拽状态并可能启动 `moveFolder()` 持久化事务；入口未先拒绝
失活页面。晚到 drop 可在旧生命周期中解析目标并写库，即使后续成功发布会被丢弃。

## 决策

`finishFolderDrag()` 第一条语句拒绝非 `pageActive` 状态，同时清理拖拽快照；随后才读取状态、计算
意图或调用原移动事务。忙态拒绝、子树边界、层级深度、失败提示和成功发布保持不变。

## 结果

失活库页的晚到拖放不会再发起文件夹移动；正常拖拽语义不变。原版文件夹索引拖拽 Replay 锁定该防线。
