# ADR-0427: 图片裁剪纳入共享照片导入租约

日期：2026-08-26

## 状态

Accepted

## 背景

画布触摸、选区菜单、数学插入和选区样式已串行化，但图片裁剪会话可先于照片导入建立。
`startImageCrop()` 只检查内部历史与可见性；`confirmImageCrop()` 也只检查历史。照片导入
异步持久化释放 `historyBusy` 后、外层 `finally` 收口前，确认裁剪可替换图像元素并推入
撤销栈，与照片插入合并结果竞争。

## 决策

裁剪启动与确认都在内部历史门禁前拒绝 Canvas `photoImportBusy`。已有裁剪会话继续允许
拖拽、重置和取消等无文档写入操作，但确认必须等待导入收口；不新增状态字段或改变裁剪
算法。

## 结果

照片导入期间不会产生新的裁剪提交竞争；导入完成后恢复交互。焦点 Replay 锁定两个入口的
守卫存在与顺序。未启动模拟器、虚拟机、真机或 Hypium；T-042 保持 Goal 最后任务。
