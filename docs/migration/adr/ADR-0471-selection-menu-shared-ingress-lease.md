# ADR-0471: 选区菜单动作纳入共享照片导入租约

日期：2026-08-26

## 状态

Accepted

## 背景

选区菜单按钮已按共享导入、历史、页面健康和身份条件响应式禁用；画布入口与各动作分支也有
防线。但组件内 `buildSelectionMenu()` 仍无条件生成全部动作，租约切换竞态中晚到点击可先转发。

## 决策

向 `SelectionOverlay` 传入共享照片导入租约状态。`buildSelectionMenu()` 在租约激活时立即返回
空菜单，否则生成原有动作列表。按钮可用性、动作顺序、能力条件、日志和父级防线不变。

## 结果

共享照片导入窗口内，晚到的选区菜单不会再暴露或触发任何选择动作。正常选区操作保持不变。
专项 Replay 锁定租约属性、空菜单返回和父级绑定。
