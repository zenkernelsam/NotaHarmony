# ADR-0359：备份加载与准备陈旧反馈绑定

Status: Accepted - Phase 382（2026-08-24）

## Context

`BackupPage.reloadPage()` 成功续体会检查销毁与加载代次，但失败续体只检查加载代次。迟到失败仍可清空配置、
服务器、上次备份状态并向旧页面发布 ERROR。`backupAll()` 内层准备 catch 也会在 `exportAllNotes()` 失败后
构造用户文案并直接弹窗，绕过外层生命周期门禁。

## Decision

- 重载失败先记录 durable 错误；随后必须同时满足页面未销毁且仍是当前加载代次，才允许重置或发布错误 UI。
- 云备份准备失败同样先记录 durable 错误；陈旧任务在计算用户文案和调用 alert 前静默返回。
- 活动页的错误展示、配置重置、备份流程和 finally 清理语义保持不变。

## Consequences

离开或换代后的旧重载与旧准备任务不会再触达旧界面。真实数据库故障、配置存储异常和网络失败的用户可见表现
仍需后续设备级验收。本决策不启动模拟器、虚拟机、真机或 Hypium。
