# ADR-0498：资料库文件夹交互入口激活边界

日期：2026-08-29

## 状态

Accepted

## 背景

文件夹查询和部分确认入口已经具备生命周期续体保护，但多个文件夹交互入口仍只检查 `folderBusy` 或仓库存在：打开/重命名对话框、删除确认、删除/移动文件夹、移动笔记、按索引重排、拖拽捕获、展开树和打开 compact drawer。失活页面的晚到菜单、拖拽或按钮事件仍可能修改 UI 快照、启动查询/持久化，随后才由异步 guard 丢弃结果。

## 决策

所有上述文件夹交互和突变入口在原有忙态/仓库检查前增加 `pageActive` 准入；失活时不修改对话框、展开集合、拖拽快照或 busy 状态，也不启动仓库操作。`closeCompactFolderDrawer()` 保持无条件可用，允许失活/忙态清理 UI。

## 结果

文件夹领域入口与其后续生命周期 guard 形成一致的 fail-closed 边界；活动页的创建、重命名、删除、移动、排序、拖拽和导航语义不变。全量 Desktop Replay `421/421`（33.836 秒），clean 2.951 秒、ohosTest HAP 9.097 秒、default HAP 27.608 秒静态构建成功。
