# ADR-0430: 文本取消纳入共享照片导入租约

日期：2026-08-26

## 状态

Accepted

## 背景

Phase 456 已串行化文本提交，但取消路径仍只检查 `historyBusy`。导入前新建的空文本块在
异步照片持久化释放内部历史租约后、共享租约收口前被取消时，会从 `textBlocks` 与
`elementOrder` 删除元素并触发持久化，与随后照片结果合并产生顺序和状态竞争。

## 决策

`onTextCancel()` 在内部历史门禁前拒绝 Canvas `photoImportBusy`；用户可稍后重试取消或确认。
不自动销毁草稿，也不改变空文本创建的撤销语义、原始墨迹预约刷新或页上下文防御。

## 结果

既有空文本取消不再与照片导入收口竞争文档状态；焦点 Replay 锁定守卫及副作用路径。未启动
模拟器、虚拟机、真机或 Hypium；T-042 保持 Goal 最后任务。
