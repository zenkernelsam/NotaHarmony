# ADR-0486: 笔记新建删除纳入激活边界

日期：2026-08-26

## 状态

Accepted

## 背景

笔记删除确认、删除事务和新建入口依赖后续生命周期守卫丢弃结果，但入口本身未拒绝失活页面。
晚到菜单确认或 FAB 点击可打开对话框、递增忙态并启动无意义持久化事务。

## 决策

`confirmDelete()`、`deleteNoteAndRefresh()` 与 `createAndOpen()` 的第一条防线加入 `pageActive`
拒绝。原有忙态检查、生命周期捕获、成功/失败上下文守卫、快照发布、导航和提示语义保持不变。

## 结果

失活库页不会再接受晚到笔记创建、删除确认或持久化；正常入口不变。笔记创建/删除生命周期边界
Replay 锁定该防线。
