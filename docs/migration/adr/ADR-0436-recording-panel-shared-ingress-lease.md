# ADR-0436: 录音面板纳入共享照片导入租约

日期：2026-08-26

## 状态

Accepted

## 背景

Phase 463 后继续盘点导航级副作用，发现录音面板只感知录音自身状态。照片导入释放
内部历史租约但尚未收口时，面板仍可启动或停止录音、切换播放、seek、切档、软删除和
撤销删除。这些路径会操作录音资源、加载资产或排队持久化删除，与导入收口竞争。

## 决策

父页向 `RecordingPanel` 传递共享租约状态；共享导入期间禁用 seek、速度、录制控制、
播放、删除和撤销删除。九个回调再显式拒绝共享导入与结构租约，作为第二层防御。
关闭面板按钮保持可用，录音控制器与删除控制器内部语义不变。

## 结果

照片导入收口前录音面板不能发起新副作用；导入完成后立即恢复。焦点 Replay 锁定属性
传递、控件禁用和全部回调守卫。未启动模拟器、虚拟机、真机或 Hypium；T-042 保持
Goal 最后任务。
